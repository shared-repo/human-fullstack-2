# PRD: 게시판 글쓰기 화면 개발

## 1. 개요
HTML Form 태그를 활용하여 사용자가 게시판에 글을 작성할 수 있는 화면을 구축한다.

## 2. 목표
- HTML Form의 주요 구성 요소(input, select, textarea, radio, checkbox 등)의 올바른 사용법 익히기.
- `<table>`을 활용한 레이아웃 구성 및 `<label>`을 이용한 접근성 향상.

## 3. 요구사항 상세

### 3.1 기본 구조
- **파일명**: `write-board.html`
- **제목**: 화면 상단에 "게시판 글쓰기" 제목 표시 (`<h1>` 또는 `<h2>` 권장)
- **Form 속성**: 
    - `method="post"`
    - `action` 속성은 생략하거나 비워둠.

### 3.2 입력 항목 및 유효성 검사
| 항목 | 입력 방식 | 필수 여부 | 상세 조건 |
| :--- | :--- | :---: | :--- |
| 작성자 | `text` | 필수 (*) | placeholder 제공 |
| 비밀번호 | `password` | 필수 (*) | 필수 입력 |
| 제목 | `text` | 필수 (*) | placeholder 제공 |
| 카테고리 | `select` | - | 공지사항, 질문, 자유게시판 |
| 공개 여부 | `radio` | - | 공개 / 비공개 (기본값 설정 권장) |
| 내용 | `textarea` | 필수 (*) | 5줄(rows) 이상 입력 가능 |
| 첨부파일 | `file` | - | 단일 파일 선택 |
| 작성 동의 | `checkbox` | - | "게시글 등록에 동의합니다." 문구 포함 |

### 3.3 버튼 기능
- **등록 버튼**: `type="submit"`. 입력된 데이터를 서버로 전송 시도.
- **취소 버튼**: `type="reset"`. 입력한 모든 내용을 초기화.

## 4. 화면 디자인 및 레이아웃 조건
- **레이아웃**: `<table>` 태그를 사용하여 항목명과 입력창을 정렬한다.
- **레이블**: 모든 입력 항목에 `<label>` 태그를 적용하여 클릭 편의성과 접근성을 보장한다.
- **필수 표시**: 필수 입력 항목(작성자, 비밀번호, 제목, 내용) 옆에 `*` 표시를 하여 시각적으로 안내한다.
- **UI 가이드**: 사용자가 보기 쉽도록 적절한 여백과 배치를 유지한다.

## 5. 예시 레이아웃 (Wireframe)
1. 제목: 게시판 글쓰기
2. 테이블 구성:
    - [작성자 *] [입력란]
    - [비밀번호 *] [입력란]
    - [제목 *] [입력란]
    - [카테고리] [드롭다운]
    - [공개 여부] ( )공개 ( )비공개
    - [내용 *] [텍스트 영역]
    - [첨부파일] [파일 선택]
    - [ ] 게시글 등록에 동의합니다.
3. [등록] [취소] 버튼 중앙 또는 우측 정렬
