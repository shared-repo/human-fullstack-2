이미지 갤러리 웹 페이지 만들기

목표

HTML을 활용하여 여러 장의 이미지를 한 페이지에 배치하고, 사용자가 이미지를 쉽게 감상할 수 있는 갤러리 페이지를 구현한다.

기능 요구사항

0. 이미지 준비
웹에서 원하는 주제의 이미지를 검색해서 다운로드
예 : 좋아하는 연예인, 영화, 여행지, 반려동물 등

1. html 파일 만들기

이름 : image-gallery.html

2. 페이지 제목 표시
페이지 상단에 갤러리 제목을 표시한다.
제목은 화면 중앙에 정렬한다.

예시
My Photo Gallery


3. 이미지 목록 표시
모든 이미지는 동일한 크기로 표시한다.
이미지가 깨지지 않도록 적절히 조정한다.

예시
[이미지] [이미지] [이미지]
[이미지] [이미지] [이미지]


4. 이미지 설명 표시
각 이미지 아래에 간단한 설명을 표시한다.
설명은 한 줄 정도의 짧은 문장으로 작성한다.

예시

[이미지]
제주도 풍경

[이미지]
강아지 산책

5. 이미지를 클릭하면 관련 웹사이트로 이동하도록 구현
