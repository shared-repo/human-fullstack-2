[주제]
React를 활용한 웹앱 제작

[ 요구사항 ]
1. 관심 주제 결정 ( 예 : 지역별통계 )
2. 세부 페이지 결정 ( 예 : 인구변화, 날씨/미세먼지 등 환경변화, ... )
3. 각 팀원이 1개 이상의 세부 페이지를 제작할 수 있도록 역할 부여
4. 각 팀원별 상세 페이지 구현 방법
    - 기본 정보 화면 또는 컴포넌트 구현
    - 상세 정보 화면 또는 컴포넌트 구현 - 목록 데이터를 테이블 / 그래프 형태로 표시
    - 옵션1: 기본 정보 화면에서 상세보기를 클릭하면 상세정보화면 표시
    - 옵션2: 같은 화면에서 기본 정보 컴포넌트의 버튼을 클릭하면 상세 정보를 컴포넌트에 관련 내용 표시

5. 메인페이지 제작 : 메인 페이지에서 세부 페이지로 연결하는 라우팅 구성
6. 데이터는 open api 사용해서 활용
7. 모든 페이지가 일관된 모양과 디자인을 갖도록 제작
8. CSS는 생성형 AI 서비스 활용 가능

[ 팀구성 ]
1팀 : 정용진, 최지성, 최연후, 박세인
2팀 : 김동현, 이동규, 조정은
3팀 : 이상진, 전민규, 허지훈
