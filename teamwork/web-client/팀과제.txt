[주제]
홈페이지 제작

[ 요구사항 ]
1. 관심 주제 결정 ( 예 : 영화 )
2. 세부 페이지 결정 ( 예 : 장르별 페이지 )
3. 각 팀원이 1개 이상의 페이지를 제작할 수 있도록 역할 부여
4. 메인페이지 제작 : 메인 페이지에서 세부 페이지로 연결하는 메뉴 링크 구성
5. 필요하다면 각 페이지 사이의 연결 구현
6. 가능하다면 open api 사용해서 화면 내용 제작 ( 선택적 )
7. 모든 페이지가 일관된 모양과 디자인을 갖도록 제작

[ 팀구성 ]
1팀 : 정용진, 허지훈, 최연후
2팀 : 김동현, 이동규, 조정은
3팀 : 이상진, 전민규, 최지성

미참여 : 박세인
