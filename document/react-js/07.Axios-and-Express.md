# 6일차: Axios와 Express 연동

## 학습 목표
- Axios를 이용해 GET/POST/PUT/DELETE 요청을 처리할 수 있다.
- Express의 기본 서버 구조(라우트, JSON 응답, CORS)를 이해한다.
- 프록시 개념을 이해하고, Express를 프록시 서버로 활용할 수 있다.
- React + Express를 연동하여 CRUD 기능을 구현할 수 있다.

---

## 1. Axios 소개

### 1.1 Axios란?
- HTTP 요청을 보내기 위한 자바스크립트 라이브러리
- `fetch`보다 사용법이 간단하고, 요청/응답 데이터를 자동으로 JSON으로 변환
- 인터셉터(interceptor), 타임아웃, 공통 설정(baseURL 등) 적용이 쉬움

### 1.2 설치

```bash
npm install axios
```

### 1.3 fetch와 비교

```jsx
// fetch
fetch('/api/users')
  .then((res) => res.json())
  .then((data) => console.log(data));

// axios
axios.get('/api/users')
  .then((res) => console.log(res.data));
```

## 2. Axios로 CRUD 요청 처리

### 2.1 GET 요청 (조회)

```jsx
import axios from 'axios';
import { useEffect, useState } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    axios.get('/api/users').then((res) => setUsers(res.data));
  }, []);

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

### 2.2 POST 요청 (생성)

```jsx
async function addUser(newUser) {
  const res = await axios.post('/api/users', newUser);
  return res.data;
}
```

### 2.3 PUT 요청 (수정)

```jsx
async function updateUser(id, updatedUser) {
  const res = await axios.put(`/api/users/${id}`, updatedUser);
  return res.data;
}
```

### 2.4 DELETE 요청 (삭제)

```jsx
async function deleteUser(id) {
  await axios.delete(`/api/users/${id}`);
}
```

### 2.5 axios 인스턴스 생성 (baseURL 설정)

```jsx
// api/client.js
import axios from 'axios';

const api = axios.create({
  baseURL: 'http://localhost:4000/api',
});

export default api;
```

```jsx
import api from './api/client';

api.get('/users').then((res) => console.log(res.data));
```

### 2.6 에러 처리

```jsx
async function loadUsers() {
  try {
    const res = await axios.get('/api/users');
    setUsers(res.data);
  } catch (err) {
    console.error('요청 실패:', err.message);
    setError('데이터를 불러오지 못했습니다.');
  }
}
```

## 3. Express 서버 기본 구조

### 3.1 Express란?
- Node.js 기반의 웹 서버 프레임워크
- 라우트(경로) 별로 요청을 처리하는 핸들러를 등록하는 방식

### 3.2 프로젝트 생성 및 설치

```bash
mkdir server
cd server
npm init -y
npm install express cors
```

### 3.3 기본 서버 작성

```js
// server/index.js
const express = require('express');
const cors = require('cors');

const app = express();
app.use(cors());
app.use(express.json());

app.get('/api/users', (req, res) => {
  res.json([
    { id: 1, name: '홍길동' },
    { id: 2, name: '김영희' },
  ]);
});

app.listen(4000, () => {
  console.log('서버가 4000번 포트에서 실행 중입니다.');
});
```

### 3.4 CORS란?
- 브라우저가 다른 출처(origin)의 서버로 보내는 요청을 기본적으로 차단하는 정책
- React 개발 서버(`localhost:5173`)와 Express 서버(`localhost:4000`)는 서로 다른 출처
- `cors` 미들웨어를 사용하면 다른 출처의 요청을 허용할 수 있음

### 3.5 라우트별 CRUD 핸들러 작성

```js
let users = [
  { id: 1, name: '홍길동', email: 'hong@example.com' },
  { id: 2, name: '김영희', email: 'kim@example.com' },
];

// 목록 조회
app.get('/api/users', (req, res) => {
  res.json(users);
});

// 단건 조회
app.get('/api/users/:id', (req, res) => {
  const user = users.find((u) => u.id === Number(req.params.id));
  if (!user) return res.status(404).json({ message: '사용자를 찾을 수 없습니다.' });
  res.json(user);
});

// 생성
app.post('/api/users', (req, res) => {
  const newUser = { id: Date.now(), ...req.body };
  users.push(newUser);
  res.status(201).json(newUser);
});

// 수정
app.put('/api/users/:id', (req, res) => {
  const id = Number(req.params.id);
  users = users.map((u) => (u.id === id ? { ...u, ...req.body } : u));
  res.json(users.find((u) => u.id === id));
});

// 삭제
app.delete('/api/users/:id', (req, res) => {
  const id = Number(req.params.id);
  users = users.filter((u) => u.id !== id);
  res.status(204).end();
});
```

## 4. 프록시 개념

### 4.1 프록시가 필요한 이유
- React 개발 서버와 API 서버의 포트가 다르면 CORS 문제가 발생할 수 있음
- Vite의 프록시 설정을 이용하면 React에서 `/api`로 요청 시 자동으로 Express 서버로 전달

### 4.2 Vite 프록시 설정

```js
// vite.config.js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  server: {
    proxy: {
      '/api': 'http://localhost:4000',
    },
  },
});
```

- 이 설정 이후 React 코드에서는 `axios.get('/api/users')`처럼 상대 경로로 요청 가능

### 4.3 외부 API 연동 시 프록시 활용 (미리보기)
- 8일차에서 다룰 Open API 연동 시, 외부 API 키를 클라이언트(브라우저)에 노출하지 않기 위해 Express 서버를 거쳐서 호출하는 패턴을 사용
- 오늘 실습에서는 우선 "내 데이터를 다루는 목업 서버"로 Express를 활용

## 5. 실습: Express 목업/프록시 서버 + React 연동 CRUD

### 실습 1. Express 목업 서버 구축
1. `server` 폴더에 Express 프로젝트 생성
2. 메모리 배열로 사용자 데이터 관리
3. 사용자 목록 조회(`GET /api/users`), 단건 조회(`GET /api/users/:id`), 생성(`POST /api/users`), 수정(`PUT /api/users/:id`), 삭제(`DELETE /api/users/:id`) API 구현
4. CORS 설정 적용

### 실습 2. React에서 Axios로 CRUD 연동
1. Vite 프로젝트에 axios 설치 및 프록시 설정
2. 사용자 목록을 불러와 화면에 표시 (로딩/에러 처리 포함, 5일차 내용 활용)
3. 입력 폼으로 새 사용자 추가 (POST)
4. 사용자 항목 클릭 시 수정 폼으로 전환하여 정보 수정 (PUT)
5. 삭제 버튼으로 사용자 제거 (DELETE)

### 실습 3. (선택) 로딩/에러 상태 + 사용자 피드백
1. 각 CRUD 동작(추가/수정/삭제) 시 처리 중 상태를 표시 (예: 버튼 비활성화)
2. 요청 실패 시 에러 메시지를 화면에 표시
