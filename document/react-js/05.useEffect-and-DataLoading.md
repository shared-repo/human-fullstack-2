# 5일차: useEffect와 생명주기

## 학습 목표
- 컴포넌트의 생명주기(마운트, 업데이트, 언마운트) 개념을 이해한다.
- useEffect를 이용해 부수 효과(side effect)를 처리할 수 있다.
- 의존성 배열의 역할을 이해하고 올바르게 사용할 수 있다.
- cleanup 함수를 이용해 리소스를 정리할 수 있다.
- 외부 데이터를 불러오고 로딩/에러 상태를 처리할 수 있다.

---

## 1. 컴포넌트 생명주기 개념

### 1.1 생명주기란?
- 컴포넌트가 화면에 나타나고(마운트), 업데이트되고, 사라지는(언마운트) 일련의 과정
- 마운트: 컴포넌트가 처음 화면에 그려질 때
- 업데이트: state나 props가 변경되어 다시 렌더링될 때
- 언마운트: 컴포넌트가 화면에서 제거될 때

### 1.2 부수 효과(Side Effect)란?
- 컴포넌트 렌더링과 직접적인 관련은 없지만 필요한 작업들
- 예: 데이터 가져오기(API 호출), 타이머 설정, 이벤트 리스너 등록, 외부 라이브러리 연동 등
- 이런 작업들은 `useEffect`를 통해 처리

## 2. useEffect 기본 사용법

### 2.1 기본 문법

```jsx
import { useEffect } from 'react';

function Welcome() {
  useEffect(() => {
    console.log('컴포넌트가 화면에 표시되었습니다.');
  });

  return <h2>환영합니다!</h2>;
}
```

- 기본적으로 컴포넌트가 렌더링될 때마다(마운트 + 업데이트 시) 실행됨

### 2.2 의존성 배열

```jsx
useEffect(() => {
  console.log('마운트 시 1번만 실행');
}, []); // 빈 배열: 처음 한 번만 실행

useEffect(() => {
  console.log('count가 변경될 때마다 실행');
}, [count]); // count가 바뀔 때만 실행
```

| 의존성 배열 | 실행 시점 |
| --- | --- |
| 없음 | 매 렌더링마다 |
| `[]` (빈 배열) | 마운트 시 1번만 |
| `[변수]` | 마운트 시 + 해당 변수가 변경될 때 |

### 2.3 예제: 문서 제목 변경

```jsx
function Counter() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `클릭 횟수: ${count}`;
  }, [count]);

  return (
    <div>
      <p>{count}번 클릭했습니다.</p>
      <button onClick={() => setCount(count + 1)}>클릭</button>
    </div>
  );
}
```

## 3. cleanup 함수

### 3.1 cleanup이 필요한 이유
- 타이머, 이벤트 리스너, 구독 등은 컴포넌트가 사라질 때 정리해주지 않으면 메모리 누수나 예기치 않은 동작이 발생할 수 있음

### 3.2 cleanup 함수 작성법
- `useEffect` 내부에서 함수를 반환하면, 컴포넌트가 언마운트되거나 의존성이 바뀌어 effect가 재실행되기 전에 호출됨

```jsx
useEffect(() => {
  const timer = setInterval(() => {
    console.log('1초마다 실행');
  }, 1000);

  return () => {
    clearInterval(timer); // cleanup: 타이머 해제
  };
}, []);
```

### 3.3 예제: 창 크기 감지

```jsx
function WindowSize() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    function handleResize() {
      setWidth(window.innerWidth);
    }

    window.addEventListener('resize', handleResize);

    return () => {
      window.removeEventListener('resize', handleResize);
    };
  }, []);

  return <p>현재 창 너비: {width}px</p>;
}
```

## 4. 데이터 로딩 패턴

### 4.1 fetch를 이용한 데이터 가져오기

```jsx
function UserList() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then((res) => res.json())
      .then((data) => setUsers(data));
  }, []);

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

### 4.2 로딩 상태 처리

```jsx
function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then((res) => res.json())
      .then((data) => {
        setUsers(data);
        setLoading(false);
      });
  }, []);

  if (loading) {
    return <p>로딩 중...</p>;
  }

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

### 4.3 에러 상태 처리

```jsx
function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetch('https://jsonplaceholder.typicode.com/users')
      .then((res) => {
        if (!res.ok) {
          throw new Error('데이터를 불러오지 못했습니다.');
        }
        return res.json();
      })
      .then((data) => setUsers(data))
      .catch((err) => setError(err.message))
      .finally(() => setLoading(false));
  }, []);

  if (loading) return <p>로딩 중...</p>;
  if (error) return <p>에러: {error}</p>;

  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

### 4.4 async/await를 이용한 방식

```jsx
useEffect(() => {
  async function loadUsers() {
    try {
      const res = await fetch('https://jsonplaceholder.typicode.com/users');
      if (!res.ok) throw new Error('데이터를 불러오지 못했습니다.');
      const data = await res.json();
      setUsers(data);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  }

  loadUsers();
}, []);
```

## 5. 실습: 외부 데이터 호출 및 로딩/에러 상태 처리

### 실습 1. 사용자 목록 불러오기
1. `https://jsonplaceholder.typicode.com/users` API를 호출하여 사용자 목록을 화면에 표시
2. 데이터를 불러오는 동안 "로딩 중..." 메시지 표시
3. 요청이 실패하는 경우(예: 잘못된 URL로 변경해서 테스트)를 대비해 에러 메시지 표시
4. 각 사용자 항목을 4일차에서 만든 라우팅 구조처럼 클릭 시 상세 정보를 보여주는 페이지로 이동 (선택)

### 실습 2. 검색어에 따른 데이터 재요청
1. 검색어 입력창을 만들고, 입력값을 state로 관리
2. `https://jsonplaceholder.typicode.com/posts?userId={검색어}` 형태로 API를 호출하여 결과를 표시
3. 검색어(`userId`)가 바뀔 때마다 `useEffect`의 의존성 배열을 이용해 데이터를 다시 요청
4. 검색 결과가 없을 경우 "결과가 없습니다" 메시지 표시 (조건부 렌더링)

### 실습 3. (선택) 타이머를 이용한 자동 새로고침
1. 5초마다 자동으로 데이터를 다시 불러오는 기능 구현 (`setInterval` + cleanup)
2. "마지막 갱신 시간"을 화면에 표시
