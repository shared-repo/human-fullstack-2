# 3일차: State와 이벤트 처리

## 학습 목표
- useState를 이용해 컴포넌트의 상태를 관리할 수 있다.
- 다양한 이벤트(클릭, 입력, 제출 등)를 처리할 수 있다.
- 제어 컴포넌트(Controlled Component)를 이용해 폼 입력을 관리할 수 있다.
- 간단한 유효성 검사를 적용할 수 있다.

---

## 1. State란?

### 1.1 State 개념
- 컴포넌트 내부에서 관리되는 "변하는 데이터"
- state가 변경되면 컴포넌트가 자동으로 다시 렌더링됨
- props는 부모로부터 전달받는 읽기 전용 데이터인 반면, state는 컴포넌트가 직접 관리하는 데이터

### 1.2 일반 변수와의 차이
- 일반 변수를 변경해도 화면은 갱신되지 않음
- state를 변경하면 React가 변경을 감지하고 화면을 다시 그림

## 2. useState 사용법

### 2.1 기본 문법

```jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>현재 값: {count}</p>
      <button onClick={() => setCount(count + 1)}>증가</button>
      <button onClick={() => setCount(count - 1)}>감소</button>
    </div>
  );
}

export default Counter;
```

- `useState(초기값)` → `[현재 상태, 상태를 변경하는 함수]` 반환
- 상태 변경 함수(`setCount`)를 호출해야만 화면이 갱신됨 (직접 `count = count + 1` 처럼 변경하면 안 됨)

### 2.2 함수형 업데이트
- 이전 상태 값을 기반으로 업데이트할 때는 함수 형태 사용 권장

```jsx
setCount((prev) => prev + 1);
```

### 2.3 여러 개의 state 사용

```jsx
function Profile() {
  const [name, setName] = useState('');
  const [age, setAge] = useState(0);

  return (
    <div>
      <p>이름: {name}</p>
      <p>나이: {age}</p>
    </div>
  );
}
```

### 2.4 객체/배열 state 다루기
- state를 변경할 때는 기존 객체/배열을 직접 수정하지 않고, 새로운 객체/배열을 만들어서 교체해야 함 (불변성 유지)

```jsx
const [user, setUser] = useState({ name: '홍길동', age: 28 });

// 올바른 방법: 스프레드 연산자로 새 객체 생성
setUser((prev) => ({ ...prev, age: prev.age + 1 }));
```

## 3. 이벤트 처리

### 3.1 이벤트 핸들러 작성법
- DOM 이벤트와 유사하지만 camelCase 사용: `onClick`, `onChange`, `onSubmit` 등
- 이벤트 핸들러에는 함수를 전달 (호출이 아닌 참조)

```jsx
function Button() {
  function handleClick() {
    alert('클릭되었습니다!');
  }

  return <button onClick={handleClick}>클릭</button>;
}
```

### 3.2 이벤트 객체 사용

```jsx
function InputBox() {
  function handleChange(e) {
    console.log(e.target.value);
  }

  return <input type="text" onChange={handleChange} />;
}
```

### 3.3 이벤트 핸들러에 인자 전달

```jsx
function List({ items }) {
  function handleDelete(id) {
    console.log('삭제:', id);
  }

  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>
          {item.text}
          <button onClick={() => handleDelete(item.id)}>삭제</button>
        </li>
      ))}
    </ul>
  );
}
```

## 4. 제어 컴포넌트 (Controlled Component)

### 4.1 제어 컴포넌트란?
- input, textarea, select 같은 폼 요소의 값을 React state로 관리하는 방식
- `value`와 `onChange`를 함께 사용 → 입력값이 항상 state와 동기화됨

```jsx
function NameInput() {
  const [name, setName] = useState('');

  return (
    <div>
      <input
        type="text"
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="이름을 입력하세요"
      />
      <p>입력한 이름: {name}</p>
    </div>
  );
}
```

### 4.2 폼 제출 처리

```jsx
function SignupForm() {
  const [email, setEmail] = useState('');

  function handleSubmit(e) {
    e.preventDefault(); // 기본 새로고침 동작 방지
    console.log('제출된 이메일:', email);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
      />
      <button type="submit">제출</button>
    </form>
  );
}
```

### 4.3 여러 입력 필드를 하나의 state(객체)로 관리

```jsx
function SignupForm() {
  const [form, setForm] = useState({ email: '', password: '' });

  function handleChange(e) {
    const { name, value } = e.target;
    setForm((prev) => ({ ...prev, [name]: value }));
  }

  return (
    <form>
      <input name="email" value={form.email} onChange={handleChange} />
      <input name="password" type="password" value={form.password} onChange={handleChange} />
    </form>
  );
}
```

## 5. 간단한 유효성 검사

### 5.1 기본 패턴
- 제출 시점 또는 입력 변경 시점에 값을 검사하고 에러 메시지를 state로 관리

```jsx
function SignupForm() {
  const [email, setEmail] = useState('');
  const [error, setError] = useState('');

  function handleSubmit(e) {
    e.preventDefault();
    if (!email.includes('@')) {
      setError('올바른 이메일 형식이 아닙니다.');
      return;
    }
    setError('');
    console.log('제출 성공:', email);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input value={email} onChange={(e) => setEmail(e.target.value)} />
      {error && <p style={{ color: 'red' }}>{error}</p>}
      <button type="submit">제출</button>
    </form>
  );
}
```

### 5.2 자주 사용하는 검사 항목
- 필수 입력 여부 (빈 문자열 체크)
- 형식 검사 (이메일, 비밀번호 길이 등)
- 일치 여부 (비밀번호 확인 등)

## 6. 실습

### 실습 1. 회원가입 폼 만들기
1. 이름, 이메일, 비밀번호, 비밀번호 확인 입력 필드를 제어 컴포넌트로 작성
2. 제출 시 다음 항목을 검사
   - 모든 필드가 입력되었는지
   - 이메일에 `@`가 포함되어 있는지
   - 비밀번호와 비밀번호 확인이 일치하는지
3. 검사를 통과하면 "가입 완료" 메시지를, 실패하면 에러 메시지를 화면에 표시

### 실습 2. 투두리스트 만들기
1. 입력창과 추가 버튼으로 새로운 항목을 추가할 수 있도록 구현
2. 항목 목록을 state(배열)로 관리하고 화면에 렌더링
3. 각 항목에 "완료" 체크박스를 추가해 완료 여부를 토글
4. 각 항목에 "삭제" 버튼을 추가해 목록에서 제거
5. (선택) 완료된 항목은 글자에 취소선 스타일 적용
