# 2일차: 컴포넌트와 Props

## 학습 목표
- Props의 개념을 이해하고 부모-자식 컴포넌트 간 데이터를 전달할 수 있다.
- children, 기본값, 객체 형태의 props 등 다양한 props 활용 패턴을 사용할 수 있다.
- 재사용 가능한 컴포넌트를 설계하고 분리할 수 있다.
- 카드/리스트 형태의 UI 컴포넌트를 직접 구현할 수 있다.

---

## 1. Props 개념

### 1.1 Props란?
- 컴포넌트에 전달하는 데이터 (Properties의 줄임말)
- 부모 컴포넌트 → 자식 컴포넌트로 단방향 전달
- 함수의 매개변수와 유사한 개념: 같은 컴포넌트라도 props에 따라 다른 화면을 그릴 수 있음

### 1.2 Props 전달과 사용

```jsx
// Greeting.jsx
function Greeting(props) {
  return <h2>안녕하세요, {props.name}님!</h2>;
}

export default Greeting;
```

```jsx
// App.jsx
import Greeting from './Greeting';

function App() {
  return (
    <div>
      <Greeting name="홍길동" />
      <Greeting name="김영희" />
    </div>
  );
}
```

### 1.3 구조 분해 할당(Destructuring)으로 props 받기

```jsx
function Greeting({ name }) {
  return <h2>안녕하세요, {name}님!</h2>;
}
```

### 1.4 Props는 읽기 전용
- 자식 컴포넌트는 전달받은 props를 직접 변경할 수 없음 (단방향 데이터 흐름)
- props 값을 바꾸고 싶다면 부모 컴포넌트의 상태(state)를 변경해야 함 (3일차에서 다룰 내용)

## 2. Props 활용 패턴

### 2.1 기본값 설정 (Default Props)

```jsx
function Greeting({ name = '손님' }) {
  return <h2>안녕하세요, {name}님!</h2>;
}
```

### 2.2 여러 종류의 props 전달

```jsx
function UserCard({ name, age, isAdmin }) {
  return (
    <div className="user-card">
      <p>이름: {name}</p>
      <p>나이: {age}</p>
      {isAdmin && <span className="badge">관리자</span>}
    </div>
  );
}
```

```jsx
<UserCard name="홍길동" age={28} isAdmin={true} />
<UserCard name="김영희" age={25} isAdmin={false} />
```

### 2.3 객체/배열을 props로 전달

```jsx
const user = { name: '홍길동', age: 28 };

function App() {
  return <UserCard user={user} />;
}

function UserCard({ user }) {
  return (
    <div>
      <p>이름: {user.name}</p>
      <p>나이: {user.age}</p>
    </div>
  );
}
```

### 2.4 children props
- 컴포넌트 태그 사이에 작성한 내용을 `props.children`으로 전달받음
- 레이아웃, 박스, 버튼 등 "내용을 감싸는" 컴포넌트를 만들 때 유용

```jsx
function Card({ children }) {
  return <div className="card">{children}</div>;
}

function App() {
  return (
    <Card>
      <h3>제목</h3>
      <p>카드 내용입니다.</p>
    </Card>
  );
}
```

## 3. 컴포넌트 재사용 설계

### 3.1 재사용 가능한 컴포넌트의 특징
- 하나의 역할만 담당 (단일 책임)
- 데이터(props)에 따라 다양한 형태로 표현 가능
- 스타일과 동작이 일관됨

### 3.2 설계 연습: 동일한 데이터를 여러 컴포넌트로 표현하기
- 같은 사용자 목록 데이터를 가지고
  - 리스트 형태 (`UserListItem`)
  - 카드 형태 (`UserCard`)
  로 각각 표현 가능하도록 컴포넌트를 설계

### 3.3 배열 데이터를 컴포넌트로 렌더링하기 (간단 소개)
- 추후(4일차)에 `map()`을 본격적으로 다루지만, 오늘은 간단한 형태로 미리 경험

```jsx
const users = [
  { id: 1, name: '홍길동', age: 28 },
  { id: 2, name: '김영희', age: 25 },
];

function App() {
  return (
    <div>
      {users.map((user) => (
        <UserCard key={user.id} name={user.name} age={user.age} />
      ))}
    </div>
  );
}
```

## 4. 실습: 카드/리스트 컴포넌트 제작

### 실습 1. UserCard 컴포넌트 만들기
1. `name`, `age`, `job`, `isAdmin` props를 받는 `UserCard` 컴포넌트 작성
2. `isAdmin`이 `true`일 때만 "관리자" 배지를 표시
3. 3명 이상의 사용자 데이터를 가지고 여러 개의 `UserCard`를 화면에 렌더링

### 실습 2. ProductList 컴포넌트 만들기
1. 상품 데이터(이름, 가격, 이미지 자리, 재고 여부)를 배열로 준비
2. `ProductCard` 컴포넌트를 만들어 상품 1개 정보를 표시
3. 재고가 없는 경우(`inStock: false`) "품절" 표시
4. `ProductList` 컴포넌트에서 배열을 순회하며 `ProductCard`를 렌더링

### 실습 3. (선택) Card 공통 컴포넌트로 리팩토링
1. `children`을 활용한 공통 `Card` 컴포넌트 작성
2. `UserCard`, `ProductCard`를 `Card` 컴포넌트로 감싸서 공통 스타일 적용
