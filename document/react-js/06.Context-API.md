# 6일차: 전역 상태관리 + 데이터 시각화

## 학습 목표
- Context API를 이용해 여러 컴포넌트에서 상태를 공유할 수 있다.
- Recharts를 이용해 데이터를 차트로 시각화할 수 있다.
- 데이터를 필터/정렬/집계하여 화면에 표현할 수 있다.
- Context로 공유되는 필터 상태에 따라 차트가 갱신되는 화면을 구현할 수 있다.

---

## 1. 전역 상태관리가 필요한 이유

### 1.1 Props Drilling 문제
- 부모 → 자식 → 손자 ... 여러 단계를 거쳐 props를 전달해야 하는 상황
- 중간 컴포넌트는 해당 데이터를 사용하지 않아도 단순히 전달만 해야 함 → 코드가 복잡해짐

```jsx
// Props Drilling 예시
function App() {
  const user = { name: '홍길동' };
  return <Page user={user} />;
}

function Page({ user }) {
  return <Sidebar user={user} />;
}

function Sidebar({ user }) {
  return <UserMenu user={user} />;
}

function UserMenu({ user }) {
  return <p>{user.name}님</p>;
}
```

### 1.2 Context API로 해결
- 컴포넌트 트리의 특정 범위 내에서 데이터를 "전역"처럼 공유할 수 있는 React 내장 기능
- 중간 컴포넌트를 거치지 않고 필요한 컴포넌트에서 바로 값을 꺼내 사용 가능

## 2. Context API 기본 사용법

### 2.1 Context 생성

```jsx
// contexts/UserContext.js
import { createContext } from 'react';

export const UserContext = createContext(null);
```

### 2.2 Provider로 값 제공

```jsx
import { UserContext } from './contexts/UserContext';

function App() {
  const user = { name: '홍길동' };

  return (
    <UserContext.Provider value={user}>
      <Page />
    </UserContext.Provider>
  );
}
```

### 2.3 useContext로 값 사용

```jsx
import { useContext } from 'react';
import { UserContext } from './contexts/UserContext';

function UserMenu() {
  const user = useContext(UserContext);
  return <p>{user.name}님</p>;
}
```

### 2.4 상태와 함께 사용하기 (Context + useState)

```jsx
// contexts/FilterContext.js
import { createContext, useState } from 'react';

export const FilterContext = createContext(null);

export function FilterProvider({ children }) {
  const [category, setCategory] = useState('all');

  return (
    <FilterContext.Provider value={{ category, setCategory }}>
      {children}
    </FilterContext.Provider>
  );
}
```

```jsx
// main.jsx 또는 App.jsx
import { FilterProvider } from './contexts/FilterContext';

function App() {
  return (
    <FilterProvider>
      <FilterBar />
      <Dashboard />
    </FilterProvider>
  );
}
```

```jsx
// FilterBar.jsx
import { useContext } from 'react';
import { FilterContext } from './contexts/FilterContext';

function FilterBar() {
  const { category, setCategory } = useContext(FilterContext);

  return (
    <select value={category} onChange={(e) => setCategory(e.target.value)}>
      <option value="all">전체</option>
      <option value="electronics">전자제품</option>
      <option value="food">식품</option>
    </select>
  );
}
```

```jsx
// Dashboard.jsx
import { useContext } from 'react';
import { FilterContext } from './contexts/FilterContext';

function Dashboard() {
  const { category } = useContext(FilterContext);
  return <p>현재 선택된 카테고리: {category}</p>;
}
```

### 2.5 Context 사용 시 주의점
- Context 값이 바뀌면 해당 Context를 구독하는 모든 컴포넌트가 다시 렌더링됨
- 전역으로 자주 바뀌지 않는 값(로그인 정보, 테마, 필터 조건 등)에 적합
- 모든 상태를 Context로 옮길 필요는 없음 (컴포넌트 내부에서만 쓰이는 상태는 useState로 충분)

## 3. 데이터 시각화 (Recharts)

### 3.1 Recharts 설치

```bash
npm install recharts
```

### 3.2 막대 그래프(BarChart) 예시

```jsx
import {
  BarChart, Bar, XAxis, YAxis, Tooltip, CartesianGrid, ResponsiveContainer,
} from 'recharts';

const data = [
  { name: '1월', sales: 400 },
  { name: '2월', sales: 300 },
  { name: '3월', sales: 600 },
];

function SalesChart() {
  return (
    <ResponsiveContainer width="100%" height={300}>
      <BarChart data={data}>
        <CartesianGrid strokeDasharray="3 3" />
        <XAxis dataKey="name" />
        <YAxis />
        <Tooltip />
        <Bar dataKey="sales" fill="#1565c0" />
      </BarChart>
    </ResponsiveContainer>
  );
}
```

### 3.3 선 그래프(LineChart) 예시

```jsx
import {
  LineChart, Line, XAxis, YAxis, Tooltip, CartesianGrid, ResponsiveContainer,
} from 'recharts';

function TrendChart({ data }) {
  return (
    <ResponsiveContainer width="100%" height={300}>
      <LineChart data={data}>
        <CartesianGrid strokeDasharray="3 3" />
        <XAxis dataKey="name" />
        <YAxis />
        <Tooltip />
        <Line type="monotone" dataKey="value" stroke="#2e7d32" />
      </LineChart>
    </ResponsiveContainer>
  );
}
```

### 3.4 파이 차트(PieChart) 예시

```jsx
import { PieChart, Pie, Cell, Tooltip, ResponsiveContainer } from 'recharts';

const data = [
  { name: '전자제품', value: 400 },
  { name: '식품', value: 300 },
  { name: '의류', value: 300 },
];

const COLORS = ['#1565c0', '#2e7d32', '#f9a825'];

function CategoryPieChart() {
  return (
    <ResponsiveContainer width="100%" height={300}>
      <PieChart>
        <Pie data={data} dataKey="value" nameKey="name" outerRadius={100} label>
          {data.map((entry, index) => (
            <Cell key={entry.name} fill={COLORS[index % COLORS.length]} />
          ))}
        </Pie>
        <Tooltip />
      </PieChart>
    </ResponsiveContainer>
  );
}
```

## 4. 데이터 가공 (필터/정렬/집계)

### 4.1 필터링

```jsx
const filtered = products.filter((p) => p.category === selectedCategory);
```

### 4.2 정렬

```jsx
const sorted = [...products].sort((a, b) => a.price - b.price);
```

### 4.3 집계 (카테고리별 합계 계산)

```jsx
function aggregateByCategory(products) {
  const result = {};

  products.forEach((p) => {
    if (!result[p.category]) {
      result[p.category] = 0;
    }
    result[p.category] += p.price;
  });

  // [{ name: '전자제품', value: 12000 }, ...] 형태로 변환
  return Object.entries(result).map(([name, value]) => ({ name, value }));
}
```

### 4.4 필터 + 가공 + 차트 연결 흐름
1. 원본 데이터(배열) 준비
2. Context의 필터 상태에 따라 데이터 필터링
3. 필터링된 데이터를 차트가 요구하는 형태로 가공
4. 가공된 데이터를 차트 컴포넌트에 전달

## 5. 실습: Context로 공유되는 필터 상태 + 차트 렌더링

### 실습 1. 카테고리 필터 Context 구성
1. `FilterContext`를 생성하고 선택된 카테고리(`category`) 상태를 관리
2. `FilterProvider`로 앱 전체를 감싸기
3. 카테고리를 선택할 수 있는 `FilterBar` 컴포넌트 작성 (전체/전자제품/식품/의류 등)

### 실습 2. 데이터 대시보드 화면 구현
1. 샘플 상품/매출 데이터(배열) 준비 (`category`, `price` 등의 필드 포함)
2. Context의 `category` 값에 따라 데이터를 필터링
3. 필터링된 데이터를 다음 두 가지로 시각화
   - 카테고리별 합계를 보여주는 막대 그래프 또는 파이 차트
   - 항목별 가격을 보여주는 리스트 또는 표
4. `FilterBar`에서 카테고리를 변경하면 차트와 목록이 함께 갱신되는지 확인
