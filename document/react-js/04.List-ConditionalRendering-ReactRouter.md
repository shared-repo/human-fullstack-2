# 4일차: 리스트/조건부 렌더링 + React Router

## 학습 목표
- 배열 데이터를 `map()`을 이용해 리스트로 렌더링할 수 있다.
- `key`의 역할과 올바른 사용법을 이해한다.
- 다양한 조건부 렌더링 방식을 사용할 수 있다.
- React Router를 이용해 다중 페이지(목록/상세)를 구성할 수 있다.

## 1. 리스트 렌더링

### 1.1 map()을 이용한 렌더링
- 배열의 각 항목을 JSX 요소로 변환하여 화면에 표시

```jsx
const fruits = ['사과', '바나나', '포도'];

function FruitList() {
  return (
    <ul>
      {fruits.map((fruit) => (
        <li key={fruit}>{fruit}</li>
      ))}
    </ul>
  );
}
```

### 1.2 key의 역할
- React가 각 항목을 구분하고, 변경된 항목만 효율적으로 업데이트하기 위한 식별자
- 가능한 경우 데이터의 고유 id를 사용 (배열의 인덱스는 항목 추가/삭제/순서 변경 시 문제가 될 수 있음)

```jsx
const users = [
  { id: 1, name: '홍길동' },
  { id: 2, name: '김영희' },
];

function UserList() {
  return (
    <ul>
      {users.map((user) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

### 1.3 객체 배열 + 컴포넌트 조합
- 데이터를 컴포넌트에 props로 전달하여 리스트 렌더링 (2일차 내용 복습 + 심화)

```jsx
function UserListItem({ name, age }) {
  return <li>{name} ({age}세)</li>;
}

function UserList({ users }) {
  return (
    <ul>
      {users.map((user) => (
        <UserListItem key={user.id} name={user.name} age={user.age} />
      ))}
    </ul>
  );
}
```

## 2. 조건부 렌더링

### 2.1 if문을 이용한 분기
- 컴포넌트 함수 안에서 조건에 따라 다른 JSX를 반환

```jsx
function Greeting({ isLoggedIn }) {
  if (isLoggedIn) {
    return <p>환영합니다!</p>;
  }
  return <p>로그인이 필요합니다.</p>;
}
```

### 2.2 삼항 연산자
- JSX 내부에서 간단한 분기를 표현할 때 사용

```jsx
function Status({ isOnline }) {
  return <p>상태: {isOnline ? '온라인' : '오프라인'}</p>;
}
```

### 2.3 && 연산자
- 조건이 true일 때만 요소를 표시하고, false일 때는 아무것도 표시하지 않음

```jsx
function Notification({ count }) {
  return (
    <div>
      <h3>알림</h3>
      {count > 0 && <p>{count}개의 새 알림이 있습니다.</p>}
    </div>
  );
}
```

### 2.4 빈 배열/데이터 없음 처리
- 리스트가 비어 있을 때 사용자에게 안내 메시지를 보여주는 패턴

```jsx
function ProductList({ products }) {
  if (products.length === 0) {
    return <p>등록된 상품이 없습니다.</p>;
  }

  return (
    <ul>
      {products.map((p) => (
        <li key={p.id}>{p.name}</li>
      ))}
    </ul>
  );
}
```

## 3. React Router

### 3.1 React Router란?
- SPA에서 URL에 따라 다른 컴포넌트(페이지)를 보여줄 수 있도록 해주는 라이브러리
- 페이지 전체를 새로고침하지 않고 화면을 전환

### 3.2 설치 및 기본 설정

```bash
npm install react-router-dom
```

```jsx
// main.jsx
import { BrowserRouter } from 'react-router-dom';

ReactDOM.createRoot(document.getElementById('root')).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>
);
```

### 3.3 라우트 설정

```jsx
// App.jsx
import { Routes, Route } from 'react-router-dom';
import Home from './pages/Home';
import ProductList from './pages/ProductList';
import ProductDetail from './pages/ProductDetail';

function App() {
  return (
    <Routes>
      <Route path="/" element={<Home />} />
      <Route path="/products" element={<ProductList />} />
      <Route path="/products/:id" element={<ProductDetail />} />
    </Routes>
  );
}
```

### 3.4 페이지 이동 - Link

```jsx
import { Link } from 'react-router-dom';

function Home() {
  return (
    <div>
      <h1>홈</h1>
      <Link to="/products">상품 목록 보기</Link>
    </div>
  );
}
```

### 3.5 동적 라우트와 useParams

```jsx
import { useParams } from 'react-router-dom';

function ProductDetail() {
  const { id } = useParams();
  return <h2>상품 상세 - ID: {id}</h2>;
}
```

### 3.6 useNavigate를 이용한 코드 기반 이동

```jsx
import { useNavigate } from 'react-router-dom';

function ProductListItem({ id, name }) {
  const navigate = useNavigate();

  return (
    <li onClick={() => navigate(`/products/${id}`)}>
      {name}
    </li>
  );
}
```

## 4. 실습: 다중 페이지(목록/상세) 구현

### 실습 1. 상품 목록 / 상세 페이지
1. `react-router-dom`을 설치하고 라우터 설정
2. 페이지 구성
   - `/` : 홈 페이지 (간단한 소개 + 상품 목록으로 이동 링크)
   - `/products` : 상품 목록 페이지 (2일차/3일차에서 사용한 상품 데이터 활용)
   - `/products/:id` : 상품 상세 페이지
3. 상품 목록에서 항목 클릭 시 해당 상품의 상세 페이지로 이동
4. 상세 페이지에서 `useParams`로 id를 받아와 해당 상품 정보를 표시
5. 상품이 존재하지 않는 id로 접근 시 "상품을 찾을 수 없습니다" 메시지 표시 (조건부 렌더링 활용)

### 실습 2. (선택) 네비게이션 바 추가
1. 모든 페이지에서 공통으로 보이는 네비게이션 바(`Nav`) 컴포넌트 작성
2. `Link`를 이용해 홈/상품 목록 이동 메뉴 구성
3. 현재 위치한 경로에 따라 메뉴 항목을 강조 표시 (선택, `useLocation` 활용)
