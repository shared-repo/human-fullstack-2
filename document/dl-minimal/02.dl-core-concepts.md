## 1. 뉴럴 네트워크 구조 상세

### 뉴런(Neuron) 하나가 하는 일

뉴런은 단순히 **가중합(weighted sum) + 활성화** 를 수행합니다.

```
입력값들        가중치         편향       활성화 함수
[x1, x2, x3] × [w1, w2, w3] + b  →  activation(z)  →  출력 a
```

수식으로 표현하면:

```
z = w1·x1 + w2·x2 + w3·x3 + b    # 선형 결합 (가중합 + 편향)
a = activation(z)                  # 비선형 변환 → 이것이 "딥"의 핵심
```

**Spring Boot 개발자 관점:** `z`는 일종의 점수(score)고, `activation(z)`는 그 점수를 모델이 다음 층으로 넘길 형태로 변환하는 후처리입니다.

### 층(Layer)의 역할

| 층 | 역할 | 비유 |
|----|------|------|
| **입력층** | 원시 데이터를 받는 창구 | HTTP Request |
| **은닉층** | 패턴을 단계적으로 추출 | 서비스 레이어 체인 |
| **출력층** | 최종 예측값 생성 | HTTP Response |

- 은닉층이 **1개** 이상이면 "딥" 러닝이라 부릅니다.
- 층이 깊어질수록 더 **추상적인** 패턴을 학습합니다.  
  (이미지라면: 픽셀 → 엣지 → 형태 → 얼굴)

### 가중치(Weight)와 편향(Bias)의 의미

```python
# PyTorch에서 Linear(3, 2)가 내부적으로 가지는 구조
# 입력 3개 → 출력 2개

# weight 행렬: (2, 3) 크기
# [[w11, w12, w13],    # 뉴런 1번이 각 입력에 부여하는 중요도
#  [w21, w22, w23]]   # 뉴런 2번이 각 입력에 부여하는 중요도

# bias 벡터: (2,) 크기
# [b1, b2]            # 각 뉴런의 기본 활성화 임계값 조정

layer = nn.Linear(3, 2)
print(layer.weight.shape)  # torch.Size([2, 3])
print(layer.bias.shape)    # torch.Size([2])
```

**직관:** 가중치는 "이 입력이 얼마나 중요한가?", 편향은 "아무 입력 없어도 얼마나 활성화될 것인가?"를 나타냅니다.

## 2. 활성화 함수 심화

### 왜 활성화 함수가 필요한가?

활성화 함수 없이 층을 아무리 쌓아도 결국 하나의 선형 변환과 동일합니다.

```python
# 활성화 없는 2층 네트워크
# z1 = W1·x + b1
# z2 = W2·z1 + b2 = W2·(W1·x + b1) + b2 = (W2·W1)·x + (W2·b1 + b2)
# → 결국 Wx + b 형태 (1층과 동일!)
```

비선형 활성화 함수를 추가하면 층을 쌓을수록 표현력이 기하급수적으로 증가합니다.

### ReLU (Rectified Linear Unit) — 은닉층의 기본값

```
ReLU(x) = max(0, x)
```

```
출력
 │     /
 │    /
 │   /
 │  /
─┼─────────── 입력
 0
```

**왜 ReLU를 기본값으로 쓰는가?**

1. **계산이 빠름:** 단순 비교 연산 (양수면 그대로, 음수면 0)
2. **기울기 소실 문제 완화:** 양수 구간에서 기울기가 항상 1
3. **희소 활성화:** 절반의 뉴런만 활성화 → 효율적 학습

**단점:** 음수 입력에서 기울기가 0 → 해당 뉴런이 영구적으로 죽는 "dying ReLU" 문제
→ 해결책: `LeakyReLU`, `ELU` 등

```python
# ReLU 변종 비교
x = torch.tensor([-2.0, -1.0, 0.0, 1.0, 2.0])

print(nn.ReLU()(x))           # [0, 0, 0, 1, 2]
print(nn.LeakyReLU(0.01)(x)) # [-0.02, -0.01, 0, 1, 2]  음수 구간 소량 허용
print(nn.ELU()(x))            # [-0.865, -0.632, 0, 1, 2] 부드러운 음수 처리
```

### Sigmoid — 이진 분류 출력층

```
Sigmoid(x) = 1 / (1 + e^(-x))   →   출력 범위: (0, 1)
```

- **0.5 기준으로 클래스 구분:** 0.5 이상이면 클래스 1, 미만이면 클래스 0
- 은닉층에서는 사용 비권장 → 기울기 소실(Vanishing Gradient) 문제

```python
x = torch.tensor([-3.0, -1.0, 0.0, 1.0, 3.0])
print(nn.Sigmoid()(x))
# tensor([0.0474, 0.2689, 0.5000, 0.7311, 0.9526])
# 극단값에서 기울기가 0에 가까워짐 → 기울기 소실
```

### Softmax — 다중 분류 출력층

```
Softmax(xi) = e^xi / Σ(e^xj)    →   출력 합 = 1.0 (확률 분포)
```

```python
# 3개 클래스 분류 예시
logits = torch.tensor([2.0, 1.0, 0.5])  # 모델의 날 것 점수
probs  = nn.Softmax(dim=0)(logits)
print(probs)   # tensor([0.6590, 0.2424, 0.0986]) — 합계 = 1.0
# → 클래스 0일 확률 65.9%, 클래스 1은 24.2%, 클래스 2는 9.9%
```

> **주의:** PyTorch의 `CrossEntropyLoss`는 내부적으로 Softmax를 포함하므로, 이를 사용할 때 출력층에 Softmax를 직접 붙이지 않습니다.

### Tanh — RNN 계열

```
Tanh(x) = (e^x - e^-x) / (e^x + e^-x)   →   출력 범위: (-1, 1)
```

- Sigmoid보다 출력이 0 중심(zero-centered) → 학습 안정성 개선
- LSTM, GRU 등 RNN 계열에서 주로 사용

## 3. 순전파 / 역전파 상세

### 순전파(Forward Pass)

입력 데이터가 층을 통과하며 예측값이 생성되는 과정입니다.

```python
# 2층 네트워크의 순전파 수동 계산
x  = torch.tensor([1.0, 2.0, 3.0])   # 입력

W1 = torch.randn(4, 3)               # 은닉층 가중치 (4뉴런, 입력3)
b1 = torch.zeros(4)
z1 = W1 @ x + b1                     # 선형 변환
a1 = torch.relu(z1)                  # 활성화

W2 = torch.randn(1, 4)               # 출력층 가중치 (출력1, 입력4)
b2 = torch.zeros(1)
z2 = W2 @ a1 + b2                    # 선형 변환
a2 = torch.sigmoid(z2)               # 이진 분류 → Sigmoid
# a2가 최종 예측값 (0~1 사이 확률)
```

### 손실(Loss) 계산

예측값과 실제 정답의 차이를 **하나의 숫자**로 요약합니다.

```python
y_pred = torch.tensor([0.8])   # 모델 예측: 80% 확률로 생존
y_true = torch.tensor([1.0])   # 실제 정답: 생존(1)

# BCE Loss 수동 계산
loss = -(y_true * torch.log(y_pred) + (1 - y_true) * torch.log(1 - y_pred))
print(f"손실: {loss.item():.4f}")   # 작을수록 예측이 정확

# PyTorch 사용
loss_fn = nn.BCELoss()
print(f"손실(PyTorch): {loss_fn(y_pred, y_true).item():.4f}")
```

### 역전파(Backward Pass)와 기울기(Gradient)

역전파는 **"손실이 각 가중치로 인해 얼마나 발생했는가"** 를 계산합니다.

```
기울기(gradient) = ∂Loss / ∂w   (각 가중치에 대한 손실의 편미분)
```

```python
# PyTorch의 자동미분이 이를 자동으로 계산
w = torch.tensor(2.0, requires_grad=True)
loss = (w * 3 - 6) ** 2        # Loss = (3w - 6)²

loss.backward()                 # 역전파 실행
print(f"w에 대한 기울기: {w.grad}")
# dLoss/dw = 2(3w - 6) × 3 = 6(3×2 - 6) = 0.0  ← w=2가 이미 최적
```

**기울기의 의미:**
- **기울기 양수:** 가중치를 늘리면 손실이 커진다 → 가중치를 줄여야 함
- **기울기 음수:** 가중치를 늘리면 손실이 작아진다 → 가중치를 늘려야 함
- **기울기 = 0:** 현재 위치가 극값 → 업데이트 없음

## 4. 손실함수 심화

### 회귀 손실: MSELoss

```
MSE = (1/n) × Σ(ŷi - yi)²
```

```python
# 집값 예측 예시
y_pred = torch.tensor([250.0, 300.0, 180.0])  # 만 달러 단위
y_true = torch.tensor([240.0, 310.0, 200.0])

mse = nn.MSELoss()
print(f"MSE Loss: {mse(y_pred, y_true):.2f}")
# 이상치에 민감 (제곱이므로 큰 오차가 더 크게 반영됨)
```

**MAELoss(L1Loss)와 비교:**

| | MSELoss | MAELoss |
|--|---------|---------|
| 수식 | Σ(ŷ-y)² | Σ|ŷ-y| |
| 이상치 민감도 | 높음 | 낮음 |
| 기울기 | 부드러움 | 불연속점 존재 |
| 사용 시점 | 이상치가 적을 때 | 이상치가 많을 때 |

### 분류 손실: CrossEntropyLoss

```python
# 3개 클래스 분류 (개/고양이/새)
logits = torch.tensor([[2.0, 0.5, -1.0],   # 샘플 1: 개일 가능성 높음
                        [0.1, 2.5,  0.3]])  # 샘플 2: 고양이일 가능성 높음
labels = torch.tensor([0, 1])               # 정답: 개, 고양이

ce_loss = nn.CrossEntropyLoss()
print(f"CE Loss: {ce_loss(logits, labels):.4f}")
# 내부적으로 Softmax → log → NLLLoss 적용
```

### 왜 분류에 MSE 대신 CrossEntropy를 쓰는가?

```python
import torch
import torch.nn as nn

# 시나리오: 정답=1인 이진 분류, 예측이 0.5에서 시작
y_true = torch.tensor([1.0])

# 잘못된 예측 (0.1)과 좋은 예측 (0.9)의 기울기 비교
for pred in [0.1, 0.5, 0.9]:
    y_pred = torch.tensor([pred], requires_grad=True)
    loss = nn.BCELoss()(y_pred, y_true)
    loss.backward()
    print(f"예측={pred:.1f} | Loss={loss.item():.4f} | 기울기={y_pred.grad.item():.4f}")

# 예측=0.1 → Loss 크고 기울기도 큼 → 빠르게 수정
# 예측=0.9 → Loss 작고 기울기도 작음 → 미세 조정
# → MSE보다 더 직관적이고 학습 안정적
```

## 5. 옵티마이저 심화

### 경사하강법(Gradient Descent) 기본 원리

```
새로운 가중치 = 현재 가중치 - 학습률 × 기울기
w ← w - lr × ∂Loss/∂w
```

**직관:** 산에서 내려갈 때 경사가 급한 방향으로 조금씩 내려가는 것과 같습니다.
- `lr`(학습률): 한 번에 얼마나 내려갈지 (너무 크면 발산, 너무 작으면 느림)

### SGD (Stochastic Gradient Descent)

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
# 매 배치마다 기울기 계산 → 업데이트
# 노이즈가 많지만 오히려 지역 최솟값(local minima) 탈출에 유리
```

**모멘텀(Momentum) 추가:**

```python
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
# 이전 업데이트 방향을 90% 유지하며 관성 적용
# → 진동 감소 + 수렴 속도 향상
```

### Adam (Adaptive Moment Estimation) — 대부분의 경우 기본 선택

```python
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
# lr을 각 가중치마다 자동으로 조절
# 자주 업데이트되는 가중치 → 학습률 낮춤
# 드물게 업데이트되는 가중치 → 학습률 높임
```

**Adam의 두 가지 비밀:**
1. **1차 모멘트(m):** 기울기의 이동 평균 → 방향 기억
2. **2차 모멘트(v):** 기울기 제곱의 이동 평균 → 각 매개변수별 학습률 조절

```
m = β1·m + (1-β1)·g          # β1 = 0.9
v = β2·v + (1-β2)·g²         # β2 = 0.999
w ← w - lr·m / (√v + ε)      # ε = 1e-8 (0 나눗셈 방지)
```

### AdamW — 트랜스포머 계열

```python
optimizer = torch.optim.AdamW(model.parameters(), lr=0.001, weight_decay=0.01)
# Adam + Weight Decay를 올바르게 분리
# L2 정규화를 기울기 업데이트에서 분리해 적용 → 일반화 성능 개선
```

### 학습률(Learning Rate)의 중요성

```python
import matplotlib.pyplot as plt

# 학습률에 따른 수렴 양상 시각화 개념
"""
lr 너무 작음  →  ────────────────── (아주 천천히 수렴)
lr 적당함    →  ────╮ (빠르게 수렴)
lr 너무 큼   →  ╭──╯╭──╯╭──╯ (발산/진동)
"""

# 학습률 스케줄러: 에폭이 진행될수록 학습률 감소
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.5)
# → 30 에폭마다 학습률을 절반으로 줄임
# 처음엔 빠르게 학습, 나중엔 세밀하게 조정
```

## 6. 과적합(Overfitting)과 규제화

### 과적합이란?

```
훈련 데이터를 너무 잘 외워버려서 새로운 데이터에는 성능이 떨어지는 현상

훈련 손실  ↓↓↓   (계속 감소)
검증 손실  ↓ 그리다 ↑   (어느 순간부터 증가)  ← 과적합 시작점
```

### 드롭아웃(Dropout)

훈련 중 무작위로 일부 뉴런을 비활성화합니다.

```python
# Dropout(0.3) → 30% 뉴런을 무작위로 0으로 만듦
layer = nn.Dropout(p=0.3)

x = torch.ones(1, 5)
print("훈련 모드:", layer(x))   # 일부가 0으로 변경됨
layer.eval()
print("평가 모드:", layer(x))   # 모든 값 유지 (but 0.7 스케일 조정 없음)
```

**직관:** 팀원 중 일부가 무작위로 빠져도 성과를 내야 하도록 훈련 → 각 뉴런이 독립적으로 유용한 정보를 학습

```python
model.train()  # Dropout 활성화 → 훈련 시
model.eval()   # Dropout 비활성화 → 평가/추론 시
# 이 두 줄의 차이를 반드시 지켜야 합니다!
```

### 가중치 감쇠(Weight Decay / L2 정규화)

```python
# 가중치가 너무 커지는 것을 억제
optimizer = torch.optim.Adam(model.parameters(), lr=0.001, weight_decay=1e-4)
# 손실함수에 λ × Σw² 항목 추가 → 가중치를 0 쪽으로 당기는 효과
```

### 배치 정규화(Batch Normalization)

각 배치의 활성화 값을 정규화하여 학습을 안정화합니다.

```python
class BNModel(nn.Module):
    def __init__(self, input_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, 64),
            nn.BatchNorm1d(64),    # ← 정규화: 평균 0, 표준편차 1로 조정
            nn.ReLU(),
            nn.Linear(64, 32),
            nn.BatchNorm1d(32),
            nn.ReLU(),
            nn.Linear(32, 1),
            nn.Sigmoid()
        )
    def forward(self, x): return self.net(x)

# 장점: 학습률에 덜 민감, 수렴 빠름, 과적합 감소 효과
# 주의: batch_size가 1이면 BN 사용 불가 → 그럴 땐 LayerNorm
```

## 7. 하이퍼파라미터 가이드

하이퍼파라미터는 훈련 전에 사람이 설정하는 값으로, 모델 학습으로 결정되지 않습니다.

| 하이퍼파라미터 | 역할 | 첫 시도 권장값 |
|--------------|------|-------------|
| `lr` (학습률) | 업데이트 보폭 | `1e-3` (Adam 기준) |
| `batch_size` | 한 번에 처리할 샘플 수 | `32` 또는 `64` |
| `epochs` | 전체 데이터 반복 횟수 | `50~100` + Early Stopping |
| `hidden_dim` | 은닉층 뉴런 수 | `64~256` |
| `dropout` | 드롭아웃 비율 | `0.2~0.5` |
| `weight_decay` | L2 정규화 강도 | `1e-4~1e-3` |

### 배치 크기(Batch Size)의 트레이드오프

```python
# 작은 배치 (8~16)
# 장점: 노이즈가 많아 지역 최솟값 탈출, 메모리 절약
# 단점: 학습 속도 느림, 불안정

# 큰 배치 (256~1024)
# 장점: 학습 속도 빠름, 안정적
# 단점: 메모리 많이 필요, 날카로운 최솟값(sharp minima)에 빠질 위험

# 실전 공식: GPU 메모리가 허용하는 범위에서 2의 제곱수 선택
# (16, 32, 64, 128, 256 …)
BATCH_SIZE = 32  # 대부분의 경우 안전한 시작점
```

## 8. 전체 흐름 다시 보기

```
데이터
  │
  ▼
[입력층]  ──→  원시 피처를 받음
  │
  ▼  (W·x + b → ReLU)
[은닉층1] ──→  저수준 패턴 추출  (예: 단순 선형 경계)
  │
  ▼  (W·x + b → ReLU + Dropout)
[은닉층2] ──→  중간 수준 패턴 결합  (예: 여러 조건 조합)
  │
  ▼  (W·x + b → Sigmoid/Softmax)
[출력층]  ──→  최종 예측 확률
  │
  ▼
손실 계산 (BCELoss / CrossEntropyLoss / MSELoss)
  │
  ▼
역전파 → 기울기 계산 (autograd)
  │
  ▼
옵티마이저 → 가중치 업데이트 (Adam: lr × 기울기 / √분산)
  │
  └──→ 다시 순전파 … (에폭 반복)
```

**핵심 공식 3개만 기억하기:**

```
순전파:    a = activation(W·x + b)
손실:      L = 예측과 정답의 차이 (BCE/CE/MSE)
업데이트:  w ← w - lr × ∂L/∂w
```

> 딥러닝 훈련의 본질은 이 세 줄의 반복입니다.
