## 3-1. CNN 구조 이해

### Convolution 연산 — 직관적 이해

CNN은 이미지에서 **패턴(엣지, 텍스처, 형태)을 자동으로 추출**한다.
필터(커널)가 이미지 위를 슬라이딩하며 특징을 감지한다.

```
원본 이미지 (28×28)
       ↓ Conv 3×3 필터 32개
특징 맵 (26×26×32)   ← 엣지, 선 등 저수준 특징 감지
       ↓ Conv 3×3 필터 64개
특징 맵 (24×24×64)   ← 모서리, 곡선 등 중수준 특징 감지
       ↓ MaxPool 2×2
특징 맵 (12×12×64)   ← 공간 크기 절반으로 축소
       ↓ Flatten → Fully Connected
클래스 확률 (10)      ← 최종 분류
```

### 핵심 레이어 정리

| 레이어 | 역할 | 주요 파라미터 |
|--------|------|--------------|
| `Conv2d` | 특징 맵 추출 | `in_channels`, `out_channels`, `kernel_size` |
| `MaxPool2d` | 공간 크기 축소, 주요 특징 보존 | `kernel_size=2, stride=2` |
| `BatchNorm2d` | 학습 안정화, 수렴 속도 향상 | `num_features` |
| `Flatten` | 3D 특징 맵 → 1D 벡터 변환 | — |
| `Linear` | 최종 분류 | `in_features`, `out_features` |

### 출력 크기 계산 공식

```
출력 크기 = (입력 크기 - 커널 크기 + 2 × 패딩) / 스트라이드 + 1

예시: 입력 28×28, Conv(kernel=3, padding=0, stride=1)
→ (28 - 3 + 0) / 1 + 1 = 26 × 26
```

```python
import torch
import torch.nn as nn

# 레이어 동작 확인
conv = nn.Conv2d(in_channels=1, out_channels=32, kernel_size=3)
pool = nn.MaxPool2d(kernel_size=2, stride=2)

x = torch.randn(1, 1, 28, 28)   # (배치, 채널, 높이, 너비)
print("입력:", x.shape)           # (1, 1, 28, 28)
print("Conv 후:", conv(x).shape)  # (1, 32, 26, 26)
print("Pool 후:", pool(conv(x)).shape)  # (1, 32, 13, 13)
```

### CNN 모델 클래스 작성

```python
class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()

        # 특징 추출부 (Feature Extractor)
        self.features = nn.Sequential(
            # Block 1
            nn.Conv2d(3, 32, kernel_size=3, padding=1),  # (3,32,32) → (32,32,32)
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.Conv2d(32, 32, kernel_size=3, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),                           # (32,16,16)
            nn.Dropout2d(0.25),

            # Block 2
            nn.Conv2d(32, 64, kernel_size=3, padding=1), # (64,16,16)
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.Conv2d(64, 64, kernel_size=3, padding=1),
            nn.BatchNorm2d(64),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),                           # (64,8,8)
            nn.Dropout2d(0.25),
        )

        # 분류부 (Classifier)
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(64 * 8 * 8, 512),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(512, num_classes)
        )

    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model  = SimpleCNN(num_classes=10).to(device)
print(model)
print(f"파라미터 수: {sum(p.numel() for p in model.parameters()):,}")
```

### 훈련 및 평가 함수

```python
def train_epoch(model, loader, criterion, optimizer, device):
    model.train()
    total_loss, correct, total = 0.0, 0, 0

    for X, y in loader:
        X, y = X.to(device), y.to(device)
        pred = model(X)
        loss = criterion(pred, y)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        total_loss += loss.item()
        correct    += (pred.argmax(1) == y).sum().item()
        total      += y.size(0)

    return total_loss / len(loader), correct / total


def eval_epoch(model, loader, criterion, device):
    model.eval()
    total_loss, correct, total = 0.0, 0, 0

    with torch.no_grad():
        for X, y in loader:
            X, y = X.to(device), y.to(device)
            pred  = model(X)
            total_loss += criterion(pred, y).item()
            correct    += (pred.argmax(1) == y).sum().item()
            total      += y.size(0)

    return total_loss / len(loader), correct / total
```

### 훈련 실행

```python
EPOCHS = 30
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=EPOCHS)

history = {"train_loss":[], "train_acc":[], "val_loss":[], "val_acc":[]}

for epoch in range(1, EPOCHS + 1):

print(f"\n최고 검증 정확도: {best_acc:.2%}")
```

### 완전연결(FC) vs. CNN — 이미지를 다루는 방식의 차이

| 항목 | 완전연결 모델 (주제 2 Lab 3) | CNN 모델 (이번 Lab) |
|------|------------------------------|----------------------|
| 입력 형태 | 784차원 1D 벡터로 평탄화 | 1×28×28 2D 구조 유지 |
| 공간 정보 | 소실 (픽셀 위치 관계 무시) | 보존 (인접 픽셀 관계 학습) |
| 파라미터 방식 | 픽셀마다 독립적인 가중치 | 필터를 이미지 전체에 공유 |
| 특징 추출 | 없음 (원시 픽셀 값 그대로 입력) | Conv 레이어가 엣지·곡선 등 자동 추출 |
| 기대 정확도 | ~97~98% | ~99% 이상 |

> **핵심:** MNIST는 이미지가 단순해 완전연결 모델도 높은 정확도를 내지만, 이미지 데이터 특유의 공간적 지역성(locality)을 활용하는 CNN이 더 적은 오차로 더 견고하게 학습한다.

### Step 2. CNN 모델 설계

```python
# 3-1 ~ 3-2에서 익힌 Conv → BatchNorm → ReLU → Pool 패턴을
# 입력 채널 1(흑백), 클래스 10개(숫자 0~9)에 맞게 적용한다
class MNIST_CNN(nn.Module):
    def __init__(self, num_classes=10):
        super().__init__()

        self.features = nn.Sequential(
            # Block 1: (1, 28, 28) → (16, 14, 14)
            nn.Conv2d(1, 16, kernel_size=3, padding=1),
            nn.BatchNorm2d(16),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),

            # Block 2: (16, 14, 14) → (32, 7, 7)
            nn.Conv2d(16, 32, kernel_size=3, padding=1),
            nn.BatchNorm2d(32),
            nn.ReLU(),
            nn.MaxPool2d(2, 2),
        )

        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(32 * 7 * 7, 128),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(128, num_classes)
        )

    def forward(self, x):
        x = self.features(x)
        x = self.classifier(x)
        return x

model = MNIST_CNN().to(device)
print(model)

total_params = sum(p.numel() for p in model.parameters())
```

## 3-3. 전이학습 (Transfer Learning)

### 사전학습 모델 선택 기준

| 모델 | 정확도 | 속도 | 파라미터 | 추천 사용처 |
|------|--------|------|----------|------------|
| ResNet-50 | ★★★★ | ★★★ | 25M | 일반 분류, 기준선 |
| EfficientNet-B0 | ★★★★ | ★★★★ | 5.3M | 모바일/엣지 |
| EfficientNet-B4 | ★★★★★ | ★★★ | 19M | 높은 정확도 필요 시 |
| MobileNet-V3 | ★★★ | ★★★★★ | 5.4M | 실시간 추론 |
| ViT-B/16 | ★★★★★ | ★★ | 86M | 대용량 데이터셋 |

> **기본 선택:** 데이터 적으면 EfficientNet-B0, 정확도 우선이면 ResNet-50

### Feature Extraction vs. Fine-Tuning

```
Feature Extraction (특징 추출)
  - 사전학습 가중치 동결 (freeze)
  - 마지막 분류층만 훈련
  - 데이터가 적을 때 (< 1,000장)
  - 훈련 빠름

Fine-Tuning (미세 조정)
  - 사전학습 가중치로 초기화
  - 전체 또는 일부 레이어 함께 훈련
  - 데이터가 충분할 때 (> 5,000장)
  - 더 높은 정확도 가능
```

### Feature Extraction 구현

```python
import torchvision.models as models

# ResNet-50 사전학습 모델 로딩
backbone = models.resnet50(weights=models.ResNet50_Weights.IMAGENET1K_V2)

# 모든 레이어 동결
for param in backbone.parameters():
    param.requires_grad = False

# 마지막 분류층만 교체 (CIFAR-10: 10 클래스)
in_features = backbone.fc.in_features     # 2048
backbone.fc = nn.Linear(in_features, 10)  # 새 분류층은 자동으로 학습 가능

model_fe = backbone.to(device)

# 학습 가능한 파라미터만 확인
trainable = sum(p.numel() for p in model_fe.parameters() if p.requires_grad)
total     = sum(p.numel() for p in model_fe.parameters())
print(f"학습 파라미터: {trainable:,} / 전체: {total:,} ({trainable/total:.1%})")
```

### Fine-Tuning 구현

```python
# EfficientNet-B0 로딩
backbone = models.efficientnet_b0(weights=models.EfficientNet_B0_Weights.IMAGENET1K_V1)

# 전체 동결 후 선택적 해제
for param in backbone.parameters():
    param.requires_grad = False

# 마지막 2개 블록 + 분류층만 해제
for param in backbone.features[-2:].parameters():
    param.requires_grad = True

# 분류층 교체
in_features = backbone.classifier[1].in_features
backbone.classifier[1] = nn.Linear(in_features, 10)

model_ft = backbone.to(device)

# Fine-Tuning 시 학습률 차등 적용
optimizer_ft = torch.optim.Adam([
    {"params": backbone.features[-2:].parameters(), "lr": 1e-4},  # 낮은 학습률
    {"params": backbone.classifier.parameters(),    "lr": 1e-3},  # 높은 학습률
])

print(f"Fine-Tuning 학습 파라미터: {sum(p.numel() for p in model_ft.parameters() if p.requires_grad):,}")
```

### 전이학습 훈련 (입력 크기 조정 포함)

```python

transfer_transform = transforms.Compose([
```

### 이미지 업로드 추론 엔드포인트

```python
# main.py — 전체 서버 코드
from fastapi import FastAPI, File, UploadFile, HTTPException
from pydantic import BaseModel
from PIL import Image
import onnxruntime as ort
import torchvision.transforms as transforms
import numpy as np
import io

app = FastAPI(title="CIFAR-10 이미지 분류 API", version="1.0.0")

# ── 전역 설정 ──────────────────────────────────────────────
CLASSES = ["airplane","automobile","bird","cat","deer",
           "dog","frog","horse","ship","truck"]

# ONNX 세션 초기화 (서버 시작 시 1회만)
session = ort.InferenceSession(
    "cnn_model.onnx",
    providers=["CUDAExecutionProvider", "CPUExecutionProvider"]
)
INPUT_NAME  = session.get_inputs()[0].name
OUTPUT_NAME = session.get_outputs()[0].name

# 전처리 파이프라인 (훈련과 동일한 정규화 적용)
preprocess = transforms.Compose([
    transforms.Resize((32, 32)),
    transforms.ToTensor(),
    transforms.Normalize(mean=(0.4914, 0.4822, 0.4465),
                         std=(0.2470, 0.2435, 0.2616)),
])

# ── 응답 모델 ──────────────────────────────────────────────
class PredictResponse(BaseModel):
    class_name: str
    class_id:   int
    confidence: float
    all_scores: dict[str, float]

# ── 엔드포인트 ──────────────────────────────────────────────
@app.get("/health")
def health():
    return {"status": "ok", "model": "CIFAR-10 CNN"}

@app.post("/predict", response_model=PredictResponse)
async def predict(file: UploadFile = File(...)):
    # 이미지 형식 검증
    if file.content_type not in ["image/jpeg", "image/png", "image/webp"]:
        raise HTTPException(status_code=400, detail="JPG/PNG/WEBP 이미지만 허용됩니다.")

    # 이미지 로딩 및 전처리
    contents = await file.read()
    image    = Image.open(io.BytesIO(contents)).convert("RGB")
    tensor   = preprocess(image).unsqueeze(0).numpy()   # (1,3,32,32)

    # ONNX 추론
    logits = session.run([OUTPUT_NAME], {INPUT_NAME: tensor})[0]  # (1, 10)

    # Softmax → 확률 변환
    exp_logits  = np.exp(logits - logits.max())
    probs       = exp_logits / exp_logits.sum()
    probs       = probs[0]

    pred_id   = int(probs.argmax())
    all_scores = {CLASSES[i]: round(float(probs[i]), 4) for i in range(10)}

    return PredictResponse(
        class_name = CLASSES[pred_id],
        class_id   = pred_id,
        confidence = round(float(probs[pred_id]), 4),
        all_scores = all_scores,
    )
```

```python
    param.requires_grad = False
for param in backbone.features[-2:].parameters():
    param.requires_grad = True

in_features = backbone.classifier[1].in_features
backbone.classifier[1] = nn.Linear(in_features, NUM_CLASSES)

model = backbone.to(device)
print(f"학습 파라미터: {sum(p.numel() for p in model.parameters() if p.requires_grad):,}")
```

### Step 3. 훈련

```python
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam([
    {"params": backbone.features[-2:].parameters(), "lr": 1e-4},
    {"params": backbone.classifier.parameters(),    "lr": 1e-3},
])
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=20)

best_acc = 0.0
for epoch in range(1, 21):
    tr_loss, tr_acc = train_epoch(model, train_loader, criterion, optimizer, device)
    va_loss, va_acc = eval_epoch(model, val_loader,   criterion, device)
    scheduler.step()

    if va_acc > best_acc:
        best_acc = va_acc
        torch.save({"model_state": model.state_dict(), "classes": CLASSES},
                   "lab3_best.pt")

    print(f"Epoch {epoch:>2} | Train {tr_acc:.2%} | Val {va_acc:.2%}")

print(f"\n최고 검증 정확도: {best_acc:.2%} → lab3_best.pt 저장")
```

```python
dummy = torch.randn(1, 3, 224, 224)
torch.onnx.export(
    backbone, dummy, "lab3_model.onnx",
    export_params=True, opset_version=17,
    input_names=["input"], output_names=["output"],
    dynamic_axes={"input": {0: "batch"}, "output": {0: "batch"}}
)
```

### Step 6. Spring Boot 연동 미리보기

```java
// Spring Boot에서 FastAPI 이미지 분류 API 호출
@Service
public class ImageClassifierService {

    private final WebClient webClient;

    public ImageClassifierService(WebClient.Builder builder) {
        this.webClient = builder.baseUrl("http://localhost:8000").build();
    }

    public PredictResponse classify(MultipartFile image) throws IOException {
        return webClient.post()
            .uri("/predict")
            .contentType(MediaType.MULTIPART_FORM_DATA)
            .body(BodyInserters.fromMultipartData(
                "file", new ByteArrayResource(image.getBytes()) {
                    @Override
                    public String getFilename() { return image.getOriginalFilename(); }
                }
            ))
            .retrieve()
            .bodyToMono(PredictResponse.class)
            .block();
    }
}
```
