## 2-1. 딥러닝 핵심 개념

### 뉴럴 네트워크 구조

딥러닝 모델은 **입력층 → 은닉층(들) → 출력층** 으로 구성된다.
각 층은 가중치(Weight)와 편향(Bias)을 가지며, 훈련을 통해 이 값들을 조정한다.

```
입력층         은닉층 1        은닉층 2       출력층
[x1]  ──→  [h1][h2]  ──→  [h3][h4]  ──→  [y]
[x2]         (활성화)          (활성화)
[x3]
```

### 활성화 함수

| 함수 | 수식 | 주요 사용처 |
|------|------|------------|
| ReLU | `max(0, x)` | 은닉층 (기본값) |
| Sigmoid | `1 / (1 + e⁻ˣ)` | 이진 분류 출력층 |
| Softmax | `eˣⁱ / Σeˣ` | 다중 분류 출력층 |
| Tanh | `(eˣ - e⁻ˣ) / (eˣ + e⁻ˣ)` | RNN 계열 |

### 순전파 / 역전파 흐름 (직관적 이해)

```
[순전파]  입력 → 가중치 곱 → 활성화 → ... → 예측값(ŷ)
[손실]    Loss = 예측값(ŷ)과 정답(y)의 차이 측정
[역전파]  Loss → 기울기(gradient) 계산 → 가중치 조금씩 업데이트
```

> 핵심 한 줄: **"틀린 만큼 책임지고 조금씩 고친다"**

### 손실함수와 옵티마이저

| 구분 | 종류 | 사용 시점 |
|------|------|----------|
| 손실함수 | `BCELoss` | 이진 분류 |
| 손실함수 | `CrossEntropyLoss` | 다중 분류 |
| 손실함수 | `MSELoss` | 회귀 |
| 옵티마이저 | `Adam` | **대부분의 경우 기본 선택** |
| 옵티마이저 | `AdamW` | 트랜스포머 계열 |
| 옵티마이저 | `SGD` | 학습률 조정이 필요한 경우 |

### 자동미분 (autograd)

`requires_grad=True` 로 설정하면 해당 Tensor에 대한 기울기(gradient)를 자동으로 계산한다.

```python
# 기울기 계산 예시
x = torch.tensor(3.0, requires_grad=True)
y = x ** 2 + 2 * x + 1      # y = x² + 2x + 1

y.backward()                 # 역전파 실행
print(x.grad)                # dy/dx = 2x + 2 = 8.0  (x=3 대입)
```

```python
# 실제 훈련에서의 흐름
w = torch.randn(3, requires_grad=True)
b = torch.zeros(1, requires_grad=True)

x      = torch.tensor([1.0, 2.0, 3.0])
y_true = torch.tensor([5.0])

y_pred = torch.dot(w, x) + b       # 순전파
loss   = (y_pred - y_true) ** 2    # 손실 계산
loss.backward()                     # 역전파

print("w의 기울기:", w.grad)
print("b의 기울기:", b.grad)
```

### nn.Module 기반 모델 클래스 작성

모든 PyTorch 모델은 `nn.Module` 을 상속받아 작성한다. Java의 상속 구조와 동일하며 `forward()` 에 순전파 로직을 구현한다.

```python
class BinaryClassifier(nn.Module):
    def __init__(self, input_dim):
        super().__init__()
        self.fc1     = nn.Linear(input_dim, 64)
        self.fc2     = nn.Linear(64, 32)
        self.fc3     = nn.Linear(32, 1)
        self.relu    = nn.ReLU()
        self.dropout = nn.Dropout(0.3)
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        x = self.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.relu(self.fc2(x))
        x = self.sigmoid(self.fc3(x))
        return x

# 모델 생성 및 구조 확인
model = BinaryClassifier(input_dim=10)

print(f"전체 파라미터 수: {sum(p.numel() for p in model.parameters()):,}")
```

## 2-3. 데이터 파이프라인

PyTorch 데이터 파이프라인은 `Dataset` → `DataLoader` 순서로 구성한다.

```
Dataset    : "어떤 데이터를, 어떻게 불러올지" 정의
DataLoader : "배치 크기로 나눠서 모델에 공급" 처리
```

### Dataset 구현 패턴

```python
from torch.utils.data import Dataset, DataLoader

class TabularDataset(Dataset):
    def __init__(self, X, y):
        self.X = torch.FloatTensor(X)
        self.y = torch.FloatTensor(y)

    def __len__(self):              # Java의 size() 대응
        return len(self.X)

    def __getitem__(self, idx):     # Java의 get() 대응
        return self.X[idx], self.y[idx]
```

## 2-4. 학습 루프 구현

### 훈련 함수

```python
def train_one_epoch(model, loader, criterion, optimizer, device):
    model.train()          # 훈련 모드: Dropout 활성화
    total_loss = 0.0

    for X_b, y_b in loader:
        X_b = X_b.to(device)
        y_b = y_b.to(device).unsqueeze(1)

        y_pred = model(X_b)            # 1. 순전파
        loss   = criterion(y_pred, y_b)# 2. 손실 계산
        optimizer.zero_grad()          # 3. 기울기 초기화
        loss.backward()                # 4. 역전파
        optimizer.step()               # 5. 가중치 업데이트

        total_loss += loss.item()

    return total_loss / len(loader)
```

### 검증 함수

```python
def evaluate(model, loader, criterion, device):
    model.eval()           # 평가 모드: Dropout 비활성화
    total_loss, correct, total = 0.0, 0, 0

    with torch.no_grad():  # 기울기 계산 비활성화 (메모리 절약)
        for X_b, y_b in loader:
            X_b = X_b.to(device)
            y_b = y_b.to(device).unsqueeze(1)

            y_pred     = model(X_b)
            total_loss += criterion(y_pred, y_b).item()
            correct    += ((y_pred >= 0.5).float() == y_b).sum().item()
            total      += y_b.size(0)

    return total_loss / len(loader), correct / total
```

### 전체 훈련 루프 실행

```python

model     = BinaryClassifier(INPUT_DIM).to(device)
criterion = nn.BCELoss()

history = {"train_loss": [], "val_loss": [], "val_acc": []}

print(f"{'Epoch':>6} | {'Train Loss':>10} | {'Val Loss':>10} | {'Val Acc':>8}")
print("-" * 45)

for epoch in range(1, EPOCHS + 1):
    train_loss         = train_one_epoch(model, train_loader, criterion, optimizer, device)
    val_loss, val_acc  = evaluate(model, val_loader, criterion, device)

    history["train_loss"].append(train_loss)
    history["val_loss"].append(val_loss)
    history["val_acc"].append(val_acc)

    if epoch % 10 == 0:
        print(f"{epoch:>6} | {train_loss:>10.4f} | {val_loss:>10.4f} | {val_acc:>7.2%}")
```

```python
class TitanicNet(nn.Module):
    def __init__(self, input_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(input_dim, 64),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(32, 1),
            nn.Sigmoid()
        )

    def forward(self, x):
        return self.net(x)

INPUT_DIM = X_tr.shape[1]
```

### Step 4. 훈련 설정 및 실행

```python
EPOCHS = 80
LR     = 0.001

criterion = nn.BCELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=LR, weight_decay=1e-4)
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.5)

history      = {"train_loss": [], "val_loss": [], "val_acc": []}
best_val_acc = 0.0

for epoch in range(1, EPOCHS + 1):
    # 훈련
    model.train()
    train_loss = 0.0
    for X_b, y_b in train_loader:
        X_b, y_b = X_b.to(device), y_b.to(device).unsqueeze(1)
        pred = model(X_b)
        loss = criterion(pred, y_b)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        train_loss += loss.item()
    train_loss /= len(train_loader)

    # 검증
    model.eval()
    val_loss, correct, total = 0.0, 0, 0
    with torch.no_grad():
        for X_b, y_b in val_loader:
            X_b, y_b = X_b.to(device), y_b.to(device).unsqueeze(1)
            pred      = model(X_b)
            val_loss += criterion(pred, y_b).item()
            correct  += ((pred >= 0.5).float() == y_b).sum().item()
            total    += y_b.size(0)
    val_loss /= len(val_loader)
    val_acc   = correct / total

    scheduler.step()
    history["train_loss"].append(train_loss)
    history["val_loss"].append(val_loss)
    history["val_acc"].append(val_acc)

    # 최고 성능 모델 저장
    if val_acc > best_val_acc:
        best_val_acc = val_acc
        torch.save(model.state_dict(), "titanic_best.pt")

    if epoch % 20 == 0:
        print(f"Epoch {epoch:>3} | Train: {train_loss:.4f} | Val: {val_loss:.4f} | Acc: {val_acc:.2%}")

print(f"\n최고 검증 정확도: {best_val_acc:.2%} → titanic_best.pt 저장")
```
