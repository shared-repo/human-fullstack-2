## 1. 왜 CNN인가? — MLP와의 비교

### MLP(완전 연결 신경망)의 한계

이미지를 MLP로 처리하면 다음 문제가 발생합니다.

```python
# 32×32 컬러 이미지를 MLP로 처리할 때
image_pixels = 32 * 32 * 3   # = 3,072개 입력
hidden_dim   = 512

# 첫 번째 레이어의 가중치 수
params = image_pixels * hidden_dim  # = 1,572,864개
# → 고해상도 이미지(224×224×3)라면 약 1억 5천만 개 가중치!
```

**MLP의 3가지 문제:**

| 문제 | 설명 |
|------|------|
| 위치 불변성 없음 | 고양이가 왼쪽에 있든 오른쪽에 있든 다른 입력으로 인식 |
| 파라미터 폭발 | 고해상도 이미지에서 가중치 수가 억 단위 |
| 공간 구조 무시 | 이미지를 1D 벡터로 펼치면 인접 픽셀 관계가 사라짐 |

### CNN이 이를 해결하는 방법

```
핵심 아이디어: "작은 필터(커널)로 이미지 전체를 훑는다"

→ 가중치 공유(Weight Sharing):  동일한 필터를 이미지 모든 위치에 적용
→ 위치 불변성:                  같은 패턴이 어디에 있어도 동일하게 감지
→ 파라미터 효율:                3×3 필터 = 9개 가중치로 전체 이미지 처리
```

## 2. Convolution 연산 상세

### 필터(커널)가 이미지를 훑는 과정

```
입력 이미지 (5×5)        3×3 필터           출력 특징 맵 (3×3)
┌─────────────┐          ┌───────┐           ┌─────────┐
│ 1  2  3  0  1│          │-1  0  1│           │         │
│ 0  1  2  3  0│          │-2  0  2│    →      │    ?    │
│ 1  2  1  0  1│  × (합계)│-1  0  1│           │         │
│ 0  1  0  2  1│          └───────┘           └─────────┘
│ 1  0  1  1  0│
└─────────────┘
       ↑
 필터가 왼쪽 위부터 슬라이딩하며 겹치는 영역의 원소별 곱의 합(dot product) 계산
```

**한 칸의 계산 예시:**

```python
import torch

# 입력 이미지의 왼쪽 상단 3×3 영역
patch = torch.tensor([[1., 2., 3.],
                       [0., 1., 2.],
                       [1., 2., 1.]])

# 수직 엣지 감지 필터 (Sobel 유사)
kernel = torch.tensor([[-1., 0., 1.],
                        [-2., 0., 2.],
                        [-1., 0., 1.]])

# Convolution = 원소별 곱 후 합산
result = (patch * kernel).sum()
print(f"출력값: {result.item()}")   # 이 값이 특징 맵의 한 원소가 됨
```

### PyTorch Conv2d 연산 직접 확인

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# 수직 엣지 / 수평 엣지 필터 직접 정의
vertical_filter   = torch.tensor([[-1., 0., 1.],
                                   [-2., 0., 2.],
                                   [-1., 0., 1.]]).view(1, 1, 3, 3)

horizontal_filter = torch.tensor([[-1., -2., -1.],
                                   [ 0.,  0.,  0.],
                                   [ 1.,  2.,  1.]]).view(1, 1, 3, 3)

# 단순한 테스트 이미지 (세로선이 있는 이미지 시뮬레이션)
image = torch.zeros(1, 1, 7, 7)
image[:, :, :, 3] = 1.0   # 가운데 세로선

# 필터 적용
v_edge = F.conv2d(image, vertical_filter, padding=0)
h_edge = F.conv2d(image, horizontal_filter, padding=0)

print("수직 엣지 감지 결과:")
print(v_edge.squeeze())    # 세로선 위치에서 값이 크게 나타남
print("\n수평 엣지 감지 결과:")
print(h_edge.squeeze())    # 세로선이므로 수평 필터 반응 없음
```

### 학습을 통한 필터 자동 생성

```python
# 직접 정의하는 것이 아니라, 훈련을 통해 최적 필터를 자동으로 학습
conv = nn.Conv2d(in_channels=1, out_channels=16, kernel_size=3, padding=1)

# 훈련 전 초기 필터 (랜덤)
print("학습 전 첫 번째 필터:")
print(conv.weight[0, 0])   # (3×3) 랜덤 값

# → 역전파를 통해 "유용한 패턴을 잘 감지하는 필터"로 수렴
```

## 3. 핵심 파라미터 심화

### 패딩(Padding)

패딩은 입력 이미지 테두리에 0을 추가하는 것입니다.

```
패딩 없음 (padding=0):                 패딩 있음 (padding=1):
 ┌───────┐                              ┌───────────┐
 │ 이미지 │  5×5 입력 → 3×3 출력        │0 0 0 0 0 0 0│
 └───────┘  (크기 축소)                 │0           0│
                                        │0  이미지  0│  7×7 → 5×5 출력
                                        │0           0│  (크기 유지에 가까움)
                                        │0 0 0 0 0 0 0│
                                        └───────────┘
```

```python
# padding=0: 출력이 작아짐 (모서리 정보 손실)
conv_no_pad  = nn.Conv2d(1, 8, kernel_size=3, padding=0)
# padding=1: 출력 크기 유지 (same padding)
conv_same    = nn.Conv2d(1, 8, kernel_size=3, padding=1)
# padding='same': 자동으로 same padding 계산 (PyTorch 1.9+)
conv_auto    = nn.Conv2d(1, 8, kernel_size=3, padding='same')

x = torch.randn(1, 1, 28, 28)
print("padding=0:", conv_no_pad(x).shape)   # (1, 8, 26, 26)
print("padding=1:", conv_same(x).shape)     # (1, 8, 28, 28) ← 크기 유지
print("padding=same:", conv_auto(x).shape)  # (1, 8, 28, 28)
```

**언제 패딩을 쓰는가?**
- `padding=0`: 크기를 줄이면서 중요한 특징만 추출하고 싶을 때
- `padding=1` (kernel=3): 공간 크기를 유지하면서 특징 추출 (일반적인 선택)

### 스트라이드(Stride)

스트라이드는 필터가 한 번에 몇 칸 이동하는지를 의미합니다.

```
stride=1 (기본):  필터가 한 칸씩 이동 → 출력이 크게 나옴
stride=2:         필터가 두 칸씩 이동 → 출력이 절반으로 줄어듦 (MaxPool 대신 사용 가능)
```

```python
conv_s1 = nn.Conv2d(1, 32, kernel_size=3, stride=1, padding=1)
conv_s2 = nn.Conv2d(1, 32, kernel_size=3, stride=2, padding=1)

x = torch.randn(1, 1, 32, 32)
print("stride=1:", conv_s1(x).shape)   # (1, 32, 32, 32)
print("stride=2:", conv_s2(x).shape)   # (1, 32, 16, 16) ← 절반 축소
```

### 출력 크기 계산 공식 (완전판)

```
출력 크기 = floor( (입력 크기 - 커널 크기 + 2 × 패딩) / 스트라이드 ) + 1
```

```python
def conv_output_size(input_size, kernel_size, padding, stride):
    return (input_size - kernel_size + 2 * padding) // stride + 1

# 예시 계산
cases = [
    # (입력, 커널, 패딩, 스트라이드)
    (28, 3, 0, 1),   # 일반적인 3×3 컨볼루션
    (28, 3, 1, 1),   # same padding
    (28, 3, 0, 2),   # 스트라이드 2 (다운샘플링)
    (14, 2, 0, 2),   # MaxPool2d(2,2) 와 동일 효과
]

for inp, k, p, s in cases:
    out = conv_output_size(inp, k, p, s)
    print(f"입력={inp}, kernel={k}, padding={p}, stride={s} → 출력={out}")

# 입력=28, kernel=3, padding=0, stride=1 → 출력=26
# 입력=28, kernel=3, padding=1, stride=1 → 출력=28  (same)
# 입력=28, kernel=3, padding=0, stride=2 → 출력=13
# 입력=14, kernel=2, padding=0, stride=2 → 출력=7
```

## 4. 채널(Channel)과 필터 수

### 채널의 의미

```
흑백 이미지: (1, H, W)   → 채널 1개 (밝기 정보만)
컬러 이미지: (3, H, W)   → 채널 3개 (R, G, B)
특징 맵:     (C, H, W)   → 채널 C개 (C가지 패턴 정보)
```

### Conv2d 파라미터와 필터 수의 관계

```python
# Conv2d(in_channels, out_channels, kernel_size)
conv = nn.Conv2d(3, 64, kernel_size=3)
#                ↑    ↑
#           입력 채널  출력 채널(필터 수)

# 내부에서 실제로 만들어지는 필터의 구조:
# (64, 3, 3, 3)  →  out_channels × in_channels × H × W
print("필터 텐서 shape:", conv.weight.shape)   # torch.Size([64, 3, 3, 3])
print("편향 shape:", conv.bias.shape)           # torch.Size([64])

# 총 파라미터 수
params = 64 * 3 * 3 * 3 + 64   # 가중치 + 편향
print(f"파라미터 수: {params:,}")   # 1,792개 (매우 적음!)
```

### 채널이 늘어나는 이유

```
Conv2d(1, 32, 3):  1가지 입력 → 32가지 다른 패턴 동시 탐지
Conv2d(32, 64, 3): 32가지 패턴 조합 → 64가지 더 복잡한 패턴 탐지
Conv2d(64, 128, 3): 64가지 패턴 조합 → 128가지 고수준 패턴 탐지

층이 깊어질수록 채널(필터) 수는 늘고, 공간 크기(H×W)는 줄어드는 것이 일반적
```

```python
# 전형적인 CNN 특징 맵 변화 추이
x = torch.randn(1, 3, 32, 32)   # 입력: (배치, 채널, H, W)

c1 = nn.Conv2d(3,  32, 3, padding=1);  x1 = c1(x)
p1 = nn.MaxPool2d(2);                  x2 = p1(x1)
c2 = nn.Conv2d(32, 64, 3, padding=1);  x3 = c2(x2)
p2 = nn.MaxPool2d(2);                  x4 = p2(x3)

print(f"입력:       {tuple(x.shape)}")    # (1,  3, 32, 32)
print(f"Conv1 후:   {tuple(x1.shape)}")   # (1, 32, 32, 32) ← 채널 ↑
print(f"Pool1 후:   {tuple(x2.shape)}")   # (1, 32, 16, 16) ← 공간 ↓
print(f"Conv2 후:   {tuple(x3.shape)}")   # (1, 64, 16, 16) ← 채널 ↑
print(f"Pool2 후:   {tuple(x4.shape)}")   # (1, 64,  8,  8) ← 공간 ↓
```

## 5. 풀링(Pooling) 레이어 상세

### MaxPool vs AvgPool

```python
x = torch.tensor([[[[1., 3., 2., 4.],
                     [5., 6., 7., 8.],
                     [3., 2., 1., 0.],
                     [4., 3., 5., 2.]]]])   # (1, 1, 4, 4)

max_pool = nn.MaxPool2d(kernel_size=2, stride=2)
avg_pool = nn.AvgPool2d(kernel_size=2, stride=2)

print("원본:\n", x.squeeze())
print("\nMaxPool2d(2,2):\n", max_pool(x).squeeze())
# [[6, 8],   ← 각 2×2 영역에서 최댓값
#  [4, 5]]

print("\nAvgPool2d(2,2):\n", avg_pool(x).squeeze())
# [[3.75, 5.25],   ← 각 2×2 영역의 평균
#  [3.0,  2.0]]
```

**MaxPool vs AvgPool 선택 기준:**

| | MaxPool | AvgPool |
|--|---------|---------|
| 동작 | 영역 최댓값 추출 | 영역 평균 추출 |
| 보존 정보 | 가장 강한 특징 | 전반적인 분포 |
| 주 사용처 | CNN 특징 추출 (은닉층) | Global Average Pooling (출력 직전) |
| 노이즈 | 강인 (노이즈 억제) | 노이즈 포함 |

### Global Average Pooling (GAP)

현대 CNN 아키텍처(ResNet, EfficientNet 등)에서 Flatten 대신 사용합니다.

```python
# 전통 방식: Flatten → Linear
x = torch.randn(1, 64, 8, 8)      # 특징 맵
flat = x.flatten(1)                 # (1, 64×8×8) = (1, 4096)
print("Flatten 후 크기:", flat.shape)

# GAP 방식: 공간 차원을 평균으로 압축
gap = nn.AdaptiveAvgPool2d(1)      # 출력 크기를 1×1로 강제
out = gap(x).flatten(1)            # (1, 64)
print("GAP 후 크기:", out.shape)

# GAP의 장점:
# 1. 파라미터 수 대폭 감소 (4096 → 64)
# 2. 입력 이미지 크기에 독립적 (다양한 해상도 처리 가능)
# 3. 과적합 감소
```

## 6. BatchNorm2d 역할

### 왜 필요한가?

레이어를 통과할수록 활성화 값의 분포가 변하는 현상(Internal Covariate Shift)이 발생합니다.

```python
# BatchNorm2d 동작 확인
import torch
import torch.nn as nn

bn = nn.BatchNorm2d(32)   # 채널 수 32

# 훈련 전 (랜덤 값)
x = torch.randn(4, 32, 8, 8) * 5 + 10   # 평균 10, 분산 5 (비정규화 상태)
print(f"BatchNorm 전 — 평균: {x.mean():.2f}, 표준편차: {x.std():.2f}")

bn.train()
out = bn(x)
print(f"BatchNorm 후 — 평균: {out.mean():.4f}, 표준편차: {out.std():.4f}")
# → 평균 ≈ 0, 표준편차 ≈ 1 로 정규화
```

### BatchNorm의 효과

```
1. 학습 안정화:  활성화 값이 폭발하거나 소멸하는 것을 방지
2. 학습률 둔감:  더 높은 학습률 사용 가능 → 수렴 속도 향상
3. 규제화 효과:  Dropout 없이도 어느 정도 과적합 방지
4. 기울기 소실 완화: 값이 정규화되어 활성화 함수 포화 구간 회피
```

```python
# BN 위치: Conv → BN → ReLU 순서 (관례)
block = nn.Sequential(
    nn.Conv2d(32, 64, kernel_size=3, padding=1),
    nn.BatchNorm2d(64),   # ← Conv 직후, 활성화 전
    nn.ReLU(),
)

# 주의: 평가 시 model.eval() 필수
# eval() 모드에서 BN은 훈련 중 학습한 이동 평균/분산을 사용
# train() 모드에서는 현재 배치의 통계를 사용
```

## 7. Receptive Field (수용 영역)

### 개념

각 뉴런이 원본 이미지에서 "볼 수 있는 영역"을 Receptive Field라고 합니다.

```
층 1 (Conv 3×3): 각 출력 뉴런은 원본의 3×3 영역을 봄
층 2 (Conv 3×3): 각 출력 뉴런은 층 1의 3×3을 보는데, 층 1은 원본 3×3을 봄
                 → 층 2의 뉴런은 원본의 5×5 영역을 봄
층 3 (Conv 3×3): 원본의 7×7 영역을 봄

층이 깊어질수록 Receptive Field가 넓어짐 = 더 큰 패턴 감지 가능
```

```python
def receptive_field(n_layers, kernel_size, stride=1):
    """n개의 동일한 Conv 레이어를 쌓을 때 Receptive Field 계산"""
    rf = 1
    for _ in range(n_layers):
        rf = rf + (kernel_size - 1) * stride
    return rf

for n in range(1, 6):
    rf = receptive_field(n, kernel_size=3)
    print(f"Conv3×3 × {n}층 → Receptive Field: {rf}×{rf}")

# Conv3×3 × 1층 → Receptive Field: 3×3
# Conv3×3 × 2층 → Receptive Field: 5×5
# Conv3×3 × 3층 → Receptive Field: 7×7
# Conv3×3 × 4층 → Receptive Field: 9×9
# Conv3×3 × 5층 → Receptive Field: 11×11
```

**실무 인사이트:** 5×5 필터 하나 대신 3×3 필터 두 개를 쌓으면 동일한 Receptive Field를 절반의 파라미터로 달성할 수 있습니다. (VGG 네트워크의 핵심 통찰)

```python
# 파라미터 비교
params_5x5 = 1 * 1 * 5 * 5   # 25개
params_3x3 = (1 * 1 * 3 * 3) + (1 * 1 * 3 * 3)   # 9 + 9 = 18개
print(f"5×5 필터 1개: {params_5x5}개 파라미터")
print(f"3×3 필터 2개: {params_3x3}개 파라미터 (동일 Receptive Field)")
```

## 8. 특징 맵(Feature Map) 시각화

훈련된 모델의 중간 레이어 출력을 시각화하면 모델이 무엇을 보고 있는지 확인할 수 있습니다.

```python
import matplotlib.pyplot as plt
import torch

# 특정 레이어의 출력을 캡처하는 훅 등록
activation = {}

def make_hook(name):
    def hook(module, input, output):
        activation[name] = output.detach()
    return hook

# 모델에 훅 등록 (SimpleCNN의 첫 번째 Conv 레이어)
model.features[0].register_forward_hook(make_hook("conv1"))
model.features[8].register_forward_hook(make_hook("conv3"))

# 추론 실행
model.eval()
with torch.no_grad():
    sample_img, label = test_dataset[0]
    _ = model(sample_img.unsqueeze(0).to(device))

# 첫 번째 Conv 레이어 특징 맵 시각화
conv1_output = activation["conv1"].cpu().squeeze()   # (32, H, W)

fig, axes = plt.subplots(4, 8, figsize=(16, 8))
for i, ax in enumerate(axes.flatten()):
    if i < conv1_output.shape[0]:
        ax.imshow(conv1_output[i], cmap="viridis")
        ax.set_title(f"Filter {i}", fontsize=8)
    ax.axis("off")

plt.suptitle(f"Conv1 특징 맵 (32채널) — 클래스: {CLASSES[label]}")
```

## 9. CNN 아키텍처 발전 흐름

### 주요 모델 계보

```
LeNet (1998)        → 최초의 실용적 CNN, MNIST 손글씨 인식
       ↓
AlexNet (2012)      → ImageNet 대회 혁신적 우승 (오류율 절반 감소)
       ↓                GPU 병렬화, ReLU, Dropout 도입
VGGNet (2014)       → 3×3 필터만 사용, 네트워크 깊이의 중요성 입증
       ↓
GoogLeNet (2014)    → Inception 모듈: 여러 커널 크기 병렬 적용
       ↓
ResNet (2015)       → 잔차 연결(Skip Connection)로 152층 학습 성공
       ↓
EfficientNet (2019) → 깊이/너비/해상도의 최적 비율 자동 탐색
       ↓
ViT (2020+)         → Transformer를 이미지에 적용 (패치 분할)
```

### ResNet의 핵심: 잔차 연결(Skip Connection)

```python
# 일반 블록 (문제: 깊어질수록 기울기 소실)
class NormalBlock(nn.Module):
    def forward(self, x):
        out = self.conv1(x)
        out = self.bn1(out)
        out = F.relu(out)
        out = self.conv2(out)
        out = self.bn2(out)
        return F.relu(out)   # 입력 x의 흔적이 사라짐

# 잔차 블록 (해결: 입력을 출력에 직접 더함)
class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn1   = nn.BatchNorm2d(channels)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn2   = nn.BatchNorm2d(channels)

    def forward(self, x):
        residual = x                       # ← 입력을 저장
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out = out + residual               # ← 입력을 출력에 더함 (Skip Connection)
        return F.relu(out)

# 효과:
# 기울기가 Skip Connection을 통해 직접 흐름 → 100층 이상도 안정적 학습
# 블록이 "변화량"만 학습 → 더 쉬운 최적화 문제로 변환
```

## 10. 전체 CNN 흐름 정리

```
원본 이미지 (3, 32, 32)
  │
  ▼ Conv2d(3→32, 3×3, padding=1) + BN + ReLU
특징 맵 (32, 32, 32)   ← 32가지 저수준 패턴 (엣지, 색상 경계)
  │
  ▼ Conv2d(32→32, 3×3, padding=1) + BN + ReLU
특징 맵 (32, 32, 32)   ← 패턴 더 정교하게 다듬기
  │
  ▼ MaxPool2d(2, 2)
특징 맵 (32, 16, 16)   ← 공간 절반 축소 (가장 강한 특징만 보존)
  │
  ▼ Conv2d(32→64, 3×3, padding=1) + BN + ReLU
특징 맵 (64, 16, 16)   ← 64가지 중수준 패턴 (모서리 조합, 형태)
  │
  ▼ Conv2d(64→64, 3×3, padding=1) + BN + ReLU
특징 맵 (64, 16, 16)   ← 더 복잡한 형태 패턴
  │
  ▼ MaxPool2d(2, 2)
특징 맵 (64, 8, 8)    ← 다시 절반 축소
  │
  ▼ Flatten()
벡터 (4096,)           ← 3D 특징 맵을 1D로 펼침
  │
  ▼ Linear(4096→512) + ReLU + Dropout
벡터 (512,)            ← 고수준 표현
  │
  ▼ Linear(512→10)
로짓 (10,)             ← 클래스별 점수 (날 것의 값)
  │
  ▼ CrossEntropyLoss (내부적으로 Softmax 포함)
확률 (10,)             ← 합계 = 1.0
```

**핵심 3원칙:**
```
1. Conv → BN → ReLU 를 블록 단위로 반복 (특징 추출)
2. MaxPool로 공간 크기를 줄이면서 채널(필터)은 늘림
3. Flatten 후 Linear로 최종 클래스 분류
```
