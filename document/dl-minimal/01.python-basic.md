## 1-2. Java 개발자를 위한 Python 핵심 문법 (90분)

### 변수와 타입

| Java | Python |
|------|--------|
| `int x = 10;` | `x = 10` |
| `String s = "hello";` | `s = "hello"` |
| `boolean flag = true;` | `flag = True` |
| 타입 선언 필수 | 타입 추론 (동적 타입) |
| 세미콜론 필수 | 세미콜론 없음 |
| 중괄호 블록 | 들여쓰기 블록 |

### 컬렉션

| Java | Python |
|------|--------|
| `ArrayList<Integer>` | `list` (가변 순서) |
| `HashMap<String, Integer>` | `dict` (키-값) |
| `HashSet<String>` | `set` (중복 없음) |
| `int[]` | `tuple` (불변 순서) |

### 함수

```python
# Java: public int add(int a, int b) { return a + b; }
def add(a, b):
    return a + b

# 기본값 인자
def greet(name, msg="안녕하세요"):
    return f"{msg}, {name}!"

# 다중 반환
def min_max(nums):
    return min(nums), max(nums)

low, high = min_max([3, 1, 4, 1, 5])
```

### 클래스

```python
# Java의 클래스와 동일한 구조
class Animal:
    def __init__(self, name):   # Java의 생성자
        self.name = name        # Java의 this.name

    def speak(self):
        return f"{self.name}이(가) 소리를 냅니다"

class Dog(Animal):              # Java의 extends
    def speak(self):            # 메서드 오버라이드
        return f"{self.name}: 멍멍!"

dog = Dog("바둑이")
print(dog.speak())
```

## 1-3. NumPy / Pandas 핵심 (90분)

### NumPy — 수치 배열 연산

**핵심 개념:** N차원 배열(ndarray)로 반복문 없이 벡터 연산

```python
import numpy as np

# 배열 생성
a = np.array([1, 2, 3, 4, 5])
b = np.zeros((3, 4))          # 3행 4열 0 행렬
c = np.random.randn(100, 10)  # 정규분포 난수

# 벡터 연산 (반복문 없음)
print(a * 2)       # [2 4 6 8 10]
print(a + a)       # [2 4 6 8 10]
print(a ** 2)      # [1 4 9 16 25]
print(a.mean())    # 3.0
print(a.std())     # 표준편차

# 형태 변환 (딥러닝에서 자주 사용)
matrix = a.reshape(1, 5)      # (5,) → (1, 5)
flat   = matrix.flatten()     # (1, 5) → (5,)
```

### Pandas — 표 형태 데이터 처리

**핵심 개념:** DataFrame = 엑셀 시트, 강력한 데이터 조작 API

```python
import pandas as pd

# CSV 로딩
df = pd.read_csv("data.csv")

# 기본 탐색
df.head()           # 앞 5행
df.info()           # 컬럼 타입, 결측치 현황
df.describe()       # 수치 통계 요약

# 컬럼 선택
df["age"]           # 단일 컬럼 (Series)
df[["age", "salary"]]  # 복수 컬럼 (DataFrame)

# 행 필터링
df[df["age"] > 30]
df[(df["age"] > 30) & (df["dept"] == "개발")]

# 결측치 처리
df.isnull().sum()          # 결측치 수 확인
df.dropna()                # 결측 행 제거
df["age"].fillna(df["age"].mean())  # 평균값으로 대체

# 그룹 집계
df.groupby("dept")["salary"].mean()

# 새 컬럼 추가
df["bonus"] = df["salary"] * 0.1
```

## 1-4. 데이터 시각화 (90분)

### Matplotlib 기초

```python
import matplotlib.pyplot as plt
import matplotlib
matplotlib.rcParams["font.family"] = "Malgun Gothic"  # 한글 폰트

# 선 그래프
plt.plot([1, 2, 3, 4], [10, 20, 15, 30], label="매출")
plt.title("월별 매출")
plt.xlabel("월")
plt.ylabel("금액")
plt.legend()
plt.show()

# 히스토그램
plt.hist(df["age"], bins=20, edgecolor="white")
plt.title("나이 분포")
plt.show()

# 산점도
plt.scatter(df["age"], df["salary"], alpha=0.5)
plt.title("나이 vs 급여")
plt.show()
```

### Seaborn — 통계 시각화

```python
import seaborn as sns

sns.heatmap(df.corr(), annot=True, cmap="coolwarm")  # 상관관계
sns.boxplot(x="dept", y="salary", data=df)           # 부서별 급여 분포
sns.pairplot(df[["age", "salary", "bonus"]])          # 변수 간 관계
```
