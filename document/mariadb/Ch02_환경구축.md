## 1. MariaDB 설치

### 1.1 설치 전 확인 사항

설치를 시작하기 전에 다음 사항을 확인한다.

| 항목 | 권장 사양 |
|---|---|
| 운영체제 | Windows 10 / 11 (64비트) |
| 여유 디스크 공간 | 최소 1GB 이상 |
| 메모리 (RAM) | 최소 2GB 이상 권장 |
| 포트 | 3306 (기본값, 방화벽에서 차단되지 않아야 함) |

> **주의**: 이미 MySQL이 설치된 경우 포트 충돌이 발생할 수 있다. 기존에 MySQL이 설치되어 있다면 강사에게 문의한다.

---

### 1.2 MariaDB 다운로드

**① 공식 사이트 접속**

브라우저에서 아래 주소로 접속한다.

```
https://mariadb.org/download/
```

**② 버전 선택**

- MariaDB Server 항목에서 최신 **Stable(안정화)** 버전을 선택한다.
- Operating System: **Windows**
- Architecture: **x86_64** (64비트)
- Package Type: **MSI Package**

> **참고**: "RC(Release Candidate)"나 "Alpha" 버전은 아직 개발 중인 버전이므로 학습용으로는 Stable 버전을 사용한다.

**③ 다운로드 실행**

`Download` 버튼을 클릭하여 `.msi` 설치 파일을 내려받는다.  
파일명 예시: `mariadb-11.x.x-winx64.msi`

---

### 1.3 MariaDB 설치

다운로드한 `.msi` 파일을 더블클릭하여 설치를 시작한다.

**① 설치 시작**

- `Next` 클릭
- 라이선스 동의(I accept the terms in the License Agreement) 체크 후 `Next` 클릭

**② 설치 구성 요소 선택**

기본값(Default)을 유지하고 `Next`를 클릭한다.

| 구성 요소 | 설명 |
|---|---|
| MariaDB Server | 데이터베이스 서버 (필수) |
| Client Programs | 커맨드라인 클라이언트 (필수) |
| HeidiSQL | GUI 도구 (별도 설치 예정이므로 선택 해제 가능) |

**③ root 비밀번호 설정** ⚠️ 중요

- `Modify password for database user 'root'` 항목에 비밀번호를 입력한다.
- 비밀번호는 잊어버리지 않도록 반드시 기록해 둔다.
- `Enable access from remote machines for 'root' user`는 **체크 해제** 상태를 유지한다. (보안)

```
권장 비밀번호 예시: MariaDB2024!
(영문 대소문자 + 숫자 + 특수문자 조합)
```

> **주의**: root는 데이터베이스의 최고 관리자 계정이다. 비밀번호를 분실하면 데이터베이스에 접근할 수 없으므로 반드시 안전한 곳에 기록해 둔다.

**④ 서비스 설정**

- `Install as service`: 체크 유지 (Windows 시작 시 자동 실행)
- Service Name: `MySQL` (기본값 유지)
- Port: `3306` (기본값 유지)

**⑤ 설치 완료**

- `Install` 버튼 클릭
- 사용자 계정 컨트롤(UAC) 창이 나타나면 `예` 클릭
- 설치가 완료되면 `Finish` 클릭

---

### 1.4 설치 확인

**Windows 서비스에서 확인**

1. `Windows키 + R` → `services.msc` 입력 후 Enter
2. 목록에서 `MySQL` 서비스를 찾는다.
3. 상태가 **실행 중**이면 MariaDB가 정상적으로 설치된 것이다.

**작업 표시줄에서 확인**

시스템 트레이(오른쪽 하단)에 MariaDB 아이콘이 표시되면 서버가 실행 중이다.

## 2. HeidiSQL 설치 및 연결

### 2.1 HeidiSQL이란?

**HeidiSQL**은 MariaDB, MySQL 등을 **그래픽 화면(GUI)으로 편리하게 관리**할 수 있는 무료 오픈소스 도구다.

커맨드라인(검은 화면)에 명령어를 직접 입력하는 대신, 마우스 클릭으로 데이터베이스를 탐색하고 SQL을 작성·실행할 수 있다.

| 기능 | 설명 |
|---|---|
| 데이터베이스 탐색 | 트리 구조로 데이터베이스·테이블 확인 |
| SQL 편집기 | 문법 강조 기능이 있는 SQL 작성 환경 |
| 데이터 조회 | 테이블 데이터를 스프레드시트 형태로 확인 |
| 가져오기/내보내기 | CSV, SQL 파일 가져오기·내보내기 |
| 다중 연결 | 여러 서버에 동시 연결 가능 |

---

### 2.2 HeidiSQL 다운로드 및 설치

**① 공식 사이트 접속**

```
https://www.heidisql.com/download.php
```

**② 설치 파일 다운로드**

- `Installer` 항목의 최신 버전 다운로드 버튼 클릭
- 파일명 예시: `HeidiSQL_12.x_Setup.exe`

**③ 설치 진행**

- 다운로드한 파일 더블클릭
- 라이선스 동의 후 `Next` 반복 클릭
- 기본값 유지하고 `Install` 클릭
- 설치 완료 후 `Finish` 클릭

---

### 2.3 HeidiSQL에서 MariaDB 연결

**① HeidiSQL 실행**

바탕화면 또는 시작 메뉴에서 HeidiSQL을 실행한다.  
처음 실행하면 **세션 관리자** 창이 자동으로 나타난다.

**② 새 세션 만들기**

세션 관리자 왼쪽 하단의 `New` 버튼을 클릭한다.

**③ 연결 정보 입력**

| 항목 | 입력값 | 설명 |
|---|---|---|
| Network type | MariaDB or MySQL (TCP/IP) | 연결 방식 |
| Hostname / IP | `127.0.0.1` 또는 `localhost` | 내 컴퓨터(로컬) |
| User | `root` | 관리자 계정 |
| Password | (설치 시 설정한 비밀번호) | root 비밀번호 |
| Port | `3306` | 기본 포트 |

**④ 연결 테스트 및 저장**

- `Save` 버튼을 클릭하여 세션을 저장한다.
- `Open` 버튼을 클릭하여 연결한다.

**⑤ 연결 성공 확인**

연결이 성공하면 왼쪽 패널에 데이터베이스 목록이 나타난다.  
기본으로 `information_schema`, `mysql`, `performance_schema` 등 시스템 데이터베이스가 표시된다.

```
📁 127.0.0.1
  ├─ 📂 information_schema
  ├─ 📂 mysql
  ├─ 📂 performance_schema
  └─ 📂 sys
```

> **참고**: `information_schema`, `mysql`, `performance_schema`, `sys`는 MariaDB가 자체적으로 사용하는 시스템 데이터베이스다. 함부로 수정하거나 삭제하지 않는다.

### 2.4 HeidiSQL 화면 구성

```
┌─────────────────────────────────────────────────────┐
│  메뉴바 (File, Edit, Tools ...)                      │
├──────────────┬──────────────────────────────────────┤

│  트리 탐색기  │                                     │

```

| 영역 | 기능 |

**자주 사용하는 단축키**

| 단축키 | 기능 |
|---|---|
| `F9` | 전체 SQL 실행 |
| `Ctrl + Enter` | 커서가 위치한 SQL 한 문장 실행 |
| `Ctrl + /` | 선택한 줄 주석 처리 |
| `Ctrl + Z` | 실행 취소 |

### ✅ 확인 문제 2

1. HeidiSQL에서 localhost와 127.0.0.1은 어떤 의미인가?
2. HeidiSQL 연결 시 포트를 3307로 잘못 입력하면 어떻게 되는가?
3. 연결 성공 후 왼쪽 패널에 보이는 `information_schema`는 무엇인가?

> **정답**:  
> 1. 둘 다 "내 컴퓨터(로컬)"를 의미한다. localhost는 도메인 이름 형태이고, 127.0.0.1은 같은 의미의 IP 주소다.  
> 2. MariaDB 서버의 실제 포트(3306)와 달라서 연결에 실패한다. "Connection refused" 또는 "Can't connect" 오류가 발생한다.  
> 3. MariaDB가 자체적으로 사용하는 시스템 데이터베이스로, 데이터베이스·테이블·권한 등의 메타 정보(데이터에 대한 데이터)가 저장되어 있다.

## 3. 커맨드라인 클라이언트 기본 사용법

### 3.1 커맨드라인 클라이언트란?

**커맨드라인 클라이언트**는 마우스 없이 **키보드로 명령어를 직접 입력**하여 MariaDB를 조작하는 방법이다.

HeidiSQL 같은 GUI 도구가 더 편리하지만, 커맨드라인을 익혀야 하는 이유가 있다.

| 이유 | 설명 |
|---|---|
| **서버 환경** | 실무 서버(Linux)에는 GUI가 없는 경우가 많다 |
| **빠른 접속** | 간단한 작업은 CLI가 더 빠르다 |
| **스크립트 자동화** | 반복 작업을 자동화할 때 CLI 명령어를 사용한다 |
| **SQL 이해** | GUI 없이 순수 SQL에 집중하여 학습할 수 있다 |

---

### 3.2 MariaDB 커맨드라인 클라이언트 접속

**방법 1: 시작 메뉴에서 실행**

1. Windows 시작 메뉴 → `MariaDB` 폴더 → `MySQL Client` 클릭
2. 비밀번호 입력 프롬프트가 나타나면 설치 시 설정한 root 비밀번호 입력
3. 접속 성공 시 아래와 같은 프롬프트가 나타난다.

```
Welcome to the MariaDB monitor.  Commands end with ; or \g.
Your MariaDB connection id is 8
Server version: 11.x.x-MariaDB mariadb.org binary distribution

Copyright (c) 2000, 2018, Oracle, MariaDB Corporation Ab and others.

Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

MariaDB [(none)]>
```

**방법 2: Windows 명령 프롬프트에서 실행**

1. `Windows키 + R` → `cmd` 입력 후 Enter
2. 아래 명령어 입력 (비밀번호는 `-p` 뒤에 붙여 쓰거나, 엔터 후 입력)

```bash
mysql -u root -p
```

3. `Enter password:` 프롬프트가 나타나면 비밀번호 입력  
   (비밀번호 입력 시 화면에 표시되지 않는 것이 정상이다)

> **참고**: MariaDB의 커맨드라인 클라이언트 실행 파일 이름은 `mysql`이다. MySQL과의 호환성을 위해 이름을 동일하게 유지하고 있다.

---

### 3.3 기본 명령어

커맨드라인에서 자주 사용하는 기본 명령어를 익혀 둔다.  
모든 SQL 문장은 반드시 **세미콜론(`;`)으로 끝**내야 실행된다.

**데이터베이스 목록 조회**

```sql
SHOW DATABASES;
```

실행 결과:
```
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sys                |
+--------------------+
4 rows in set (0.001 sec)
```

**MariaDB 버전 확인**

```sql
SELECT VERSION();
```

실행 결과:
```
+--------------------+
| VERSION()          |
+--------------------+
| 11.x.x-MariaDB     |
+--------------------+
1 row in set (0.000 sec)
```

**현재 접속된 사용자 확인**

```sql
SELECT USER();
```

실행 결과:
```
+----------------+
| USER()         |
+----------------+
| root@localhost |
+----------------+
1 row in set (0.000 sec)
```

**현재 날짜 및 시간 확인**

```sql
SELECT NOW();
```

실행 결과:
```
+---------------------+
| NOW()               |
+---------------------+
| 2024-03-15 09:32:17 |
+---------------------+
1 row in set (0.000 sec)
```

---

### 3.4 커맨드라인 사용 시 주의 사항

**세미콜론 누락**

SQL 문장 끝에 `;`을 입력하지 않으면 MariaDB는 입력이 계속된다고 판단하여 다음 줄 입력을 기다린다.

```sql
MariaDB [(none)]> SHOW DATABASES    ← 세미콜론 없이 Enter
    ->                              ← 계속 입력 대기 상태
    -> ;                            ← 세미콜론 입력 후 Enter → 실행됨
```

**입력 취소**

현재 입력 중인 명령을 취소하려면 `\c`를 입력하고 Enter를 누른다.

```sql
MariaDB [(none)]> SHOW DATABAS\c    ← 입력 취소
MariaDB [(none)]>                   ← 새 프롬프트로 돌아옴
```

**대소문자**

SQL 키워드(`SELECT`, `SHOW`, `FROM` 등)는 대소문자를 구분하지 않는다.  
`show databases;`와 `SHOW DATABASES;`는 동일하게 동작한다.  
단, 가독성을 위해 **SQL 키워드는 대문자**로 작성하는 것을 권장한다.

---

### 3.5 커맨드라인 클라이언트 종료

MariaDB 세션을 종료하려면 다음 중 하나를 입력한다.

```sql
EXIT;
```

또는

```sql
QUIT;
```

| **SQL 종료 문자** | 반드시 세미콜론(`;`)으로 끝내야 실행됨 |
| **입력 취소** | `\c` 입력 후 Enter |
| **세션 종료** | `EXIT;` 또는 `QUIT;` |

## 트러블슈팅 (자주 발생하는 오류)

| 오류 메시지 | 원인 | 해결 방법 |
|---|---|---|
| `Can't connect to MySQL server on 'localhost'` | MariaDB 서비스가 실행되지 않음 | services.msc에서 MySQL 서비스 시작 |
| `Access denied for user 'root'@'localhost'` | 비밀번호가 틀림 | 설치 시 설정한 비밀번호 재확인 |
| `ERROR 2003 (HY000)` | 포트 번호가 틀리거나 방화벽 차단 | 포트 번호 확인, 방화벽 설정 확인 |
| HeidiSQL 연결 후 빈 화면 | 데이터베이스가 아직 없음 | 정상 상태, Chapter 4에서 생성 예정 |
