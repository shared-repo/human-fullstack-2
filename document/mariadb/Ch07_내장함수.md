## 내장 함수란?

**내장 함수(Built-in Function)**는 MariaDB가 미리 만들어 제공하는 함수다.  
복잡한 데이터 가공·계산을 SQL 한 줄로 처리할 수 있게 해준다.

```sql
-- 함수 사용 기본 형식
SELECT 함수명(인자1, 인자2, ...) FROM 테이블명;

-- 테이블 없이 단순 계산도 가능 (DUAL은 가상 테이블)
SELECT UPPER('mariadb');
SELECT NOW();
```

## 1. 문자 함수 String Functions

문자열 데이터를 연결·분리·변환·검색하는 함수다.

---

### 1.1 CONCAT — 문자열 연결

여러 문자열을 하나로 이어붙인다.

```sql
SELECT CONCAT('안녕', '하세요', '!');
-- 결과: 안녕하세요!
```

**실습**: 고객의 이름과 이메일을 하나의 문자열로 출력

```sql
SELECT
    CONCAT(name, ' <', email, '>') AS 고객정보
FROM customer;
```

실행 결과:
```
+----------------------------------+
| 고객정보                          |
+----------------------------------+
| 홍길동 <hong@example.com>        |
| 김영희 <kim@example.com>         |
| 이철수 <lee@example.com>         |
...
```

> **CONCAT_WS**: 구분자를 지정하여 연결한다. `WS`는 "With Separator"의 약자다.
> ```sql
> SELECT CONCAT_WS(' / ', name, email, phone) AS 고객정보
> FROM customer;
> -- 결과: 홍길동 / hong@example.com / 010-1111-2222
> ```

---

### 1.2 LENGTH / CHAR_LENGTH — 문자열 길이

| 함수 | 반환값 |
|---|---|
| `LENGTH(문자열)` | **바이트** 수 (한글 1자 = 3바이트) |
| `CHAR_LENGTH(문자열)` | **문자** 수 (한글 1자 = 1) |

```sql
SELECT
    '홍길동'              AS 이름,
    LENGTH('홍길동')      AS 바이트수,
    CHAR_LENGTH('홍길동') AS 문자수;
```

```
+------+----------+--------+
| 이름 | 바이트수  | 문자수  |
+------+----------+--------+
| 홍길동 |       9 |      3 |
+------+----------+--------+
```

**실습**: 이메일 길이가 20자 이하인 고객 조회

```sql
SELECT name, email, CHAR_LENGTH(email) AS 이메일길이
FROM customer
WHERE CHAR_LENGTH(email) <= 20
ORDER BY 이메일길이;
```

---

### 1.3 UPPER / LOWER — 대소문자 변환

```sql
SELECT
    UPPER('mariadb')  AS 대문자,
    LOWER('MARIADB')  AS 소문자;
-- 결과: MARIADB / mariadb
```

**실습**: 이메일을 대문자로 조회

```sql
SELECT name, UPPER(email) AS 이메일_대문자
FROM customer;
```

---

### 1.4 TRIM / LTRIM / RTRIM — 공백 제거

| 함수 | 제거 위치 |
|---|---|
| `TRIM(문자열)` | 양쪽 공백 제거 |
| `LTRIM(문자열)` | 왼쪽(앞) 공백 제거 |
| `RTRIM(문자열)` | 오른쪽(뒤) 공백 제거 |

```sql
SELECT
    TRIM('  MariaDB  ')  AS 양쪽제거,
    LTRIM('  MariaDB  ') AS 앞만제거,
    RTRIM('  MariaDB  ') AS 뒤만제거;
-- 결과: 'MariaDB' / 'MariaDB  ' / '  MariaDB'
```

> **실무 활용**: 사용자가 입력한 값의 앞뒤 공백을 자동 제거할 때 주로 사용한다.  
> 파일에서 가져온 데이터에 불필요한 공백이 포함된 경우에도 사용한다.

---

### 1.5 SUBSTRING — 부분 문자열 추출

```sql
SUBSTRING(문자열, 시작위치, 길이)
-- 시작위치는 1부터 시작
```

```sql
SELECT
    SUBSTRING('2024-01-15', 1, 4) AS 연도,
    SUBSTRING('2024-01-15', 6, 2) AS 월,
    SUBSTRING('2024-01-15', 9, 2) AS 일;
-- 결과: 2024 / 01 / 15
```

**SUBSTRING_INDEX**: 구분자를 기준으로 문자열을 분리한다.

```sql
SUBSTRING_INDEX(문자열, 구분자, n)
-- n > 0: 왼쪽부터 n번째 구분자 이전
-- n < 0: 오른쪽부터 |n|번째 구분자 이후
```

**실습**: 이메일에서 도메인(@) 앞부분과 뒷부분 분리

```sql
SELECT
    email,
    SUBSTRING_INDEX(email, '@', 1)  AS 아이디,
    SUBSTRING_INDEX(email, '@', -1) AS 도메인
FROM customer;
```

실행 결과:
```
+------------------+---------+-------------+
| email            | 아이디  | 도메인       |
+------------------+---------+-------------+
| hong@example.com | hong    | example.com |
| kim@example.com  | kim     | example.com |
| lee@example.com  | lee     | example.com |
...
```

---

### 1.6 LEFT / RIGHT — 왼쪽·오른쪽에서 추출

```sql
LEFT(문자열, n)   -- 왼쪽에서 n자
RIGHT(문자열, n)  -- 오른쪽에서 n자
```

```sql
SELECT
    LEFT('블루투스 키보드', 4)  AS 앞4자,
    RIGHT('hong@example.com', 11) AS 뒤11자;
-- 결과: '블루투스' / 'example.com'
```

**실습**: 연락처에서 앞 3자리(통신사 코드) 추출

```sql
SELECT name, phone, LEFT(phone, 3) AS 통신사코드
FROM customer;
```

---

### 1.7 REPLACE — 문자열 치환

```sql
REPLACE(문자열, 찾을문자열, 바꿀문자열)
```

```sql
-- 연락처에서 하이픈(-) 제거
SELECT name, phone, REPLACE(phone, '-', '') AS 하이픈제거
FROM customer;
```

실행 결과:
```
+--------+---------------+------------+
| name   | phone         | 하이픈제거  |
+--------+---------------+------------+
| 홍길동  | 010-1111-2222 | 01011112222 |
| 김영희  | 010-2222-3333 | 01022223333 |
...
```

---

### 1.8 INSTR / LOCATE — 문자 위치 검색

특정 문자열이 처음 나타나는 위치(1부터 시작)를 반환한다. 찾지 못하면 0을 반환한다.

```sql
SELECT
    INSTR('USB 4포트 허브', '포트') AS 위치;
-- 결과: 6
```

### 1.9 LPAD / RPAD — 패딩 (자릿수 채우기)

```sql
LPAD(문자열, 전체길이, 채울문자)  -- 왼쪽에 채움
RPAD(문자열, 전체길이, 채울문자)  -- 오른쪽에 채움
```

```sql
-- 상품 ID를 3자리로 맞추기 (001, 002 ...)
SELECT
    LPAD(product_id, 3, '0') AS 상품코드,
    product_name
FROM product;
```

실행 결과:
```
+----------+------------------------+
| 상품코드  | product_name           |
+----------+------------------------+
| 001      | 무선 마우스             |
| 002      | USB 4포트 허브          |
...
```

## 2. 날짜 및 시간 함수 Date & Time Functions

날짜·시간 데이터를 조회·계산·형식 변환하는 함수다.

---

### 2.1 현재 날짜·시간 조회

| 함수 | 반환값 | 예시 |
|---|---|---|
| `NOW()` | 현재 날짜 + 시간 | `2024-07-25 09:30:00` |
| `CURDATE()` | 현재 날짜만 | `2024-07-25` |
| `CURTIME()` | 현재 시간만 | `09:30:00` |
| `SYSDATE()` | 함수 실행 시점의 날짜+시간 | `2024-07-25 09:30:01` |

```sql
SELECT NOW(), CURDATE(), CURTIME();
```

> **NOW() vs SYSDATE()**: 하나의 쿼리 내에서 `NOW()`는 쿼리 시작 시간을 고정 반환하고, `SYSDATE()`는 함수가 실제 실행되는 순간의 시간을 반환한다. 일반적으로는 `NOW()`를 사용한다.

---

### 2.2 날짜·시간 구성 요소 추출

```sql
SELECT
    order_date,
    YEAR(order_date)    AS 연도,
    MONTH(order_date)   AS 월,
    DAY(order_date)     AS 일,
    HOUR(order_date)    AS 시,
    MINUTE(order_date)  AS 분,
    SECOND(order_date)  AS 초
FROM orders
WHERE order_id = 1;
```

실행 결과:
```
+---------------------+------+---+----+----+----+----+
| order_date          | 연도  | 월 | 일 | 시 | 분  | 초 |
+---------------------+------+---+----+----+----+----+
| 2024-01-15 10:23:00 | 2024 |  1 | 15 | 10 | 23 |  0 |
+---------------------+------+---+----+----+----+----+
```

**실습**: 월별 주문 건수 집계

```sql
SELECT
    YEAR(order_date)  AS 연도,
    MONTH(order_date) AS 월,
    COUNT(*)          AS 주문건수
FROM orders
GROUP BY YEAR(order_date), MONTH(order_date)
ORDER BY 연도, 월;
```

실행 결과:
```
+------+---+----------+
| 연도  | 월 | 주문건수 |
+------+---+----------+
| 2024 |  1 |        1 |
| 2024 |  2 |        2 |
| 2024 |  3 |        2 |
| 2024 |  4 |        2 |
| 2024 |  5 |        2 |
| 2024 |  6 |        1 |
+------+---+----------+
```

---

### 2.3 날짜 차이 계산

**DATEDIFF**: 두 날짜의 차이를 **일(Day)** 단위로 반환한다.

```sql
DATEDIFF(날짜1, 날짜2)  -- 날짜1 - 날짜2 (일 수)
```

**실습**: 오늘 기준 각 주문의 경과 일수

```sql
SELECT
    order_id,
    order_date,
    DATEDIFF(CURDATE(), order_date) AS 경과일수,
    status
FROM orders
ORDER BY 경과일수 DESC;
```

실행 결과 (2024-07-25 기준):
```
+----------+---------------------+----------+-----------+
| order_id | order_date          | 경과일수  | status    |
+----------+---------------------+----------+-----------+
|        1 | 2024-01-15 10:23:00 |      192 | 배송완료   |
|        2 | 2024-02-03 14:05:00 |      173 | 배송완료   |
|        3 | 2024-02-20 09:47:00 |      156 | 배송완료   |
...
```

**TIMESTAMPDIFF**: 두 날짜·시간의 차이를 **지정 단위**로 반환한다.

```sql
TIMESTAMPDIFF(단위, 날짜1, 날짜2)
-- 단위: SECOND, MINUTE, HOUR, DAY, WEEK, MONTH, YEAR
```

```sql
-- 주문일부터 현재까지 경과 개월 수
SELECT
    order_id,
    order_date,
    TIMESTAMPDIFF(MONTH, order_date, CURDATE()) AS 경과개월
FROM orders;
```

---

### 2.4 날짜 더하기·빼기

```sql
DATE_ADD(날짜, INTERVAL n 단위)   -- 더하기
DATE_SUB(날짜, INTERVAL n 단위)   -- 빼기
```

| 단위 키워드 | 설명 |
|---|---|
| `DAY` | 일 |
| `WEEK` | 주 |
| `MONTH` | 월 |
| `YEAR` | 연 |
| `HOUR` | 시간 |
| `MINUTE` | 분 |

```sql
SELECT
    '2024-01-15'                                  AS 주문일,
    DATE_ADD('2024-01-15', INTERVAL 30 DAY)       AS 30일후,
    DATE_ADD('2024-01-15', INTERVAL 3 MONTH)      AS 3개월후,
    DATE_SUB('2024-01-15', INTERVAL 7 DAY)        AS 7일전;
```

실행 결과:
```
+------------+------------+------------+------------+
| 주문일      | 30일후      | 3개월후     | 7일전       |
+------------+------------+------------+------------+
| 2024-01-15 | 2024-02-14 | 2024-04-15 | 2024-01-08 |
+------------+------------+------------+------------+
```

**실습**: 주문일로부터 3일 후 예상 배송 완료일 계산

```sql
SELECT
    order_id,
    order_date,
    DATE_ADD(order_date, INTERVAL 3 DAY) AS 예상배송완료일
FROM orders;
```

### 2.5 날짜 형식 지정 — DATE_FORMAT

날짜·시간을 원하는 형식의 문자열로 변환한다.

```sql
DATE_FORMAT(날짜, '형식문자열')
```

**주요 형식 지정자**

| 지정자 | 의미 | 출력 예 |
|:---:|---|---|
| `%Y` | 4자리 연도 | 2024 |
| `%y` | 2자리 연도 | 24 |
| `%m` | 2자리 월 (01~12) | 01 |
| `%c` | 월 (1~12) | 1 |
| `%d` | 2자리 일 (01~31) | 15 |
| `%e` | 일 (1~31) | 15 |
| `%H` | 24시간 형식 시 | 10 |
| `%h` | 12시간 형식 시 | 10 |
| `%i` | 분 (00~59) | 23 |
| `%s` | 초 (00~59) | 00 |
| `%W` | 요일 (영문 전체) | Monday |
| `%a` | 요일 (영문 약자) | Mon |
| `%p` | AM/PM | AM |

```sql
SELECT
    order_date,
    DATE_FORMAT(order_date, '%Y년 %m월 %d일')          AS 한국형식,
    DATE_FORMAT(order_date, '%Y/%m/%d %H:%i')          AS 날짜시간,
    DATE_FORMAT(order_date, '%Y년 %c월 %e일 (%W)')     AS 요일포함
FROM orders
WHERE order_id = 1;
```

실행 결과:
```
+---------------------+------------------+----------------+----------------------------+
| order_date          | 한국형식          | 날짜시간        | 요일포함                    |
+---------------------+------------------+----------------+----------------------------+
| 2024-01-15 10:23:00 | 2024년 01월 15일 | 2024/01/15 10:23 | 2024년 1월 15일 (Monday)  |
+---------------------+------------------+----------------+----------------------------+
```

---

### 2.6 기타 날짜 함수

```sql
-- 해당 월의 마지막 날
SELECT LAST_DAY('2024-02-01');
-- 결과: 2024-02-29 (2024년은 윤년)

-- 연중 몇 번째 날인지
SELECT DAYOFYEAR('2024-01-15');
-- 결과: 15
```

## 3. 수치 함수 Numeric Functions

숫자 데이터를 반올림·올림·내림·형식 지정하는 함수다.

---

### 3.1 반올림 — ROUND

```sql
ROUND(숫자, 소수점자리수)
-- 소수점자리수 생략 시 정수로 반올림
-- 음수 지정 시 정수 자리에서 반올림
```

```sql
SELECT
    ROUND(44700.6)      AS 정수반올림,     -- 44701

    ROUND(44700.6, -3)  AS 천단위반올림,   -- 45000
    ROUND(44700.4, -3)  AS 천단위반올림2;  -- 44000
```

### 3.2 올림·내림·버림

| 함수 | 설명 | 예시 |
|---|---|---|
| `CEIL(n)` / `CEILING(n)` | 올림 (소수 → 더 큰 정수) | `CEIL(44700.1)` → `44701` |
| `FLOOR(n)` | 내림 (소수 → 더 작은 정수) | `FLOOR(44700.9)` → `44700` |
| `TRUNCATE(n, d)` | 지정 자리 이하 버림 | `TRUNCATE(44700.9, 0)` → `44700` |

```sql
SELECT
    CEIL(44700.1)        AS 올림,      -- 44701
    FLOOR(44700.9)       AS 내림,      -- 44700
    TRUNCATE(44700.9, 0) AS 버림,      -- 44700
    TRUNCATE(44700.9, -3) AS 천단위버림; -- 44000
```

> **ROUND vs TRUNCATE**: `ROUND(2.5)` → 3 (반올림), `TRUNCATE(2.5, 0)` → 2 (버림)  
> 금액 계산에서 무조건 버림이 필요한 경우(예: 할인 쿠폰 계산) `TRUNCATE`를 사용한다.

### 3.5 천 단위 구분자 형식 — FORMAT

## 4. 제어 흐름 함수 Control Flow Functions

조건에 따라 다른 값을 반환한다. 프로그래밍의 `if-else`와 같은 역할이다.

---

### 4.1 IF

```sql
IF(조건, 참일때값, 거짓일때값)
```

```sql
-- 재고 20개 미만이면 '재고부족', 이상이면 '재고충분'
SELECT
    product_name,
    stock,
    IF(stock < 20, '⚠ 재고부족', '재고충분') AS 재고상태
FROM product
ORDER BY stock;
```

실행 결과:
```
+------------------------+-------+----------+
| product_name           | stock | 재고상태  |
+------------------------+-------+----------+
| 원목 1인 책상           |    10 | ⚠ 재고부족 |
| 스테인리스 전기주전자    |    15 | ⚠ 재고부족 |
| 블루투스 키보드          |    20 | 재고충분   |
| USB 4포트 허브          |    30 | 재고충분   |
...
```

---

### 4.2 IFNULL

값이 `NULL`이면 대체값을 반환한다.

```sql
IFNULL(값, NULL일때반환값)
```

```sql
-- 연락처가 NULL인 경우 '미등록'으로 표시
SELECT
    name,
    IFNULL(phone, '미등록') AS 연락처
FROM customer;
```

---

### 4.3 NULLIF

두 값이 같으면 `NULL`을 반환하고, 다르면 첫 번째 값을 반환한다.

```sql
NULLIF(값1, 값2)
-- 값1 = 값2 이면 → NULL
-- 값1 ≠ 값2 이면 → 값1
```

```sql
SELECT
    NULLIF(5, 5) AS 같을때,   -- NULL
    NULLIF(5, 3) AS 다를때;   -- 5
```

> **활용**: 0으로 나누기 오류 방지
> ```sql
> -- 분모가 0이면 NULL 반환 (오류 대신)
> SELECT 100 / NULLIF(0, 0);  -- NULL
> SELECT 100 / NULLIF(5, 0);  -- 20
> ```

---

### 4.4 COALESCE

인자 목록에서 **첫 번째 NULL이 아닌 값**을 반환한다.  
여러 컬럼 중 값이 있는 첫 번째 것을 선택할 때 유용하다.

```sql
COALESCE(값1, 값2, 값3, ...)
```

```sql
SELECT
    COALESCE(NULL, NULL, '기본값')  AS 결과1,  -- '기본값'
    COALESCE(NULL, '두번째', '세번째') AS 결과2,  -- '두번째'
    COALESCE('첫번째', NULL, '세번째') AS 결과3;  -- '첫번째'
```

```sql
-- 연락처가 없으면 이메일로 대신 연락처 표시
SELECT
    name,
    COALESCE(phone, email, '연락처없음') AS 연락처
FROM customer;
```

### 4.5 CASE 문

여러 조건을 순서대로 검사하여 맞는 결과를 반환한다.  
프로그래밍의 `switch-case`와 유사하다.

**형식 1 — 조건 비교**

```sql
CASE
    WHEN 조건1 THEN 결과1
    WHEN 조건2 THEN 결과2

    ELSE 기본결과
END
```

**실습**: 가격대별 상품 등급 분류

```sql
    price,

        WHEN price < 20000            THEN '저가'
        WHEN price BETWEEN 20000 AND 49999 THEN '중가'
        WHEN price >= 50000           THEN '고가'

FROM product
ORDER BY price;
```


## 5. 데이터 유형 변환 CAST · CONVERT

### 5.1 묵시적 변환 vs 명시적 변환

**묵시적 변환(Implicit Conversion)**은 MariaDB가 자동으로 유형을 변환하는 것이다.  
**명시적 변환(Explicit Conversion)**은 `CAST()`나 `CONVERT()`로 직접 변환하는 것이다.

**묵시적 변환 예시**

```sql
SELECT '100' + 50;     -- 결과: 150  (문자 '100' → 숫자 100으로 자동 변환)
SELECT '100원' + 50;   -- 결과: 150  (숫자로 시작하는 문자는 숫자 부분만 사용)
SELECT 'abc' + 50;     -- 결과: 50   (숫자로 변환 불가능하면 0으로 처리)
SELECT '2024-01-15' + 0; -- 결과: 2024 (날짜 형식 문자열의 숫자 부분)
```

> ⚠️ **묵시적 변환의 위험성**: 예상치 못한 결과가 나올 수 있다. 유형 변환이 필요할 때는 명시적 변환을 사용하는 것이 안전하다.

---

### 5.2 CAST

```sql
CAST(값 AS 유형)
```

**지원 유형**

| 유형 | 설명 |
|---|---|
| `SIGNED` | 부호 있는 정수 |
| `UNSIGNED` | 부호 없는 정수 |
| `DECIMAL(p,s)` | 소수 |
| `CHAR(n)` | 문자열 |
| `DATE` | 날짜 |
| `DATETIME` | 날짜+시간 |
| `TIME` | 시간 |
| `JSON` | JSON |

```sql
SELECT
    CAST('25000'      AS UNSIGNED)    AS 문자를숫자로,    -- 25000
    CAST(25000        AS CHAR)        AS 숫자를문자로,    -- '25000'
    CAST('2024-01-15' AS DATE)        AS 문자를날짜로,    -- 2024-01-15
    CAST(44700.7      AS SIGNED)      AS 소수를정수로,    -- 44700 (버림)
    CAST('3.14'       AS DECIMAL(5,2)) AS 문자를소수로;   -- 3.14
```

**실습**: 문자열로 저장된 날짜를 날짜 유형으로 변환하여 비교

```sql
-- 날짜를 문자열로 비교 (주의: 예상치 못한 결과 가능)
SELECT * FROM orders WHERE order_date > '2024-03-01';

-- 명시적 변환 후 비교 (안전)
SELECT * FROM orders WHERE order_date > CAST('2024-03-01' AS DATE);
```

---

### 5.3 CONVERT

`CAST()`와 유사하지만 문자 인코딩 변환에도 사용할 수 있다.

```sql
-- 유형 변환 (CAST와 동일)
CONVERT(값, 유형)

-- 문자 인코딩 변환
CONVERT(값 USING 문자셋)
```

```sql
SELECT CONVERT('25000', UNSIGNED);         -- 25000
SELECT CONVERT('hello', CHAR(3));           -- 'hel' (3자리로 잘림)
SELECT CONVERT('한글' USING utf8mb4);      -- 인코딩 변환
```

---

### 5.4 실무 활용 예시

**숫자를 문자열로 변환하여 CONCAT에 사용**

```sql
-- ❌ 오류: 숫자와 문자열을 직접 CONCAT하면 예상치 못한 결과
-- ✅ 올바른 방법: CAST로 먼저 변환
SELECT CONCAT('주문번호: ', CAST(order_id AS CHAR), ' / 금액: ',
              FORMAT(unit_price, 0), '원') AS 주문요약
FROM order_detail
LIMIT 3;
```

**날짜 연산 전 유형 확인**

```sql
-- 문자열 날짜를 DATE로 변환 후 날짜 함수 적용
SELECT DATEDIFF(CURDATE(), CAST('2024-01-01' AS DATE)) AS 경과일;
```

---

### 5.5 유형 변환 함수 비교

| 상황 | 권장 함수 |
|---|---|
| 일반 유형 변환 | `CAST(값 AS 유형)` |
| MySQL 호환 유형 변환 | `CONVERT(값, 유형)` |
| 문자 인코딩 변환 | `CONVERT(값 USING 문자셋)` |
| NULL 대체 | `IFNULL(값, 대체값)` |
| 첫 번째 NULL 아닌 값 | `COALESCE(값1, 값2, ...)` |
