## 3.1 문자열 기초

2장에서 문자열(str)이 글자들의 모음이라는 것을 배웠어요. 이번 장에서는 문자열을 자유롭게 다루는 방법을 익혀봅니다. 데이터 분석에서 다루는 데이터의 상당 부분이 텍스트 형태이기 때문에 문자열 처리 능력은 매우 중요합니다.

### 문자열과 인덱스

문자열은 각 글자에 **인덱스(index)** 라는 번호가 붙어 있어요. 인덱스는 **0부터** 시작합니다.

```
문 자 열:  P  y  t  h  o  n
인덱스:    0  1  2  3  4  5
```

대괄호 `[]` 안에 인덱스를 넣으면 해당 위치의 글자를 가져올 수 있어요.

```python
word = "Python"

print(word[0])   # P
print(word[1])   # y
print(word[5])   # n
```

**실행 결과**
```
P
y
n
```

인덱스에 **음수**를 사용하면 뒤에서부터 셀 수 있어요.

```
문 자 열:  P  y  t  h  o  n
음수 인덱스: -6 -5 -4 -3 -2 -1
```

```python
word = "Python"

print(word[-1])   # n  (마지막 글자)
print(word[-2])   # o  (뒤에서 두 번째)
```

**실행 결과**
```
n
o
```

### 문자열 길이

`len()` 함수로 문자열의 길이(글자 수)를 구할 수 있습니다.

```python
word = "Python"
sentence = "안녕하세요"

print(len(word))      # 6
print(len(sentence))  # 5
```

**실행 결과**
```
6
5
```

## 3.2 슬라이싱

**슬라이싱(slicing)** 은 문자열의 일부를 잘라내는 기능입니다. 마치 빵을 원하는 두께로 잘라내듯이, 원하는 부분만 추출할 수 있어요.

### 기본 슬라이싱

`[시작:끝]` 형식으로 사용합니다. **시작 인덱스는 포함되고, 끝 인덱스는 포함되지 않습니다.**

```python
word = "Python"

print(word[0:3])   # Pyt  (0, 1, 2번 인덱스)
print(word[2:5])   # tho  (2, 3, 4번 인덱스)
print(word[1:4])   # yth  (1, 2, 3번 인덱스)
```

**실행 결과**
```
Pyt
tho
yth
```

### 시작·끝 생략

시작이나 끝을 생략하면 각각 문자열의 처음과 끝까지를 의미합니다.

```python
word = "Python"

print(word[:3])    # Pyt  (처음부터 2번 인덱스까지)
print(word[3:])    # hon  (3번 인덱스부터 끝까지)
print(word[:])     # Python  (전체)
```

**실행 결과**
```
Pyt
hon
Python
```

### 간격(step) 지정

`[시작:끝:간격]` 형식으로 몇 칸씩 건너뛸지 지정할 수 있어요.

```python
word = "Python"

print(word[::2])    # Pto  (한 칸씩 건너뜀)
print(word[::-1])   # nohtyP  (거꾸로 뒤집기)
```

**실행 결과**
```
Pto
nohtyP
```

> **📌 활용 팁:** `문자열[::-1]`은 문자열을 뒤집는 가장 간단한 방법입니다. 회문(앞뒤로 읽어도 같은 단어) 판별 등에 활용할 수 있어요.

### 슬라이싱 실전 활용

```python
email = "hong@example.com"

# @ 앞부분(아이디) 추출
at_index = email.index("@")
user_id = email[:at_index]
print("아이디:", user_id)    # 아이디: hong

# 확장자 추출 (뒤에서 3글자)
extension = email[-3:]
print("확장자:", extension)  # 확장자: com
```

**실행 결과**
```
아이디: hong
확장자: com
```

## 3.3 split · join · replace

### split() — 문자열 나누기

`split()`은 특정 구분자를 기준으로 문자열을 나눠 **리스트**로 반환합니다. 구분자를 생략하면 공백(스페이스, 탭, 줄 바꿈)을 기준으로 나눠요.

```python
sentence = "파이썬 데이터 분석 입문"
words = sentence.split()
print(words)   # ['파이썬', '데이터', '분석', '입문']

csv_data = "홍길동,25,서울,데이터분석"
fields = csv_data.split(",")
print(fields)  # ['홍길동', '25', '서울', '데이터분석']
```

**실행 결과**
```
['파이썬', '데이터', '분석', '입문']
['홍길동', '25', '서울', '데이터분석']
```

> **📌 데이터 분석 활용:** CSV 파일의 한 줄은 쉼표로 구분된 문자열입니다. `split(",")` 으로 각 항목을 분리하는 방식이 자주 쓰여요.

나눌 횟수를 제한하려면 두 번째 인수로 최대 분리 횟수를 지정합니다.

```python
data = "홍길동:25:서울:개발자"
result = data.split(":", 2)   # 최대 2번만 분리
print(result)   # ['홍길동', '25', '서울:개발자']
```

---

### join() — 문자열 합치기

`join()`은 리스트의 항목들을 특정 구분자로 이어 붙여 하나의 문자열로 만듭니다. `split()`의 반대 동작이에요.

```python
words = ['파이썬', '데이터', '분석', '입문']

# 공백으로 이어 붙이기
result1 = " ".join(words)
print(result1)   # 파이썬 데이터 분석 입문

# 쉼표로 이어 붙이기
result2 = ",".join(words)
print(result2)   # 파이썬,데이터,분석,입문

# 구분자 없이 이어 붙이기
result3 = "".join(words)
print(result3)   # 파이썬데이터분석입문
```

**실행 결과**
```
파이썬 데이터 분석 입문
파이썬,데이터,분석,입문
파이썬데이터분석입문
```

---

### replace() — 문자열 바꾸기

`replace(찾을 문자열, 바꿀 문자열)`은 문자열 안에서 특정 부분을 찾아 다른 내용으로 바꿉니다.

```python
sentence = "파이썬은 어렵다. 파이썬은 복잡하다."

# '파이썬'을 'Python'으로 모두 바꾸기
result = sentence.replace("파이썬", "Python")
print(result)   # Python은 어렵다. Python은 복잡하다.

# 특정 횟수만 바꾸기 (세 번째 인수)
result2 = sentence.replace("파이썬", "Python", 1)
print(result2)  # Python은 어렵다. 파이썬은 복잡하다.
```

**실행 결과**
```
Python은 어렵다. Python은 복잡하다.
Python은 어렵다. 파이썬은 복잡하다.
```

공백이나 특정 문자를 제거할 때도 활용할 수 있어요.

```python
phone = "010-1234-5678"
clean_phone = phone.replace("-", "")
print(clean_phone)   # 01012345678
```

## 3.4 f-string 포맷팅

**f-string** 은 문자열 안에 변수나 식을 바로 넣을 수 있는 방법입니다. 문자열 앞에 `f`를 붙이고, 넣고 싶은 변수나 식을 `{}` 안에 작성해요.

### 기본 사용법

```python
name = "홍길동"
age = 25

# 기존 방식 (+ 연산자 사용)
print("이름: " + name + ", 나이: " + str(age))

# f-string 방식 (훨씬 간결!)
print(f"이름: {name}, 나이: {age}")
```

**실행 결과**
```
이름: 홍길동, 나이: 25
이름: 홍길동, 나이: 25
```

### 식(계산) 삽입

`{}` 안에 계산식을 직접 넣을 수도 있어요.

```python
price = 12000
count = 3

print(f"단가: {price}원, 수량: {count}개, 합계: {price * count}원")
```

**실행 결과**
```
단가: 12000원, 수량: 3개, 합계: 36000원
```

### 소수점 자릿수 지정

`{변수:.자릿수f}` 형식으로 소수점 자릿수를 지정할 수 있어요.

```python
pi = 3.141592653589793

print(f"π ≈ {pi:.2f}")   # 소수점 둘째 자리
print(f"π ≈ {pi:.4f}")   # 소수점 넷째 자리
```

**실행 결과**
```
π ≈ 3.14
π ≈ 3.1416
```

### 천 단위 구분 기호

`{변수:,}` 형식으로 숫자에 천 단위 쉼표를 자동으로 붙일 수 있습니다.

```python
salary = 3500000
print(f"월급: {salary:,}원")   # 월급: 3,500,000원
```

**실행 결과**
```
월급: 3,500,000원
```

### 정렬과 너비 지정

출력 너비를 고정하고 정렬 방향을 지정할 수 있어요. 표 형식의 출력을 만들 때 유용합니다.

```python
# <: 왼쪽 정렬, >: 오른쪽 정렬, ^: 가운데 정렬
print(f"{'이름':<10}{'점수':>5}")
print(f"{'홍길동':<10}{95:>5}")
print(f"{'김철수':<10}{87:>5}")
print(f"{'이영희':<10}{100:>5}")
```

**실행 결과**
```
이름          점수
홍길동          95
김철수          87
이영희         100
```

## 3.5 자주 쓰는 문자열 메서드

**메서드(method)** 는 특정 자료형이 가진 기능입니다. `변수.메서드()` 형식으로 사용해요.

### 대소문자 변환

```python
text = "Hello, Python!"

print(text.upper())      # HELLO, PYTHON!  (모두 대문자)
print(text.lower())      # hello, python!  (모두 소문자)
print(text.capitalize()) # Hello, python!  (첫 글자만 대문자)
print(text.title())      # Hello, Python!  (각 단어 첫 글자 대문자)
```

**실행 결과**
```
HELLO, PYTHON!
hello, python!
Hello, python!
Hello, Python!
```

### 공백 제거

사용자 입력이나 파일에서 읽은 데이터에는 앞뒤로 불필요한 공백이 있는 경우가 많아요.

```python
text = "   안녕하세요   "

print(text.strip())    # "안녕하세요"  (앞뒤 공백 제거)
print(text.lstrip())   # "안녕하세요   "  (왼쪽 공백만 제거)
print(text.rstrip())   # "   안녕하세요"  (오른쪽 공백만 제거)
```

**실행 결과**
```
안녕하세요
안녕하세요   
   안녕하세요
```

### 포함 여부 확인

```python
sentence = "파이썬으로 데이터 분석을 배웁니다"

print("데이터" in sentence)      # True
print("머신러닝" in sentence)    # False
print("파이썬" not in sentence)  # False
```

**실행 결과**
```
True
False
False
```

### 시작·끝 문자열 확인

```python
filename = "report_2024.csv"

print(filename.startswith("report"))  # True
print(filename.endswith(".csv"))       # True
print(filename.endswith(".xlsx"))      # False
```

**실행 결과**
```
True
True
False
```

> **📌 데이터 분석 활용:** 파일 목록에서 특정 확장자 파일만 골라낼 때 `endswith()`를 자주 사용합니다.

### 위치 찾기

```python
sentence = "파이썬은 배우기 쉬운 언어입니다"

print(sentence.find("배우기"))    # 6  (찾으면 시작 인덱스 반환)
print(sentence.find("어렵다"))    # -1 (없으면 -1 반환)
print(sentence.index("쉬운"))     # 10 (찾으면 시작 인덱스 반환)
# sentence.index("어렵다")        # 없으면 오류 발생
```

**실행 결과**
```
6
-1
10
```

> **📌 참고:** `find()`는 찾지 못하면 `-1`을 반환하고, `index()`는 오류를 발생시킵니다. 찾지 못할 수도 있는 경우에는 `find()`를 쓰는 것이 안전해요.

### 개수 세기

```python
sentence = "banana"

print(sentence.count("a"))    # 3
print(sentence.count("na"))   # 2
```

**실행 결과**
```
3
2
```

### 자주 쓰는 문자열 메서드 요약

| 메서드 | 기능 | 예시 |
|---|---|---|
| `upper()` | 모두 대문자로 | `"hello".upper()` → `"HELLO"` |
| `lower()` | 모두 소문자로 | `"HELLO".lower()` → `"hello"` |
| `strip()` | 앞뒤 공백 제거 | `"  hi  ".strip()` → `"hi"` |
| `split()` | 구분자로 분리 | `"a,b".split(",")` → `['a', 'b']` |
| `join()` | 리스트를 문자열로 | `",".join(['a','b'])` → `"a,b"` |
| `replace()` | 문자열 교체 | `"ab".replace("a","x")` → `"xb"` |
| `find()` | 위치 찾기 | `"hello".find("l")` → `2` |
| `count()` | 개수 세기 | `"banana".count("a")` → `3` |
| `startswith()` | 시작 문자열 확인 | `"abc".startswith("a")` → `True` |
| `endswith()` | 끝 문자열 확인 | `"abc".endswith("c")` → `True` |

## 3.6 실전 예제

지금까지 배운 문자열 기능을 활용해 간단한 연락처 카드 생성기를 만들어 봅시다.

### 예제: 연락처 카드 생성기

```python
print("=" * 40)
print("       연락처 카드 생성기")
print("=" * 40)

# 사용자 입력
full_name = input("이름을 입력하세요: ")
email = input("이메일을 입력하세요: ")
phone = input("전화번호를 입력하세요 (예: 010-1234-5678): ")

# 데이터 가공
name_upper = full_name.upper()          # 이름을 대문자로
email_clean = email.strip().lower()     # 공백 제거 후 소문자로
phone_clean = phone.replace("-", "")    # 전화번호에서 '-' 제거

# 이메일에서 아이디 추출
at_index = email_clean.find("@")
user_id = email_clean[:at_index]

# 결과 출력
print()
print("=" * 40)
print(f"  이름  : {full_name}")
print(f"  영문  : {name_upper}")
print(f"  이메일: {email_clean}")
print(f"  아이디: {user_id}")
print(f"  전화  : {phone_clean[:3]}-{phone_clean[3:7]}-{phone_clean[7:]}")
print("=" * 40)
```

**실행 예시**
```
========================================
       연락처 카드 생성기
========================================
이름을 입력하세요: 홍길동
이메일을 입력하세요:  Hong@Example.com 
전화번호를 입력하세요 (예: 010-1234-5678): 010-9876-5432

========================================
  이름  : 홍길동
  영문  : 홍길동
  이메일: hong@example.com
  아이디: hong
  전화  : 010-9876-5432
========================================
```

### 코드 설명

- `email.strip().lower()` : 메서드를 연속으로 이어 쓸 수 있습니다. 앞 메서드의 결과에 바로 다음 메서드를 적용해요. 이것을 **메서드 체이닝**이라고 합니다.
- `email_clean.find("@")` : `@`의 위치를 찾아 그 앞부분(`[:at_index]`)을 아이디로 추출합니다.
- `phone_clean[:3]`, `phone_clean[3:7]`, `phone_clean[7:]` : 슬라이싱으로 전화번호를 세 구간으로 나눈 뒤 `-`로 다시 이어 붙입니다.

### 직접 해보기

연락처 카드에 다음 기능을 추가해 보세요.

- 전화번호 자릿수가 11자리인지 확인하고, 아니면 "올바른 전화번호가 아닙니다"를 출력

힌트: `in` 연산자와 `len()` 함수를 활용해 보세요!

> **📌 3장 정리**
> - 문자열의 각 글자에는 0부터 시작하는 인덱스가 붙어 있으며, 음수 인덱스로 뒤에서부터 접근할 수 있습니다.
> - 슬라이싱 `[시작:끝:간격]`으로 문자열의 원하는 부분을 추출할 수 있습니다.
> - `split()`으로 문자열을 나누고, `join()`으로 리스트를 문자열로 합칩니다.
> - `replace()`로 특정 문자열을 다른 내용으로 바꿀 수 있습니다.
> - f-string(`f"..."`)을 사용하면 변수와 식을 문자열 안에 간결하게 넣을 수 있습니다.
> - `strip()`, `upper()`, `lower()`, `find()`, `count()` 등 다양한 메서드로 문자열을 가공합니다.
