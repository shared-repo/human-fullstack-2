## 8.1 모듈과 패키지란?

### 모듈 (Module)

지금까지 작성한 코드는 모두 하나의 파일 안에 담겨 있었어요. 그런데 프로그램이 커지면 모든 코드를 한 파일에 넣기 어려워지고, 다른 프로그램에서 같은 함수를 재사용하고 싶을 때도 생깁니다.

**모듈(module)** 은 파이썬 코드가 담긴 `.py` 파일입니다. 필요한 모듈을 불러와 그 안의 함수, 클래스, 변수를 사용할 수 있어요.

```
my_project/
  ├── main.py        ← 메인 코드
  ├── calculator.py  ← 계산 관련 함수 모음 (모듈)
  └── utils.py       ← 공통 유틸리티 함수 모음 (모듈)
```

### 패키지 (Package)

**패키지(package)** 는 여러 모듈을 폴더 단위로 묶은 것입니다. 규모가 큰 프로젝트에서 모듈을 주제별로 정리할 때 사용해요.

```
my_project/
  ├── main.py
  └── tools/              ← 패키지 (폴더)
        ├── __init__.py   ← 패키지임을 나타내는 파일
        ├── calculator.py
        └── formatter.py
```

파이썬에서 제공하는 **표준 라이브러리**도 패키지 형태로 이미 설치되어 있어, `import`로 바로 불러와 쓸 수 있습니다. `random`, `os`, `math` 등이 대표적이에요.

## 8.2 import 사용법

### 기본 import

`import 모듈이름` 형태로 모듈 전체를 불러옵니다. 모듈 안의 기능은 `모듈이름.기능` 형태로 사용해요.

```python
import math

print(math.pi)          # 3.141592653589793
print(math.sqrt(16))    # 4.0
print(math.ceil(3.2))   # 4  (올림)
print(math.floor(3.9))  # 3  (내림)
```

**실행 결과**
```
3.141592653589793
4.0
4
3
```

### from ~ import

모듈에서 특정 기능만 골라서 불러올 수 있습니다. 이 방식을 사용하면 모듈 이름 없이 바로 함수 이름만으로 호출할 수 있어요.

```python
from math import pi, sqrt

print(pi)        # 3.141592653589793
print(sqrt(25))  # 5.0
```

**실행 결과**
```
3.141592653589793
5.0
```

### 별칭 붙이기: as

모듈이나 함수에 짧은 별칭을 붙여 사용할 수 있습니다. 이름이 긴 모듈을 편리하게 쓸 때 유용해요. 데이터 분석에서 사용할 라이브러리들도 관례적인 별칭이 있습니다.

```python
import math as m

print(m.pi)       # 3.141592653589793
print(m.sqrt(9))  # 3.0
```

```python
# 데이터 분석에서 자주 보게 될 관례적 별칭들
import numpy as np          # NumPy
import pandas as pd         # Pandas
import matplotlib.pyplot as plt   # Matplotlib
```

> **📌 관례적 별칭:** `np`, `pd`, `plt` 같은 별칭은 전 세계 파이썬 커뮤니티에서 표준처럼 쓰이므로 그대로 따르는 것이 좋습니다. 다른 사람의 코드를 읽을 때도 바로 알아볼 수 있어요.

### 와일드카드 import (주의)

`from 모듈 import *` 는 모듈의 모든 것을 한꺼번에 불러옵니다. 편리해 보이지만 어떤 이름이 어디서 왔는지 알 수 없어 충돌이 생기기 쉬워요. 특별한 이유가 없다면 사용을 피하는 것이 좋습니다.

```python
# ❌ 권장하지 않는 방식
from math import *
print(pi)    # 어디서 온 pi인지 코드만 보면 알기 어려움

# ✅ 권장하는 방식
from math import pi
print(pi)
```

### import 위치

`import`는 관례적으로 **파일 맨 위**에 모아서 작성합니다. 어떤 모듈을 사용하는지 한눈에 파악할 수 있어요.

```python
# 파일 맨 위에 모아서 작성
import os
import math
from datetime import datetime

# 이후 코드 작성
print(datetime.now())
```

## 8.3 표준 라이브러리 맛보기

파이썬을 설치하면 별도 설치 없이 바로 사용할 수 있는 **표준 라이브러리**가 함께 제공됩니다. 자주 쓰는 세 가지를 살펴볼게요.

### random — 난수 생성

```python
import random

# 0.0 이상 1.0 미만의 실수 난수
print(random.random())           # 예: 0.7364...

# 지정 범위의 정수 난수 (양 끝값 포함)
print(random.randint(1, 10))     # 예: 7

# 리스트에서 무작위로 하나 선택
fruits = ["사과", "바나나", "딸기", "포도"]
print(random.choice(fruits))     # 예: 딸기

# 리스트를 무작위로 섞기 (원본 변경)
numbers = [1, 2, 3, 4, 5]
random.shuffle(numbers)
print(numbers)                   # 예: [3, 1, 5, 2, 4]

# 리스트에서 k개 무작위 추출
print(random.sample(range(1, 46), 6))  # 로또 번호 추출 예: [7, 15, 23, 31, 38, 42]
```

> **📌 재현 가능한 난수:** `random.seed(숫자)`를 설정하면 매번 같은 난수가 생성돼요. 데이터 분석에서 실험 결과를 재현할 때 유용하게 쓰입니다.

```python
random.seed(42)
print(random.randint(1, 100))   # 항상 같은 값 출력
```

### math — 수학 함수

```python
import math

# 기본 상수
print(math.pi)     # 3.141592653589793 (원주율)
print(math.e)      # 2.718281828459045 (자연상수)

# 제곱근, 거듭제곱
print(math.sqrt(144))    # 12.0  (제곱근)
print(math.pow(2, 10))   # 1024.0 (거듭제곱)

# 올림, 내림, 반올림
print(math.ceil(3.2))    # 4   (올림)
print(math.floor(3.9))   # 3   (내림)

# 로그
print(math.log(100, 10)) # 2.0  (밑이 10인 로그)
print(math.log2(8))      # 3.0  (밑이 2인 로그)

# 삼각함수 (라디안 단위)
print(math.sin(math.pi / 2))   # 1.0
print(math.degrees(math.pi))   # 180.0 (라디안 → 도)
```

### 자주 쓰는 math 함수 요약

| 함수 | 기능 | 예시 |
|---|---|---|
| `math.sqrt(x)` | 제곱근 | `sqrt(9)` → `3.0` |
| `math.pow(x, y)` | 거듭제곱 | `pow(2, 8)` → `256.0` |
| `math.ceil(x)` | 올림 | `ceil(3.1)` → `4` |
| `math.floor(x)` | 내림 | `floor(3.9)` → `3` |
| `math.log(x, base)` | 로그 | `log(100, 10)` → `2.0` |
| `math.pi` | 원주율 π | `3.14159...` |
| `math.e` | 자연상수 e | `2.71828...` |

### os — 운영체제 기능

`os` 모듈은 파일·폴더 경로 확인, 파일 목록 조회, 환경 변수 접근 등 운영체제와 관련된 기능을 제공합니다.

```python
import os

# 현재 작업 디렉터리 확인
print(os.getcwd())             # 예: /Users/username/project

# 특정 경로에 있는 파일·폴더 목록
print(os.listdir("."))         # 현재 폴더의 파일 목록

# 경로 조합 (운영체제에 맞는 구분자 자동 적용)
path = os.path.join("data", "2024", "result.csv")
print(path)                    # data/2024/result.csv (macOS/Linux)
                               # data\2024\result.csv (Windows)

# 파일·폴더 존재 여부 확인
print(os.path.exists("data"))     # True 또는 False
print(os.path.isfile("main.py"))  # True 또는 False
print(os.path.isdir("data"))      # True 또는 False

# 파일 이름과 확장자 분리
filename = "report_2024.csv"
name, ext = os.path.splitext(filename)
print(name)   # report_2024
print(ext)    # .csv
```

> **📌 데이터 분석 활용:** 데이터 파일이 담긴 폴더에서 CSV 파일 목록을 자동으로 읽어올 때 `os.listdir()`과 `endswith(".csv")`를 함께 자주 사용합니다.

```python
import os

data_folder = "data"
csv_files = [f for f in os.listdir(data_folder) if f.endswith(".csv")]
print(csv_files)   # ['sales_jan.csv', 'sales_feb.csv', ...]
```

### datetime — 날짜와 시간

데이터 분석에서 날짜 데이터를 자주 다루기 때문에 `datetime` 모듈도 알아두면 유용해요.

```python
from datetime import datetime, date, timedelta

# 현재 날짜와 시간
now = datetime.now()
print(now)                        # 2024-05-01 14:30:25.123456
print(now.strftime("%Y년 %m월 %d일 %H시 %M분"))  # 2024년 05월 01일 14시 30분

# 특정 날짜 만들기
birthday = date(1999, 3, 15)
print(birthday)                   # 1999-03-15

# 날짜 계산
today = date.today()
d_day = date(2024, 12, 31)
remaining = d_day - today
print(f"연말까지 {remaining.days}일 남았습니다.")

# 날짜 더하기·빼기
one_week_later = today + timedelta(days=7)
print(f"일주일 후: {one_week_later}")
```

## 8.4 pip로 외부 패키지 설치

### pip란?

**pip**는 파이썬의 패키지 관리 도구입니다. 전 세계 개발자들이 만들어 공유한 수십만 개의 패키지를 명령어 하나로 설치할 수 있어요. 패키지들은 **PyPI(Python Package Index)** 라는 저장소에 모여 있습니다.

### 패키지 설치

터미널(가상환경 활성화 상태)에서 아래 명령어를 실행합니다.

```
pip install 패키지이름
```

예를 들어 `requests` 패키지를 설치하려면 아래와 같이 입력해요.

```
pip install requests
```

> **💡 스크린샷:** 터미널에서 pip install 실행 화면

### 여러 패키지 한 번에 설치

```
pip install numpy pandas matplotlib
```

### 특정 버전 설치

```
pip install numpy==1.26.0
```

### 설치된 패키지 목록 확인

```
pip list
```

> **💡 스크린샷:** pip list 실행 결과 화면

### 패키지 삭제

```
pip uninstall 패키지이름
```

### requirements.txt 활용

프로젝트에서 사용하는 패키지 목록을 `requirements.txt` 파일로 관리하면 다른 환경에서도 동일한 패키지를 한 번에 설치할 수 있습니다.

```
# requirements.txt 파일 내용 예시
numpy==1.26.0
pandas==2.1.0
matplotlib==3.8.0
```

```
# requirements.txt 기반으로 한 번에 설치
pip install -r requirements.txt
```

### 데이터 분석을 위한 패키지 미리 설치하기

데이터 분석 과정에서 다룰 라이브러리를 미리 설치해 두면 좋습니다.

```
pip install numpy pandas matplotlib seaborn scikit-learn
```

| 패키지 | 용도 |
|---|---|
| `numpy` | 수치 계산, 배열 처리 |
| `pandas` | 표 형태 데이터 분석 |
| `matplotlib` | 데이터 시각화 |
| `seaborn` | 통계 시각화 (matplotlib 기반) |
| `scikit-learn` | 머신러닝 |

## 8.5 사용자 정의 모듈과 패키지

지금까지는 파이썬이 제공하는 모듈을 불러오는 방법을 배웠어요. 이번에는 직접 모듈과 패키지를 만들어 사용하는 방법을 알아봅니다.

---

### 사용자 정의 모듈 만들기

파이썬 파일(`.py`) 하나가 그대로 모듈이 됩니다. 예를 들어 자주 사용하는 계산 함수들을 `calculator.py` 파일로 만들어 보겠습니다.

**프로젝트 구조**
```
my_project/
  ├── main.py          ← 메인 코드
  └── calculator.py   ← 사용자 정의 모듈
```

**calculator.py**
```python
# 계산 관련 함수 모음

PI = 3.141592   # 모듈 수준의 변수

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "0으로 나눌 수 없습니다."
    return a / b

def circle_area(radius):
    return PI * radius ** 2
```

### 사용자 정의 모듈 불러오기

같은 폴더에 `main.py`를 만들고 `calculator.py`를 불러와 사용합니다. 불러오는 방법은 세 가지예요.

**방법 1: 모듈 전체 import**

```python
# main.py
import calculator

print(calculator.add(10, 5))          # 15
print(calculator.multiply(3, 7))      # 21
print(calculator.circle_area(5))      # 78.5398...
print(calculator.PI)                  # 3.141592
```

**방법 2: 특정 기능만 import**

```python
# main.py
from calculator import add, circle_area, PI

print(add(10, 5))         # 15  — 모듈 이름 없이 바로 사용
print(circle_area(5))     # 78.5398...
print(PI)                 # 3.141592
```

**방법 3: 별칭 붙여 import**

```python
# main.py
import calculator as calc

print(calc.add(10, 5))     # 15
print(calc.divide(10, 3))  # 3.333...
```

### `if __name__ == "__main__":`

모듈 파일을 직접 실행할 때와 다른 파일에서 불러올 때를 구분하는 관용적인 패턴입니다.

```python
# calculator.py

PI = 3.141592

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

# 이 파일을 직접 실행할 때만 아래 코드가 동작
if __name__ == "__main__":
    print("=== calculator 모듈 테스트 ===")
    print(f"add(3, 5)      = {add(3, 5)}")        # 8
    print(f"subtract(10, 4) = {subtract(10, 4)}")  # 6
```

`calculator.py`를 직접 실행하면 테스트 코드가 동작하지만, `main.py`에서 `import calculator`로 불러올 때는 테스트 코드가 실행되지 않습니다.

```
# calculator.py 직접 실행 시
=== calculator 모듈 테스트 ===
add(3, 5)       = 8
subtract(10, 4) = 6

# main.py에서 import 시 → 테스트 코드 실행 안 됨
```

### 사용자 정의 패키지 만들기

모듈이 많아지면 관련 모듈끼리 폴더로 묶어 **패키지**로 관리할 수 있어요. 패키지로 만들려면 폴더 안에 **`__init__.py`** 파일을 반드시 넣어야 합니다. 이 파일이 있어야 파이썬이 해당 폴더를 패키지로 인식해요.

**프로젝트 구조**
```
my_project/
  ├── main.py
  └── mytools/              ← 패키지 (폴더)
        ├── __init__.py     ← 패키지 선언 파일 (비어 있어도 됨)
        ├── calculator.py   ← 계산 모듈
        └── formatter.py    ← 출력 형식 모듈
```

**mytools/calculator.py**
```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "0으로 나눌 수 없습니다."
    return a / b
```

**mytools/formatter.py**
```python
def print_title(title):
    print("=" * 40)
    print(f"  {title}")
    print("=" * 40)

def print_result(label, value):
    print(f"  {label:<15}: {value}")
```

**mytools/\_\_init\_\_.py**
```python
# __init__.py — 패키지를 초기화하는 파일
# 비워두거나, 자주 쓰는 기능을 미리 불러와 편리하게 제공할 수 있습니다.

from .calculator import add, subtract   # 패키지 수준에서 바로 접근 가능하게
```

### 사용자 정의 패키지 불러오기

**방법 1: 모듈 단위로 import**

```python
# main.py
from mytools import calculator
from mytools import formatter

formatter.print_title("사칙연산 결과")
formatter.print_result("10 + 5", calculator.add(10, 5))
formatter.print_result("10 × 7", calculator.multiply(10, 7))
formatter.print_result("10 ÷ 3", calculator.divide(10, 3))
```

**실행 결과**
```
========================================
  사칙연산 결과
========================================
  10 + 5         : 15
  10 × 7         : 70
  10 ÷ 3         : 3.3333333333333335
```

**방법 2: 특정 함수만 import**

```python
# main.py
from mytools.calculator import add, multiply
from mytools.formatter import print_title, print_result

print_title("계산 결과")
print_result("덧셈", add(3, 7))
print_result("곱셈", multiply(4, 5))
```

**방법 3: \_\_init\_\_.py에서 미리 노출한 기능 사용**

`__init__.py`에서 `from .calculator import add, subtract`를 선언해 두었기 때문에 패키지 이름만으로 바로 접근할 수 있습니다.

```python
# main.py
import mytools

print(mytools.add(10, 5))       # 15  — 패키지 이름으로 바로 호출
print(mytools.subtract(10, 5))  # 5
```

### import 방식 비교 요약

| 방식 | 코드 예시 | 호출 방법 |
|---|---|---|
| 모듈 전체 | `import calculator` | `calculator.add(1, 2)` |
| 기능만 선택 | `from calculator import add` | `add(1, 2)` |
| 별칭 사용 | `import calculator as calc` | `calc.add(1, 2)` |
| 패키지의 모듈 | `from mytools import calculator` | `calculator.add(1, 2)` |
| 패키지의 특정 함수 | `from mytools.calculator import add` | `add(1, 2)` |
| \_\_init\_\_.py 노출 | `import mytools` | `mytools.add(1, 2)` |

## 8.6 실전 예제

지금까지 배운 모듈 활용 방법을 종합해 간단한 숫자 맞히기 게임을 만들어 봅시다.

### 예제: 숫자 맞히기 게임

```python
import random

def play_game(min_num=1, max_num=100, max_tries=7):
    """
    숫자 맞히기 게임
    - min_num ~ max_num 범위의 숫자를 max_tries번 안에 맞혀야 합니다.
    """
    answer = random.randint(min_num, max_num)
    tries = 0

    print("=" * 45)
    print(f"  🎯 숫자 맞히기 게임")
    print(f"  {min_num}~{max_num} 사이의 숫자를 {max_tries}번 안에 맞혀보세요!")
    print("=" * 45)

    while tries < max_tries:
        remaining = max_tries - tries
        try:
            guess = int(input(f"\n  숫자 입력 (남은 기회: {remaining}번): "))
        except ValueError:
            print("  숫자를 입력해 주세요.")
            continue

        tries += 1

        if guess < answer:
            print(f"  📉 {guess}보다 큽니다.")
        elif guess > answer:
            print(f"  📈 {guess}보다 작습니다.")
        else:
            print(f"\n  🎉 정답입니다! {tries}번 만에 맞혔어요!")
            break
    else:
        print(f"\n  😢 실패! 정답은 {answer}였습니다.")

    print("=" * 45)


# 게임 실행
play_game()
```

**실행 예시**
```
=============================================
  🎯 숫자 맞히기 게임
  1~100 사이의 숫자를 7번 안에 맞혀보세요!
=============================================

  숫자 입력 (남은 기회: 7번): 50
  📉 50보다 큽니다.

  숫자 입력 (남은 기회: 6번): 75
  📈 75보다 작습니다.

  숫자 입력 (남은 기회: 5번): 63
  📉 63보다 큽니다.

  숫자 입력 (남은 기회: 4번): 70
  🎉 정답입니다! 4번 만에 맞혔어요!
=============================================
```

### 코드 설명

- `import random` : 표준 라이브러리 `random`을 불러와 `randint()`로 정답을 생성합니다.
- `try ~ except ValueError` : 숫자가 아닌 값을 입력했을 때 오류 없이 처리합니다. 예외 처리는 9장에서 자세히 다뤄요.
- `while ~ else` : 기회를 모두 소진해 반복문이 정상 종료되면 `else` 블록을 실행합니다. (4장 참고)
- 함수 매개변수에 기본값(`min_num=1`, `max_num=100`, `max_tries=7`)을 설정해 게임 난이도를 쉽게 조절할 수 있어요.

> **📌 8장 정리**
> - **모듈**은 파이썬 코드가 담긴 `.py` 파일이고, **패키지**는 여러 모듈을 폴더로 묶은 것입니다.
> - `import 모듈`, `from 모듈 import 기능`, `import 모듈 as 별칭` 세 가지 방식으로 불러옵니다.
> - 표준 라이브러리 `random`(난수), `math`(수학), `os`(파일·경로), `datetime`(날짜·시간)을 설치 없이 바로 사용할 수 있습니다.
> - `pip install 패키지명`으로 외부 패키지를 설치하고, `requirements.txt`로 패키지 목록을 관리합니다.
> - `.py` 파일 하나가 모듈이 되고, `__init__.py`가 있는 폴더가 패키지가 됩니다. `if __name__ == "__main__":` 패턴으로 직접 실행과 임포트를 구분합니다.
> - 패키지 안의 모듈은 `from 패키지 import 모듈` 또는 `from 패키지.모듈 import 함수` 형태로 불러오고, `__init__.py`에서 자주 쓰는 기능을 미리 노출해 두면 더 간결하게 사용할 수 있습니다.
