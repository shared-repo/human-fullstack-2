# 7장. 객체와 클래스

## 7.1 객체란 무엇인가?

### 객체 지향 프로그래밍

지금까지는 변수와 함수를 따로 다뤘어요. 그런데 현실 세계의 사물을 프로그램으로 표현할 때는 데이터와 기능을 한데 묶어 생각하는 것이 더 자연스럽습니다.

예를 들어 "강아지"를 표현한다면 이런 요소들이 있어요.

- **데이터(속성)**: 이름, 나이, 품종
- **기능(행동)**: 짖기, 먹기, 달리기

이처럼 **데이터(속성)와 기능(메서드)를 하나의 단위로 묶어 다루는 방식**을 **객체 지향 프로그래밍(Object-Oriented Programming, OOP)** 이라고 합니다.

### 클래스와 객체의 관계

- **클래스(class)**: 객체를 만들기 위한 **설계도**입니다.
- **객체(object)**: 설계도를 바탕으로 만들어진 **실체**입니다.

붕어빵 틀(클래스)과 붕어빵(객체)의 관계를 생각하면 쉬워요. 틀은 하나지만 붕어빵은 여러 개 만들 수 있고, 각각 다른 재료(팥, 슈크림 등)를 넣을 수 있습니다.

```
클래스 (설계도)        객체 (실체)
─────────────        ──────────────────────────
강아지               뽀삐 (말티즈, 3살)
                     초코 (푸들, 5살)
                     콩이 (시바견, 2살)
```

사실 파이썬에서는 우리가 이미 객체를 사용하고 있었어요. 문자열, 리스트, 딕셔너리 모두 객체입니다. `"hello".upper()`, `[1,2,3].append(4)` 같은 메서드 호출이 바로 객체의 기능을 사용하는 것이에요.

## 7.2 클래스 만들기

### 기본 클래스 정의

`class` 키워드로 클래스를 정의합니다. 클래스 이름은 관례적으로 **첫 글자를 대문자**로 써요.

```python
class Dog:
    pass   # 내용이 없을 때 pass로 채움
```

### 객체(인스턴스) 생성

클래스 이름 뒤에 `()`를 붙이면 객체가 만들어집니다. 클래스로부터 만들어진 객체를 **인스턴스(instance)** 라고도 해요.

```python
class Dog:
    pass

dog1 = Dog()   # 객체 생성
dog2 = Dog()   # 또 다른 객체 생성

print(type(dog1))   # <class '__main__.Dog'>
print(dog1 == dog2) # False — 같은 클래스지만 서로 다른 객체
```

**실행 결과**
```
<class '__main__.Dog'>
False
```

## 7.3 속성과 메서드

### 속성 (Attribute)

**속성**은 객체가 가진 데이터입니다. 객체를 만든 후 `.` 뒤에 이름을 붙여 속성을 추가하거나 접근할 수 있어요.

```python
class Dog:
    pass

dog1 = Dog()
dog1.name = "뽀삐"    # 속성 추가
dog1.age = 3
dog1.breed = "말티즈"

print(dog1.name)    # 뽀삐
print(dog1.age)     # 3
print(dog1.breed)   # 말티즈
```

**실행 결과**
```
뽀삐
3
말티즈
```

하지만 이 방식은 객체를 만들 때마다 속성을 일일이 추가해야 해서 불편해요. 이 문제를 해결하는 것이 바로 `__init__` 생성자입니다.

### 메서드 (Method)

**메서드**는 클래스 안에 정의된 함수입니다. 일반 함수와 다른 점은 첫 번째 매개변수로 반드시 **`self`** 를 받아야 한다는 것이에요. `self`는 메서드를 호출한 객체 자신을 가리킵니다.

```python
class Dog:
    def bark(self):
        print("멍멍!")

    def run(self):
        print("달립니다!")

dog1 = Dog()
dog1.bark()   # 멍멍!
dog1.run()    # 달립니다!
```

**실행 결과**
```
멍멍!
달립니다!
```

### 인스턴스 변수와 클래스 변수

속성에는 두 가지 종류가 있습니다.

- **인스턴스 변수(instance variable)**: `self.변수명` 형태로 정의하며, **객체마다 독립적으로** 가지는 값입니다.
- **클래스 변수(class variable)**: 클래스 안, 메서드 밖에서 정의하며, **모든 객체가 공유**하는 값입니다.

```python
class Dog:
    species = "포유류"   # 클래스 변수 — 모든 Dog 객체가 공유

    def __init__(self, name, age):
        self.name = name   # 인스턴스 변수 — 객체마다 다름
        self.age = age     # 인스턴스 변수 — 객체마다 다름

dog1 = Dog("뽀삐", 3)
dog2 = Dog("초코", 5)

# 인스턴스 변수: 객체마다 다른 값
print(dog1.name)   # 뽀삐
print(dog2.name)   # 초코

# 클래스 변수: 모든 객체가 같은 값
print(dog1.species)   # 포유류
print(dog2.species)   # 포유류

# 클래스 이름으로도 접근 가능
print(Dog.species)    # 포유류
```

**실행 결과**
```
뽀삐
초코
포유류
포유류
포유류
```

### 클래스 변수 수정 시 주의사항

클래스 변수를 수정할 때는 반드시 **클래스 이름**을 통해 바꿔야 합니다. 객체를 통해 바꾸면 해당 객체에만 새로운 인스턴스 변수가 생기고, 클래스 변수는 그대로 유지됩니다.

```python
class Dog:
    species = "포유류"

    def __init__(self, name):
        self.name = name

dog1 = Dog("뽀삐")
dog2 = Dog("초코")

# 클래스 변수를 클래스 이름으로 수정 → 모든 객체에 반영
Dog.species = "개과 포유류"
print(dog1.species)   # 개과 포유류
print(dog2.species)   # 개과 포유류

# 객체를 통해 수정 → 해당 객체에만 인스턴스 변수가 생김 (클래스 변수는 그대로)
dog1.species = "동물"
print(dog1.species)   # 동물      ← dog1의 인스턴스 변수
print(dog2.species)   # 개과 포유류  ← 클래스 변수 그대로
print(Dog.species)    # 개과 포유류  ← 클래스 변수 그대로
```

**실행 결과**
```
개과 포유류
개과 포유류
동물
개과 포유류
개과 포유류
```

### 클래스 변수 활용 — 객체 수 세기

클래스 변수는 **생성된 객체의 수를 세거나, 모든 객체가 공유해야 하는 설정값**을 저장할 때 자주 사용합니다.

```python
class Dog:
    count = 0   # 생성된 Dog 객체 수

    def __init__(self, name):
        self.name = name
        Dog.count += 1   # 객체가 만들어질 때마다 1 증가

dog1 = Dog("뽀삐")
dog2 = Dog("초코")
dog3 = Dog("콩이")

print(f"현재 등록된 강아지 수: {Dog.count}마리")   # 3마리
```

**실행 결과**
```
현재 등록된 강아지 수: 3마리
```

### 인스턴스 변수 vs 클래스 변수 비교

| 구분 | 인스턴스 변수 | 클래스 변수 |
|---|---|---|
| 정의 위치 | `__init__` 안, `self.변수명` | 클래스 안, 메서드 밖 |
| 공유 범위 | 객체마다 독립적 | 모든 객체가 공유 |
| 접근 방법 | `객체.변수명` | `클래스.변수명` 또는 `객체.변수명` |
| 수정 방법 | `self.변수명 = 값` | `클래스이름.변수명 = 값` |
| 주요 용도 | 이름, 나이 등 개별 데이터 | 공유 설정값, 객체 수 집계 등 |

### 메서드의 종류: 일반 메서드 · 클래스 메서드 · 정적 메서드

클래스 안에서 정의할 수 있는 메서드는 세 가지입니다.

| 종류 | 첫 번째 인수 | 데코레이터 | 접근 대상 |
|---|---|---|---|
| 일반 메서드 | `self` | 없음 | 인스턴스 변수, 클래스 변수 모두 |
| 클래스 메서드 | `cls` | `@classmethod` | 클래스 변수 |
| 정적 메서드 | 없음 | `@staticmethod` | 없음 (독립적인 유틸리티) |

> **📌 데코레이터란?** 함수나 메서드의 동작을 수정하는 `@` 기호로 시작하는 문법입니다. 메서드 바로 위에 붙여 사용해요.

#### @classmethod

`@classmethod`는 **클래스 자체를 다루는 메서드**입니다. 첫 번째 인수로 클래스를 뜻하는 `cls`를 받아요. 클래스 변수를 읽거나 수정할 때, 또는 객체를 만드는 또 다른 방법을 제공할 때 사용합니다.

```python
class Dog:
    count = 0   # 클래스 변수

    def __init__(self, name):
        self.name = name
        Dog.count += 1

    @classmethod
    def get_count(cls):
        print(f"현재 등록된 강아지 수: {cls.count}마리")

    @classmethod
    def from_string(cls, info):
        """'이름:나이' 형식의 문자열로 객체를 생성하는 클래스 메서드"""
        name, age = info.split(":")
        return cls(name)   # cls(...)는 Dog(...)와 동일


dog1 = Dog("뽀삐")
dog2 = Dog.from_string("초코:5")   # 클래스 메서드로 객체 생성

Dog.get_count()   # 현재 등록된 강아지 수: 2마리
```

**실행 결과**
```
현재 등록된 강아지 수: 2마리
```

#### @staticmethod

`@staticmethod`는 **클래스나 인스턴스와 직접 관련 없는 독립적인 기능**을 클래스 안에 묶어두고 싶을 때 사용합니다. `self`도 `cls`도 받지 않아요. 클래스와 논리적으로 관련은 있지만, 객체나 클래스 변수에 접근할 필요가 없는 유틸리티 함수에 적합합니다.

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @staticmethod
    def is_valid_age(age):
        """나이가 유효한 값인지 확인하는 정적 메서드"""
        return 0 < age <= 30

# 객체 없이 클래스 이름으로 바로 호출
print(Dog.is_valid_age(3))    # True
print(Dog.is_valid_age(-1))   # False
print(Dog.is_valid_age(50))   # False
```

**실행 결과**
```
True
False
False
```

> **📌 라이브러리 코드를 읽을 때:** 외부 라이브러리 코드에서 `@classmethod`나 `@staticmethod`를 보게 되면, 전자는 "클래스 수준의 동작을 다루는 메서드", 후자는 "클래스와 관련은 있지만 독립적으로 동작하는 함수"라고 이해하면 됩니다.

## 7.4 생성자: __init__

### __init__ 이란?

**`__init__`** 은 객체가 만들어질 때 자동으로 호출되는 특별한 메서드입니다. 속성의 초기값을 설정하는 데 사용해요. **생성자(constructor)** 라고도 부릅니다.

앞뒤로 밑줄 두 개(`__`)가 붙은 메서드를 **매직 메서드(magic method)** 또는 **던더 메서드(dunder method)** 라고 해요.

```python
class Dog:
    def __init__(self, name, age, breed):
        self.name = name     # 속성 초기화
        self.age = age
        self.breed = breed

    def bark(self):
        print(f"{self.name}: 멍멍!")

    def info(self):
        print(f"이름: {self.name}, 나이: {self.age}살, 품종: {self.breed}")


# 객체 생성 시 인수 전달
dog1 = Dog("뽀삐", 3, "말티즈")
dog2 = Dog("초코", 5, "푸들")

dog1.bark()   # 뽀삐: 멍멍!
dog2.bark()   # 초코: 멍멍!

dog1.info()   # 이름: 뽀삐, 나이: 3살, 품종: 말티즈
dog2.info()   # 이름: 초코, 나이: 5살, 품종: 푸들
```

**실행 결과**
```
뽀삐: 멍멍!
초코: 멍멍!
이름: 뽀삐, 나이: 3살, 품종: 말티즈
이름: 초코, 나이: 5살, 품종: 푸들
```

`self.name = name` 에서 왼쪽 `self.name`은 **객체의 속성**이고, 오른쪽 `name`은 **`__init__`에 전달된 매개변수**입니다. 이 한 줄로 매개변수 값을 객체 속성에 저장해요.

### __str__ 메서드

`__str__`은 객체를 `print()`로 출력할 때 어떻게 표시할지 정의하는 매직 메서드입니다.

```python
class Dog:
    def __init__(self, name, age, breed):
        self.name = name
        self.age = age
        self.breed = breed

    def __str__(self):
        return f"Dog({self.name}, {self.age}살, {self.breed})"


dog1 = Dog("뽀삐", 3, "말티즈")
print(dog1)   # Dog(뽀삐, 3살, 말티즈)
```

**실행 결과**
```
Dog(뽀삐, 3살, 말티즈)
```

`__str__` 없이 출력하면 `<__main__.Dog object at 0x...>` 처럼 이해하기 어려운 메모리 주소가 나와요. `__str__`을 정의해 두면 보기 좋게 출력할 수 있습니다.

### 메서드에서 속성 수정하기

메서드 안에서 `self`를 통해 속성 값을 변경할 수 있습니다.

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def birthday(self):
        self.age += 1
        print(f"{self.name}의 생일입니다! 이제 {self.age}살이에요.")


dog1 = Dog("뽀삐", 3)
dog1.birthday()   # 뽀삐의 생일입니다! 이제 4살이에요.
dog1.birthday()   # 뽀삐의 생일입니다! 이제 5살이에요.
print(dog1.age)   # 5
```

**실행 결과**
```
뽀삐의 생일입니다! 이제 4살이에요.
뽀삐의 생일입니다! 이제 5살이에요.
5
```

## 7.5 상속 기초

### 상속이란?

**상속(inheritance)** 은 기존 클래스의 속성과 메서드를 물려받아 새 클래스를 만드는 기능입니다. 공통된 부분을 한 번만 작성하고 재사용할 수 있어요.

- **부모 클래스(parent class)**: 속성과 메서드를 물려주는 클래스
- **자식 클래스(child class)**: 물려받아 확장하는 클래스

```
동물 (부모 클래스)
  ├── 속성: 이름, 나이
  └── 메서드: eat(), sleep()
       │
       ├── 강아지 (자식 클래스) — 추가: breed, bark()
       └── 고양이 (자식 클래스) — 추가: indoor, meow()
```

### 상속 구현하기

클래스를 정의할 때 괄호 안에 부모 클래스 이름을 넣으면 됩니다.

```python
# 부모 클래스
class Animal:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def eat(self):
        print(f"{self.name}이(가) 밥을 먹습니다.")

    def sleep(self):
        print(f"{self.name}이(가) 잠을 잡니다.")


# 자식 클래스 — Animal을 상속
class Dog(Animal):
    def __init__(self, name, age, breed):
        super().__init__(name, age)   # 부모의 __init__ 호출
        self.breed = breed            # 자식 클래스만의 속성 추가

    def bark(self):                   # 자식 클래스만의 메서드 추가
        print(f"{self.name}: 멍멍!")


class Cat(Animal):
    def __init__(self, name, age, indoor):
        super().__init__(name, age)
        self.indoor = indoor

    def meow(self):
        print(f"{self.name}: 야옹~")


# 객체 생성 및 사용
dog = Dog("뽀삐", 3, "말티즈")
cat = Cat("나비", 4, True)

dog.eat()    # 부모 메서드 사용 → 뽀삐이(가) 밥을 먹습니다.
dog.bark()   # 자식 메서드 사용 → 뽀삐: 멍멍!

cat.sleep()  # 부모 메서드 사용 → 나비이(가) 잠을 잡니다.
cat.meow()   # 자식 메서드 사용 → 나비: 야옹~
```

**실행 결과**
```
뽀삐이(가) 밥을 먹습니다.
뽀삐: 멍멍!
나비이(가) 잠을 잡니다.
나비: 야옹~
```

### super()란?

`super()`는 부모 클래스를 참조하는 방법입니다. 자식 클래스의 `__init__`에서 `super().__init__(...)`을 호출해 부모의 초기화 코드를 실행해요. 이렇게 하면 부모 클래스의 속성(`name`, `age`)을 자식도 그대로 가질 수 있습니다.

### 메서드 오버라이딩 (Overriding)

자식 클래스에서 부모 클래스의 메서드를 **같은 이름으로 다시 정의**하면 자식 클래스의 메서드가 우선합니다. 이를 **메서드 오버라이딩**이라고 해요.

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name}이(가) 소리를 냅니다.")


class Dog(Animal):
    def speak(self):   # 부모 메서드 오버라이딩
        print(f"{self.name}: 멍멍!")


class Cat(Animal):
    def speak(self):   # 부모 메서드 오버라이딩
        print(f"{self.name}: 야옹~")


animals = [Dog("뽀삐"), Cat("나비"), Dog("초코")]

for animal in animals:
    animal.speak()   # 각 객체의 실제 타입에 맞는 메서드 호출
```

**실행 결과**
```
뽀삐: 멍멍!
나비: 야옹~
초코: 멍멍!
```

같은 `speak()` 메서드를 호출해도 객체 종류에 따라 다르게 동작하는 것을 **다형성(polymorphism)** 이라고 합니다. 리스트 안의 다양한 객체를 동일한 방식으로 처리할 수 있어 코드가 유연해져요.

## 7.6 실전 예제

지금까지 배운 클래스, 생성자, 상속을 활용해 간단한 도서관 관리 프로그램을 만들어 봅시다.

### 예제: 도서관 관리 프로그램

```python
# ── 클래스 정의 ──────────────────────────────

class Book:
    """도서 정보를 나타내는 클래스"""

    def __init__(self, title, author, year):
        self.title = title
        self.author = author
        self.year = year
        self.is_available = True   # 대출 가능 여부

    def __str__(self):
        status = "대출 가능" if self.is_available else "대출 중"
        return f"[{self.year}] {self.title} / {self.author} — {status}"


class Library:
    """도서관을 나타내는 클래스"""

    def __init__(self, name):
        self.name = name
        self.books = []   # 보유 도서 목록

    def add_book(self, book):
        """도서 추가"""
        self.books.append(book)
        print(f"'{book.title}' 도서가 추가되었습니다.")

    def show_all(self):
        """전체 도서 목록 출력"""
        print(f"\n{'=' * 50}")
        print(f"  📚 {self.name} 도서 목록 (총 {len(self.books)}권)")
        print(f"{'=' * 50}")
        for i, book in enumerate(self.books, 1):
            print(f"  {i}. {book}")
        print(f"{'=' * 50}")

    def borrow(self, title):
        """도서 대출"""
        for book in self.books:
            if book.title == title:
                if book.is_available:
                    book.is_available = False
                    print(f"'{title}' 대출 완료!")
                else:
                    print(f"'{title}'은(는) 현재 대출 중입니다.")
                return
        print(f"'{title}' 도서를 찾을 수 없습니다.")

    def returning(self, title):
        """도서 반납"""
        for book in self.books:
            if book.title == title:
                if not book.is_available:
                    book.is_available = True
                    print(f"'{title}' 반납 완료!")
                else:
                    print(f"'{title}'은(는) 이미 반납된 상태입니다.")
                return
        print(f"'{title}' 도서를 찾을 수 없습니다.")

    def search(self, keyword):
        """키워드로 도서 검색"""
        results = [b for b in self.books
                   if keyword in b.title or keyword in b.author]
        print(f"\n'{keyword}' 검색 결과: {len(results)}건")
        for book in results:
            print(f"  • {book}")


# ── 메인 코드 ──────────────────────────────

library = Library("파이썬 도서관")

# 도서 추가
library.add_book(Book("파이썬 입문", "홍길동", 2023))
library.add_book(Book("데이터 분석 기초", "김철수", 2022))
library.add_book(Book("머신러닝 이해하기", "이영희", 2024))
library.add_book(Book("파이썬으로 배우는 통계", "박민준", 2023))

# 전체 목록 출력
library.show_all()

# 대출
library.borrow("파이썬 입문")
library.borrow("파이썬 입문")   # 이미 대출 중

# 검색
library.search("파이썬")

# 반납 후 목록 확인
library.returning("파이썬 입문")
library.show_all()
```

**실행 결과**
```

'데이터 분석 기초' 도서가 추가되었습니다.
'머신러닝 이해하기' 도서가 추가되었습니다.
'파이썬으로 배우는 통계' 도서가 추가되었습니다.

==================================================

  2. [2022] 데이터 분석 기초 / 김철수 — 대출 가능
  3. [2024] 머신러닝 이해하기 / 이영희 — 대출 가능
  4. [2023] 파이썬으로 배우는 통계 / 박민준 — 대출 가능

  2. [2022] 데이터 분석 기초 / 김철수 — 대출 가능
  3. [2024] 머신러닝 이해하기 / 이영희 — 대출 가능
  4. [2023] 파이썬으로 배우는 통계 / 박민준 — 대출 가능

```

### 코드 설명

- `Book` 클래스 : 도서 한 권의 데이터(제목, 저자, 연도, 대출 여부)를 속성으로 갖고, `__str__`으로 보기 좋은 출력 형식을 정의합니다.
- `Library` 클래스 : 도서관 이름과 도서 목록을 속성으로 갖고, 도서 추가·출력·대출·반납·검색 기능을 메서드로 제공합니다.
- `self.books = []` : 객체마다 독립적인 도서 목록 리스트를 갖습니다.
- 리스트 컴프리헨션 : `search()` 메서드에서 키워드가 포함된 도서만 걸러낼 때 사용합니다.

> **📌 7장 정리**
> - **클래스**는 객체를 만드는 설계도이고, **객체(인스턴스)** 는 클래스로 만들어진 실체입니다.
> - **`__init__`** 은 객체 생성 시 자동 호출되는 생성자로, 속성의 초기값을 설정합니다.
> - **`self`** 는 메서드 안에서 객체 자신을 가리킵니다. 모든 메서드의 첫 번째 매개변수로 사용합니다.
> - **인스턴스 변수**(`self.변수명`)는 객체마다 독립적인 값을 가지고, **클래스 변수**는 모든 객체가 공유합니다. 클래스 변수는 클래스 이름으로 수정해야 모든 객체에 반영됩니다.
> - **`@classmethod`** 는 클래스 변수를 다루거나 객체 생성 방식을 추가할 때 사용하며 첫 번째 인수로 `cls`를 받습니다. **`@staticmethod`** 는 클래스·인스턴스와 무관한 독립적인 유틸리티 함수를 클래스 안에 묶을 때 사용합니다.
> - **상속**으로 부모 클래스의 속성과 메서드를 물려받아 재사용하고, **오버라이딩**으로 자식 클래스에 맞게 동작을 바꿀 수 있습니다.
> - **`super()`** 로 부모 클래스의 메서드를 자식 클래스에서 호출할 수 있습니다.
