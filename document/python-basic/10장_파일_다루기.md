## 10.1 파일 다루기 기초

### 왜 파일을 다뤄야 할까?

지금까지 작성한 프로그램은 실행이 끝나면 모든 데이터가 사라졌어요. 프로그램을 다시 실행하면 처음부터 다시 시작해야 했죠. 하지만 현실에서는 데이터를 **영구적으로 저장**하고 나중에 다시 불러와야 하는 경우가 많습니다.

파일을 다루는 방법을 익히면 다음과 같은 일이 가능해집니다.

- 사용자 입력 결과를 파일로 저장해 다음에도 사용하기
- 외부에서 제공된 데이터 파일(CSV, 텍스트 등)을 읽어 분석하기
- 처리 결과를 파일로 저장해 다른 프로그램과 공유하기

### 파일 열기: open()

파이썬에서 파일을 다루려면 먼저 `open()` 함수로 파일을 열어야 합니다.

```python
파일객체 = open("파일경로", "모드", encoding="utf-8")
```

**모드의 종류**

| 모드 | 의미 | 파일이 없을 때 |
|---|---|---|
| `"r"` | 읽기 (기본값) | 오류 발생 |
| `"w"` | 쓰기 (기존 내용 덮어씀) | 새 파일 생성 |
| `"a"` | 추가 쓰기 (기존 내용 뒤에 추가) | 새 파일 생성 |
| `"x"` | 새 파일 쓰기 (파일이 이미 있으면 오류) | 새 파일 생성 |

> **📌 encoding 설정:** 한글이 포함된 파일은 반드시 `encoding="utf-8"`을 지정해야 깨짐 없이 읽고 쓸 수 있어요. Windows에서는 `encoding="cp949"`가 필요한 경우도 있습니다.

### 파일 닫기: close()

파일을 열었으면 사용 후 반드시 닫아야 합니다. 닫지 않으면 데이터가 손실되거나 다른 프로그램이 파일에 접근하지 못할 수 있어요.

```python
f = open("hello.txt", "w", encoding="utf-8")
f.write("안녕하세요!")
f.close()   # 반드시 닫기
```

### with 문: 자동으로 닫기

`with` 문을 사용하면 블록이 끝날 때 파일이 **자동으로 닫힙니다**. `close()`를 깜빡할 염려가 없어 훨씬 안전하고 권장되는 방식이에요.

```python
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("안녕하세요!")
# with 블록을 벗어나면 자동으로 f.close() 실행
```

앞으로 파일을 다룰 때는 항상 `with` 문을 사용하겠습니다.

## 10.2 파일 쓰기

### write() — 문자열 쓰기

`write()`는 문자열을 파일에 씁니다. 줄 바꿈은 자동으로 되지 않으므로 `\n`을 직접 넣어야 해요.

```python
with open("greeting.txt", "w", encoding="utf-8") as f:
    f.write("안녕하세요!\n")
    f.write("파이썬 파일 쓰기 예제입니다.\n")
    f.write("세 번째 줄입니다.\n")

print("파일 쓰기 완료!")
```

**greeting.txt 내용**
```
안녕하세요!
파이썬 파일 쓰기 예제입니다.
세 번째 줄입니다.
```

### writelines() — 리스트를 한 번에 쓰기

`writelines()`는 문자열 리스트의 항목을 파일에 한 번에 씁니다. 마찬가지로 줄 바꿈은 직접 포함해야 해요.

```python
lines = [
    "홍길동, 92\n",
    "김철수, 75\n",
    "이영희, 88\n",
]

with open("scores.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)

print("점수 파일 저장 완료!")
```

### 이어쓰기 모드: "a"

`"w"` 모드는 기존 파일 내용을 모두 지우고 새로 씁니다. 기존 내용 뒤에 추가하려면 `"a"` 모드를 사용하세요.

```python
# 첫 번째 실행: 파일 생성 후 내용 쓰기
with open("log.txt", "w", encoding="utf-8") as f:
    f.write("2024-05-01: 프로그램 시작\n")

# 두 번째 실행: 기존 내용 유지하고 추가
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("2024-05-01: 데이터 처리 완료\n")
    f.write("2024-05-01: 프로그램 종료\n")
```

**log.txt 내용**
```
2024-05-01: 프로그램 시작
2024-05-01: 데이터 처리 완료
2024-05-01: 프로그램 종료
```

## 10.3 파일 읽기

### read() — 전체 읽기

`read()`는 파일 전체 내용을 하나의 문자열로 읽습니다.

```python
with open("greeting.txt", "r", encoding="utf-8") as f:
    content = f.read()

print(content)
print(f"전체 글자 수: {len(content)}")
```

**실행 결과**
```
안녕하세요!
파이썬 파일 쓰기 예제입니다.
세 번째 줄입니다.

전체 글자 수: 34
```

### readline() — 한 줄씩 읽기

`readline()`은 파일에서 한 줄을 읽습니다. 반복 호출하면 다음 줄을 읽어요.

```python
with open("greeting.txt", "r", encoding="utf-8") as f:
    line1 = f.readline()
    line2 = f.readline()

print(line1)   # 안녕하세요!\n
print(line2)   # 파이썬 파일 쓰기 예제입니다.\n
```

### readlines() — 전체를 줄 단위 리스트로 읽기

`readlines()`는 파일의 모든 줄을 리스트로 반환합니다. 각 항목에는 줄 끝 `\n`이 포함되어 있어요.

```python
with open("greeting.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()

print(lines)
# ['안녕하세요!\n', '파이썬 파일 쓰기 예제입니다.\n', '세 번째 줄입니다.\n']

for line in lines:
    print(line.strip())   # strip()으로 줄 끝 \n 제거
```

**실행 결과**
```
안녕하세요!
파이썬 파일 쓰기 예제입니다.
세 번째 줄입니다.
```

### for 문으로 줄 단위 읽기 (권장)

파일 객체를 `for` 문에 직접 넣으면 한 줄씩 효율적으로 읽을 수 있습니다. 파일이 매우 클 때도 메모리를 적게 사용해서 **가장 권장되는 방식**이에요.

```python
with open("greeting.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

**실행 결과**
```
안녕하세요!
파이썬 파일 쓰기 예제입니다.
세 번째 줄입니다.
```

### 파일 읽기 방법 비교

| 메서드 | 반환 타입 | 특징 |
|---|---|---|
| `read()` | 문자열 | 전체를 한 번에 읽음 |
| `readline()` | 문자열 | 한 줄씩 읽음 |
| `readlines()` | 리스트 | 전체를 줄 단위 리스트로 반환 |
| `for line in f` | — | 줄 단위 순회, 메모리 효율적 |

## 10.4 CSV 파일 다루기

### CSV란?

**CSV(Comma-Separated Values)** 는 데이터를 쉼표로 구분해 저장하는 텍스트 파일 형식입니다. 엑셀이나 구글 스프레드시트에서 열 수 있고, 데이터 분석에서 가장 많이 사용되는 파일 형식이에요.

```
# students.csv 예시
이름,국어,영어,수학
홍길동,92,85,90
김철수,75,80,70
이영희,88,92,95
박민준,55,60,50
```

### csv 모듈로 읽기

파이썬 표준 라이브러리의 `csv` 모듈을 사용하면 CSV 파일을 안전하게 읽을 수 있습니다.

먼저 실습용 CSV 파일을 만들어 볼게요.

```python
import csv

# CSV 파일 쓰기
with open("students.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerow(["이름", "국어", "영어", "수학"])   # 헤더
    writer.writerow(["홍길동", 92, 85, 90])
    writer.writerow(["김철수", 75, 80, 70])
    writer.writerow(["이영희", 88, 92, 95])
    writer.writerow(["박민준", 55, 60, 50])

print("students.csv 파일 생성 완료!")
```

> **📌 `newline=""`:** CSV 파일을 쓸 때 `newline=""`을 지정하지 않으면 Windows에서 빈 줄이 추가되는 문제가 발생할 수 있어요.

```python
# CSV 파일 읽기
with open("students.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader)   # 첫 줄(헤더)을 별도로 읽기
    print(f"헤더: {header}")
    print("-" * 35)
    for row in reader:
        print(row)
```

**실행 결과**
```
헤더: ['이름', '국어', '영어', '수학']
-----------------------------------
['홍길동', '92', '85', '90']
['김철수', '75', '80', '70']
['이영희', '88', '92', '95']
['박민준', '55', '60', '50']
```

> **📌 주의:** CSV에서 읽은 숫자는 모두 **문자열**입니다. 계산에 사용하려면 `int()` 또는 `float()`으로 변환해야 해요.

### DictReader / DictWriter — 딕셔너리 형태로 다루기

`DictReader`를 사용하면 각 행을 `{헤더: 값}` 형태의 딕셔너리로 읽을 수 있어 더 직관적입니다.

```python
import csv

# DictReader로 읽기
with open("students.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        name = row["이름"]
        kor = int(row["국어"])
        eng = int(row["영어"])
        math = int(row["수학"])
        avg = (kor + eng + math) / 3
        print(f"{name}: 평균 {avg:.1f}점")
```

**실행 결과**
```
홍길동: 평균 89.0점
김철수: 평균 75.0점
이영희: 평균 91.7점
박민준: 평균 55.0점
```

```python
import csv

# DictWriter로 쓰기
fieldnames = ["이름", "국어", "영어", "수학", "평균"]

with open("students_avg.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()   # 헤더 자동 작성
    writer.writerow({"이름": "홍길동", "국어": 92, "영어": 85, "수학": 90, "평균": 89.0})
    writer.writerow({"이름": "김철수", "국어": 75, "영어": 80, "수학": 70, "평균": 75.0})

print("students_avg.csv 저장 완료!")
```

## 10.5 예외 처리와 함께 쓰기

### 파일 처리에서 자주 발생하는 예외

파일을 다룰 때는 다양한 예외가 발생할 수 있습니다.

| 예외 | 발생 상황 |
|---|---|
| `FileNotFoundError` | 읽으려는 파일이 없을 때 |
| `PermissionError` | 파일 접근 권한이 없을 때 |
| `IsADirectoryError` | 파일이 아닌 폴더를 열려 할 때 |
| `UnicodeDecodeError` | 인코딩이 맞지 않을 때 |

### 파일 읽기에 예외 처리 적용

```python
def read_file(filepath):
    try:
        with open(filepath, "r", encoding="utf-8") as f:
            content = f.read()
        return content
    except FileNotFoundError:
        print(f"❌ 파일을 찾을 수 없습니다: {filepath}")
        return None
    except PermissionError:
        print(f"❌ 파일 접근 권한이 없습니다: {filepath}")
        return None
    except UnicodeDecodeError:
        print(f"❌ 파일 인코딩 오류입니다. encoding 설정을 확인하세요.")
        return None

# 존재하는 파일
content = read_file("greeting.txt")
if content:
    print(content)

# 존재하지 않는 파일
content = read_file("없는파일.txt")
```

**실행 결과**
```
안녕하세요!
파이썬 파일 쓰기 예제입니다.
세 번째 줄입니다.

❌ 파일을 찾을 수 없습니다: 없는파일.txt
```

### CSV 파일 읽기에 예외 처리 적용

```python
import csv

def read_csv(filepath):
    try:
        with open(filepath, "r", encoding="utf-8") as f:
            reader = csv.DictReader(f)
            data = [row for row in reader]
        print(f"✅ {len(data)}개 행을 읽었습니다.")
        return data
    except FileNotFoundError:
        print(f"❌ CSV 파일을 찾을 수 없습니다: {filepath}")
        return []
    except csv.Error as e:
        print(f"❌ CSV 형식 오류: {e}")
        return []

students = read_csv("students.csv")
for s in students:
    print(s)
```

**실행 결과**
```
✅ 4개 행을 읽었습니다.
{'이름': '홍길동', '국어': '92', '영어': '85', '수학': '90'}
{'이름': '김철수', '국어': '75', '영어': '80', '수학': '70'}
{'이름': '이영희', '국어': '88', '영어': '92', '수학': '95'}
{'이름': '박민준', '국어': '55', '영어': '60', '수학': '50'}
```

### finally로 파일 안전하게 닫기

`with` 문을 사용하면 자동으로 파일이 닫히지만, 직접 `open()`과 `close()`를 사용하는 경우에는 `finally`로 안전하게 닫아야 합니다.

```python
f = None
try:
    f = open("data.txt", "r", encoding="utf-8")
    content = f.read()
    print(content)
except FileNotFoundError:
    print("파일을 찾을 수 없습니다.")
finally:
    if f:
        f.close()   # 예외 발생 여부에 관계없이 파일 닫기
        print("파일이 닫혔습니다.")
```

> **📌 실전 권고:** `with` 문을 쓰면 `finally`에서 `close()`를 직접 호출할 필요가 없습니다. 가능하면 항상 `with` 문을 사용하는 것이 좋아요.

## 10.6 실전 예제

지금까지 배운 파일 읽기·쓰기, CSV 처리, 예외 처리를 모두 활용해 성적 관리 시스템을 만들어 봅시다.

### 예제: 성적 관리 시스템

학생 성적을 CSV 파일로 저장하고, 파일에서 읽어 분석 결과를 출력한 뒤 결과 파일로 저장하는 전체 흐름을 구현합니다.

```python
import csv
import os

# ── 설정 ────────────────────────────────────
INPUT_FILE = "students.csv"
OUTPUT_FILE = "result.csv"


# ── 함수 정의 ────────────────────────────────

def get_grade(avg):
    if avg >= 90: return "A"
    elif avg >= 80: return "B"
    elif avg >= 70: return "C"
    elif avg >= 60: return "D"
    else: return "F"


def load_students(filepath):
    """CSV 파일에서 학생 데이터를 읽어옵니다."""
    if not os.path.exists(filepath):
        print(f"❌ 파일이 없습니다: {filepath}")
        return []
    try:
        with open(filepath, "r", encoding="utf-8") as f:
            reader = csv.DictReader(f)
            students = []
            for row in reader:
                try:
                    students.append({
                        "이름": row["이름"],
                        "국어": int(row["국어"]),
                        "영어": int(row["영어"]),
                        "수학": int(row["수학"]),
                    })
                except (KeyError, ValueError) as e:
                    print(f"⚠️  데이터 오류 (건너뜀): {row} → {e}")
        print(f"✅ {len(students)}명의 데이터를 불러왔습니다.")
        return students
    except csv.Error as e:
        print(f"❌ CSV 읽기 오류: {e}")
        return []


def analyze(students):
    """학생 데이터를 분석해 평균과 학점을 추가합니다."""
    results = []
    for s in students:
        avg = round((s["국어"] + s["영어"] + s["수학"]) / 3, 1)
        grade = get_grade(avg)
        results.append({**s, "평균": avg, "학점": grade})
    return results


def print_report(results):
    """분석 결과를 화면에 출력합니다."""
    print("\n" + "=" * 55)
    print(f"  {'이름':<8} {'국어':>4} {'영어':>4} {'수학':>4} {'평균':>6} {'학점':>4}")
    print("-" * 55)
    for r in results:
        print(f"  {r['이름']:<8} {r['국어']:>4} {r['영어']:>4} {r['수학']:>4} {r['평균']:>6} {r['학점']:>4}")
    print("=" * 55)

    avgs = [r["평균"] for r in results]
    print(f"  전체 평균: {sum(avgs)/len(avgs):.1f}점")
    print(f"  최고 평균: {max(avgs)}점  최저 평균: {min(avgs)}점")
    print("=" * 55)


def save_results(results, filepath):
    """분석 결과를 CSV 파일로 저장합니다."""
    try:
        fieldnames = ["이름", "국어", "영어", "수학", "평균", "학점"]
        with open(filepath, "w", newline="", encoding="utf-8") as f:
            writer = csv.DictWriter(f, fieldnames=fieldnames)
            writer.writeheader()
            writer.writerows(results)
        print(f"\n✅ 결과가 저장되었습니다: {filepath}")
    except PermissionError:
        print(f"❌ 파일 저장 실패 (권한 오류): {filepath}")


# ── 메인 코드 ────────────────────────────────

print("=" * 55)
print("          성적 관리 시스템")
print("=" * 55)

students = load_students(INPUT_FILE)

if students:
    results = analyze(students)
    print_report(results)
    save_results(results, OUTPUT_FILE)
```
