## 2.1 변수와 자료형

### 변수란?

**변수(variable)** 는 데이터를 저장해 두는 공간입니다. 마치 이름표가 붙은 상자처럼, 값을 담아두고 필요할 때 꺼내 쓸 수 있어요.

```python
age = 25
name = "홍길동"
```

위 코드에서 `age`와 `name`이 변수입니다. `=` 기호는 오른쪽 값을 왼쪽 변수에 저장하라는 뜻이에요. 수학에서의 "같다"와는 다른 의미입니다.

변수에 저장된 값은 언제든지 바꿀 수 있어요.

```python
age = 25
print(age)   # 25 출력

age = 30
print(age)   # 30 출력
```

**실행 결과**
```
25
30
```

### 변수 이름 규칙

변수 이름을 정할 때는 몇 가지 규칙이 있습니다.

| 규칙 | 예시 |
|---|---|
| 영문자, 숫자, 밑줄(`_`)만 사용 가능 | `my_score`, `data1` |
| 숫자로 시작할 수 없음 | ❌ `1score` |
| 대소문자를 구분함 | `age`와 `Age`는 다른 변수 |
| 파이썬 예약어는 사용 불가 | ❌ `if`, `for`, `True` 등 |

> **📌 관습:** 파이썬에서는 변수 이름을 소문자로 쓰고 여러 단어를 이을 때 밑줄(`_`)을 사용하는 것이 일반적입니다. 예: `student_name`, `total_score`

---

### 자료형이란?

**자료형(data type)** 은 변수에 저장되는 값의 종류입니다. 파이썬의 기본 자료형은 네 가지예요.

| 자료형 | 이름 | 예시 |
|---|---|---|
| `int` | 정수 | `10`, `-3`, `0` |
| `float` | 실수(소수) | `3.14`, `-0.5`, `1.0` |
| `str` | 문자열 | `"안녕"`, `'파이썬'` |
| `bool` | 불리언 | `True`, `False` |

`type()` 함수를 사용하면 변수의 자료형을 확인할 수 있어요.

```python
a = 10
b = 3.14
c = "안녕하세요"
d = True

print(type(a))   # <class 'int'>
print(type(b))   # <class 'float'>
print(type(c))   # <class 'str'>
print(type(d))   # <class 'bool'>
```

**실행 결과**
```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

---

### 정수 (int)

소수점이 없는 숫자입니다. 양수, 음수, 0 모두 포함해요.

```python
score = 95
temperature = -5
count = 0

print(score)        # 95
print(temperature)  # -5
```

---

### 실수 (float)

소수점이 있는 숫자입니다. 데이터 분석에서 평균이나 비율을 다룰 때 자주 등장해요.

```python
average = 87.5
pi = 3.14159
ratio = 0.75

print(average)  # 87.5
print(pi)       # 3.14159
```

> **📌 주의:** 정수처럼 보여도 소수점을 붙이면 float이 됩니다. `1`은 int이고 `1.0`은 float이에요.

---

### 문자열 (str)

**문자열** 은 글자들의 모음입니다. 큰따옴표(`"`) 또는 작은따옴표(`'`) 중 하나로 감싸서 표현해요.

```python
name = "홍길동"
city = '서울'
message = "파이썬은 재미있어요!"

print(name)     # 홍길동
print(city)     # 서울
print(message)  # 파이썬은 재미있어요!
```

문자열 안에 큰따옴표나 작은따옴표가 포함되어야 할 때는 서로 다른 따옴표로 감싸면 됩니다.

```python
sentence1 = "그는 '안녕'이라고 말했습니다."
sentence2 = '그녀는 "반가워요"라고 했습니다.'

print(sentence1)
print(sentence2)
```

**실행 결과**
```
그는 '안녕'이라고 말했습니다.
그녀는 "반가워요"라고 했습니다.
```

숫자처럼 보여도 따옴표로 감싸면 문자열이에요. `100`은 int이고, `"100"`은 str입니다. 이 차이는 나중에 계산을 할 때 중요하게 작용합니다.

---

### 불리언 (bool)

**불리언** 은 `True`(참) 또는 `False`(거짓), 딱 두 가지 값만 가지는 자료형입니다. 조건을 판단할 때 사용해요.

```python
is_student = True
is_raining = False

print(is_student)  # True
print(is_raining)  # False
```

> **📌 주의:** `True`와 `False`는 반드시 첫 글자를 대문자로 씁니다. `true`나 `false`로 쓰면 오류가 발생해요.

---

### 자료형 변환

자료형을 다른 자료형으로 바꿀 수 있습니다.

```python
# 문자열 → 정수
num_str = "100"
num_int = int(num_str)
print(num_int + 5)   # 105

# 정수 → 실수
x = 7
y = float(x)
print(y)             # 7.0

# 숫자 → 문자열
age = 25
age_str = str(age)
print("나이: " + age_str)  # 나이: 25
```

**실행 결과**
```
105
7.0
나이: 25
```

> **📌 주의:** 문자열을 정수로 변환할 때, 문자열이 실제 숫자 형태여야 합니다. `int("안녕")`처럼 숫자가 아닌 문자열을 변환하려 하면 오류가 발생해요.

## 2.2 출력: print()

### 기본 사용법

`print()` 함수는 괄호 안의 내용을 화면에 출력합니다.

```python
print("안녕하세요!")
print(42)
print(3.14)
print(True)
```

**실행 결과**
```
안녕하세요!
42
3.14
True
```

---

### 여러 값 한 번에 출력하기

쉼표(`,`)로 구분해 여러 값을 한 줄에 출력할 수 있어요. 값 사이에는 자동으로 공백이 삽입됩니다.

```python
name = "홍길동"
age = 25

print(name, age)           # 홍길동 25
print("이름:", name)        # 이름: 홍길동
print("이름:", name, "나이:", age)  # 이름: 홍길동 나이: 25
```

**실행 결과**
```
홍길동 25
이름: 홍길동
이름: 홍길동 나이: 25
```

---

### sep와 end 옵션

`sep`는 값과 값 사이의 구분 문자를 바꾸는 옵션이고, `end`는 출력 마지막에 붙는 문자를 바꾸는 옵션입니다. 기본값은 `sep=" "`, `end="\n"` (줄 바꿈)이에요.

```python
# sep 사용: 값 사이를 '-'로 구분
print("2024", "05", "01", sep="-")   # 2024-05-01

# end 사용: 출력 후 줄 바꿈 대신 공백으로 이어 붙이기
print("안녕", end=" ")
print("파이썬!")                       # 안녕 파이썬!
```

**실행 결과**
```
2024-05-01
안녕 파이썬!
```

## 2.3 입력: input()

### 기본 사용법

`input()` 함수는 사용자가 키보드로 입력한 값을 받아옵니다. 괄호 안에 안내 메시지를 넣을 수 있어요.

```python
name = input("이름을 입력하세요: ")
print("안녕하세요,", name)
```

**실행 예시**
```
이름을 입력하세요: 홍길동
안녕하세요, 홍길동
```

---

### input()의 결과는 항상 문자열

`input()`으로 받은 값은 숫자처럼 보여도 항상 **문자열(str)** 입니다. 숫자로 계산하려면 자료형을 변환해야 해요.

```python
# 잘못된 예: 문자열끼리 더하면 이어 붙이기가 됨
num = input("숫자를 입력하세요: ")   # 10 입력
print(num + 5)   # ❌ 오류 발생!
```

```python
# 올바른 예: int()로 변환 후 계산
num = int(input("숫자를 입력하세요: "))   # 10 입력
print(num + 5)   # 15
```

**실행 예시**
```
숫자를 입력하세요: 10
15
```

소수점이 있는 값을 입력받으려면 `float()`을 사용합니다.

```python
height = float(input("키를 입력하세요(cm): "))   # 175.5 입력
print("입력한 키:", height)
```

## 2.4 연산자

### 산술 연산자

숫자 계산에 사용하는 연산자입니다.

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `10 + 3` | `13` |
| `-` | 빼기 | `10 - 3` | `7` |
| `*` | 곱하기 | `10 * 3` | `30` |
| `/` | 나누기 | `10 / 3` | `3.333...` |
| `//` | 몫 (정수 나누기) | `10 // 3` | `3` |
| `%` | 나머지 | `10 % 3` | `1` |
| `**` | 거듭제곱 | `2 ** 8` | `256` |

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333333333333335
print(a // b)  # 3
print(a % b)   # 1
print(a ** b)  # 1000
```

**실행 결과**
```
13
7
30
3.3333333333333335
3
1
1000
```

> **📌 활용 팁:** `%`(나머지) 연산자는 짝수·홀수 판별이나 배수 확인에 자주 쓰입니다. 예를 들어 `n % 2 == 0` 이면 n은 짝수예요.

---

### 비교 연산자

두 값을 비교해서 `True` 또는 `False`를 반환합니다.

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `==` | 같다 | `5 == 5` | `True` |
| `!=` | 다르다 | `5 != 3` | `True` |
| `>` | 크다 | `5 > 3` | `True` |
| `<` | 작다 | `5 < 3` | `False` |
| `>=` | 크거나 같다 | `5 >= 5` | `True` |
| `<=` | 작거나 같다 | `5 <= 3` | `False` |

```python
score = 85

print(score >= 90)   # False
print(score >= 80)   # True
print(score == 85)   # True
print(score != 100)  # True
```

**실행 결과**
```
False
True
True
True
```

> **📌 주의:** `=`는 값을 저장하는 기호이고, `==`는 두 값이 같은지 비교하는 기호입니다. 혼동하지 않도록 주의하세요.

---

### 논리 연산자

여러 조건을 조합할 때 사용합니다.

| 연산자 | 의미 | 설명 |
|---|---|---|
| `and` | 그리고 | 두 조건이 모두 True일 때 True |
| `or` | 또는 | 두 조건 중 하나라도 True이면 True |
| `not` | 부정 | True → False, False → True |

```python
age = 20
score = 85

# and: 나이가 18 이상이고 점수가 80 이상인가?
print(age >= 18 and score >= 80)   # True

# or: 나이가 30 이상이거나 점수가 90 이상인가?
print(age >= 30 or score >= 90)    # False

# not: 점수가 80 이상이 아닌가?
print(not score >= 80)             # False
```

**실행 결과**
```
True
False
False
```

---

### 복합 대입 연산자

변수의 값을 변경할 때 더 간결하게 쓸 수 있는 연산자입니다.

| 연산자 | 의미 | 예시 | 동일한 표현 |
|---|---|---|---|
| `+=` | 더한 후 저장 | `x += 3` | `x = x + 3` |
| `-=` | 뺀 후 저장 | `x -= 3` | `x = x - 3` |
| `*=` | 곱한 후 저장 | `x *= 3` | `x = x * 3` |
| `/=` | 나눈 후 저장 | `x /= 3` | `x = x / 3` |

```python
count = 0
count += 1   # count = count + 1
count += 1
count += 1
print(count)   # 3

total = 100
total -= 30
print(total)   # 70
```

**실행 결과**
```
3
70
```

---

### 연산자 우선순위

여러 연산자가 함께 있을 때는 우선순위가 높은 연산자부터 먼저 계산됩니다. 아래 표에서 위쪽일수록 우선순위가 높아요.

| 우선순위 | 연산자 | 설명 |
|:---:|---|---|
| 1 | `()` | 괄호 |
| 2 | `**` | 거듭제곱 |
| 3 | `+x`, `-x` | 단항 부호 (양수/음수 표시) |
| 4 | `*`, `/`, `//`, `%` | 곱하기, 나누기, 몫, 나머지 |
| 5 | `+`, `-` | 더하기, 빼기 |
| 6 | `==`, `!=`, `>`, `<`, `>=`, `<=` | 비교 연산자 |
| 7 | `not` | 논리 부정 |
| 8 | `and` | 논리 곱 |
| 9 | `or` | 논리 합 |

우선순위가 헷갈릴 때는 괄호로 명확하게 표현하는 것이 좋습니다. 코드를 읽는 사람도 이해하기 훨씬 쉬워져요.

```python
result1 = 2 + 3 * 4        # 3 * 4 먼저 계산 → 14
result2 = (2 + 3) * 4      # 괄호 안을 먼저 계산 → 20
result3 = 2 ** 3 + 1       # 2 ** 3 먼저 계산 → 9
result4 = 10 > 5 and 3 < 7 # 비교 먼저, 그다음 and → True

print(result1)   # 14
print(result2)   # 20
print(result3)   # 9
print(result4)   # True
```

**실행 결과**
```
14
20
9
True
```

## 2.5 실전 예제

지금까지 배운 변수, 자료형, 출력, 입력, 연산자를 모두 활용해 간단한 계산기 프로그램을 만들어 봅시다.

### 예제: 나의 BMI 계산기

BMI(체질량지수)는 체중과 키를 이용해 비만도를 나타내는 지표입니다.

**BMI 계산 공식:** BMI = 체중(kg) ÷ 키(m)²

```python
print("=" * 35)
print("       BMI 계산기")
print("=" * 35)

name = input("이름을 입력하세요: ")
weight = float(input("체중을 입력하세요 (kg): "))
height = float(input("키를 입력하세요 (cm): "))

# cm → m 변환
height_m = height / 100

# BMI 계산
bmi = weight / (height_m ** 2)

# 소수점 둘째 자리까지 반올림
bmi = round(bmi, 2)

print("=" * 35)
print(name, "님의 BMI:", bmi)
print("=" * 35)
```

**실행 예시**
```
===================================
       BMI 계산기
===================================
이름을 입력하세요: 홍길동
체중을 입력하세요 (kg): 70
키를 입력하세요 (cm): 175
===================================
홍길동 님의 BMI: 22.86
===================================
```

### 코드 설명

- `float(input(...))` : 사용자 입력을 실수(float)로 바로 변환합니다.
- `height / 100` : cm 단위를 m 단위로 변환합니다.
- `height_m ** 2` : 키의 제곱을 계산합니다.
- `round(bmi, 2)` : `round()` 함수는 숫자를 반올림합니다. 두 번째 인수는 소수점 자릿수예요.

### 직접 해보기

BMI 결과를 출력할 때 다음 기준을 함께 출력해 보세요.

| BMI | 기준 |
|---|---|
| 18.5 미만 | 저체중 |
| 18.5 이상 ~ 25 미만 | 정상 |
| 25 이상 | 과체중 |

힌트: 비교 연산자(`<`, `>=`)를 활용하면 됩니다. 4장 조건문에서 자세히 배울 예정이에요!

---

> **📌 2장 정리**
> - 변수는 값을 저장하는 공간이며, `=`로 값을 할당합니다.
> - 기본 자료형은 `int`(정수), `float`(실수), `str`(문자열), `bool`(불리언)입니다.
> - `print()`로 출력하고, `input()`으로 사용자 입력을 받습니다. `input()`의 결과는 항상 문자열입니다.
> - 산술 연산자(`+ - * / // % **`), 비교 연산자(`== != > < >= <=`), 논리 연산자(`and or not`)를 활용합니다.
