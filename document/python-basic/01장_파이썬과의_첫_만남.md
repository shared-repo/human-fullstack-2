## 1.1 파이썬이란?

파이썬(Python)은 1991년 네덜란드 프로그래머 귀도 반 로섬(Guido van Rossum)이 만든 프로그래밍 언어입니다. 이름은 영국 코미디 그룹 *몬티 파이썬(Monty Python)*에서 따왔어요.

파이썬의 가장 큰 특징은 **읽기 쉽고 쓰기 쉽다**는 점입니다. 아래 두 코드를 비교해 보세요. 둘 다 "안녕하세요!"를 출력하는 코드예요.

**Java로 작성한 경우**
```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("안녕하세요!");
    }
}
```

**파이썬으로 작성한 경우**
```python
print("안녕하세요!")
```

파이썬은 단 한 줄이면 됩니다. 처음 프로그래밍을 배우는 분들도 코드가 무슨 뜻인지 직관적으로 이해할 수 있을 정도로 간결합니다.

---

## 1.2 왜 파이썬인가?

파이썬은 전 세계에서 가장 인기 있는 프로그래밍 언어 중 하나입니다. 특히 **데이터 분석과 인공지능(AI)** 분야에서는 사실상 표준 언어로 자리 잡았어요. 그 이유를 살펴볼게요.

### 배우기 쉬운 문법
프로그래밍을 처음 접하는 분들도 비교적 빠르게 익힐 수 있어요. 영어 문장과 비슷한 구조라 코드를 읽으면서 흐름을 이해하기 쉽습니다.

### 강력한 라이브러리
라이브러리란 다른 사람들이 미리 만들어 둔 기능 모음이에요. 파이썬에는 데이터 분석에 필요한 거의 모든 기능이 라이브러리로 제공됩니다.

| 라이브러리 | 용도 |
|---|---|
| NumPy | 숫자 데이터 계산 |
| Pandas | 표 형태 데이터 다루기 |
| Matplotlib | 데이터 시각화 (그래프) |
| scikit-learn | 머신러닝 |

이 라이브러리들은 **데이터 분석 과정**에서 자세히 다룹니다. 이 책에서 기초를 탄탄히 다져두면 데이터 분석 과정의 내용을 훨씬 수월하게 이해할 수 있어요.

### 활발한 커뮤니티
전 세계 수백만 명의 파이썬 사용자들이 질문과 답변을 공유하고 있어요. 모르는 것이 생겼을 때 검색만 해도 대부분의 해답을 찾을 수 있습니다.

## 1.4 첫 번째 코드 실행

환경이 준비되었으니 이제 첫 번째 코드를 실행해 볼게요.

### Hello, 파이썬!

Jupyter Notebook의 셀에 아래 코드를 입력하고 **Shift + Enter** 를 눌러보세요.

```python

```

**실행 결과**
```
안녕하세요, 파이썬!
```

> **💡 스크린샷:** VS Code 노트북에서 코드 실행 화면

`print()`는 괄호 안의 내용을 화면에 출력하는 명령입니다. 큰따옴표(`"`) 안에 출력하고 싶은 내용을 넣으면 돼요.

---

### 계산도 해볼게요

파이썬은 계산기처럼 사용할 수도 있어요. 셀에 아래 코드를 입력해 보세요.

```python
print(10 + 3)   # 더하기
print(10 - 3)   # 빼기
print(10 * 3)   # 곱하기
print(10 / 3)   # 나누기
```

**실행 결과**
```
13
7
30
3.3333333333333335
```

코드에서 `#` 기호 뒤에 오는 내용은 **주석(comment)** 이라고 합니다. 파이썬이 실행할 때 무시하는 메모 공간으로, 코드가 어떤 역할을 하는지 설명하는 데 사용해요.

---

### 셀 추가와 삭제

노트북에서 새 셀을 추가하려면 셀 위아래에 표시되는 **+ Code** 버튼을 클릭하면 됩니다. 셀을 삭제하려면 셀을 선택한 뒤 오른쪽 위에 나타나는 휴지통 아이콘을 클릭하세요.

> **💡 참고:** 셀 왼쪽에 재생 버튼(▶)이 있고, 실행이 완료되면 그 자리에 숫자가 표시돼요. 숫자는 셀이 실행된 순서를 나타냅니다.

## 1.5 실전 예제

지금까지 배운 내용을 활용해 간단한 자기소개 프로그램을 만들어 봅시다.

### 예제: 나를 소개하는 프로그램

```python
print("=" * 30)
print("     나의 자기소개")
print("=" * 30)
print("이름: 홍길동")
print("나이: 25세")
print("관심 분야: 데이터 분석")
print("한마디: 파이썬을 배우기 시작했습니다!")
print("=" * 30)
```

**실행 결과**
```
==============================
     나의 자기소개
==============================
이름: 홍길동
나이: 25세
관심 분야: 데이터 분석
한마디: 파이썬을 배우기 시작했습니다!
==============================
```

### 코드 설명

- `"=" * 30` : 등호 기호(`=`)를 30번 반복해서 출력합니다. 문자열에 숫자를 곱하면 그 횟수만큼 반복돼요.
- `print()` 를 여러 번 사용해서 줄마다 다른 내용을 출력할 수 있습니다.
