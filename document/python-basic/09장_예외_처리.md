## 9.1 오류란 무엇인가?

### 오류의 두 가지 종류

프로그램을 작성하다 보면 오류를 만나는 것은 피할 수 없어요. 파이썬의 오류는 크게 두 가지로 나뉩니다.

**① 문법 오류 (Syntax Error)**
코드의 문법이 잘못되어 실행 자체가 되지 않는 오류입니다. 파이썬이 코드를 읽는 단계에서 바로 발견돼요.

```python
# 콜론(:)을 빠뜨린 경우
if x > 0
    print("양수")
```

```
SyntaxError: expected ':'
```

**② 예외 (Exception)**
문법은 맞지만 **실행 도중에 발생하는 오류**입니다. 코드가 실행되다가 예상치 못한 상황을 만나면 멈춰버려요.

```python
print(10 / 0)   # 0으로 나누기 시도
```

```
ZeroDivisionError: division by zero
```

문법 오류는 코드를 수정하면 해결되지만, 예외는 **실행 중에 언제든 발생할 수 있어서** 미리 대비하는 코드가 필요합니다. 이것이 바로 **예외 처리(exception handling)** 입니다.

### 왜 예외 처리가 필요한가?

예외 처리를 하지 않으면 예외가 발생하는 순간 프로그램이 그 자리에서 완전히 종료됩니다. 아래 예시를 볼게요.

```python
# 예외 처리 없이 여러 숫자를 나누는 프로그램
numbers = [10, 20, 0, 30]

for num in numbers:
    result = 100 / num
    print(f"100 / {num} = {result}")

print("모든 계산이 끝났습니다.")
```

**실행 결과**
```
100 / 10 = 10.0
100 / 20 = 5.0
ZeroDivisionError: division by zero
```

0을 만나는 순간 프로그램이 멈춰버리고 "모든 계산이 끝났습니다."는 출력되지 않아요. 뒤에 있는 30도 처리하지 못합니다.

이처럼 예외 처리가 없으면 다음과 같은 문제가 생깁니다.

- **프로그램이 갑자기 종료됩니다.** 사용자 입장에서는 아무 설명 없이 프로그램이 꺼지는 당황스러운 경험을 하게 됩니다.
- **처리하던 작업이 중단됩니다.** 파일 저장, 데이터 분석, 네트워크 통신 등 진행 중이던 작업이 모두 중단됩니다.
- **오류의 원인을 사용자에게 전달하기 어렵습니다.** 개발자에게 익숙한 오류 메시지는 일반 사용자에게는 낯설고 불친절합니다.

예외 처리를 적용하면 상황이 달라집니다.

```python
# 예외 처리를 추가한 버전
numbers = [10, 20, 0, 30]

for num in numbers:
    try:
        result = 100 / num
        print(f"100 / {num} = {result}")
    except ZeroDivisionError:
        print(f"100 / {num} = 계산 불가 (0으로 나눌 수 없습니다)")

print("모든 계산이 끝났습니다.")
```

**실행 결과**
```
100 / 10 = 10.0
100 / 20 = 5.0
100 / 0 = 계산 불가 (0으로 나눌 수 없습니다)
100 / 30 = 3.3333333333333335
모든 계산이 끝났습니다.
```

오류가 발생해도 프로그램이 멈추지 않고, 사용자에게 친절한 메시지를 보여주면서 나머지 작업을 계속 처리합니다. 예외 처리는 **프로그램을 더 안전하고 신뢰할 수 있게 만드는** 중요한 기술입니다.

---

### 자주 만나는 예외의 종류

| 예외 이름 | 발생 상황 | 예시 |
|---|---|---|
| `ZeroDivisionError` | 0으로 나누기 | `10 / 0` |
| `ValueError` | 잘못된 값 변환 | `int("abc")` |
| `TypeError` | 자료형 불일치 | `"1" + 1` |
| `IndexError` | 리스트 인덱스 범위 초과 | `[1,2,3][5]` |
| `KeyError` | 딕셔너리에 없는 키 접근 | `{"a":1}["b"]` |
| `NameError` | 정의되지 않은 변수 사용 | `print(x)` (x 미정의) |
| `FileNotFoundError` | 없는 파일 열기 시도 | `open("없는파일.txt")` |
| `AttributeError` | 없는 속성·메서드 호출 | `"hello".push()` |

각 예외를 직접 실행해 보면서 오류 메시지를 읽는 연습을 해보세요. 오류 메시지에는 **어떤 오류인지, 어느 줄에서 발생했는지** 정보가 담겨 있어 문제를 찾는 데 큰 도움이 됩니다.

```python
# ValueError 예시
number = int("abc")
```

```
ValueError: invalid literal for int() with base 10: 'abc'
```

```python
# IndexError 예시
numbers = [1, 2, 3]
print(numbers[10])
```

```
IndexError: list index out of range
```

## 9.2 try · except · finally

### 기본 구조

`try ~ except`는 예외가 발생할 수 있는 코드를 감싸고, 예외가 발생했을 때 대신 실행할 코드를 지정합니다.

```
try:
    예외가 발생할 수 있는 코드
except:
    예외가 발생했을 때 실행할 코드
```

```python
try:
    result = 10 / 0
    print(result)
except:
    print("오류가 발생했습니다.")

print("프로그램을 계속 실행합니다.")
```

**실행 결과**
```
오류가 발생했습니다.
프로그램을 계속 실행합니다.
```

`try` 블록 안에서 예외가 발생하면 즉시 `except` 블록으로 넘어가고, 프로그램은 종료되지 않고 계속 실행됩니다.

### 예외 종류 지정하기

어떤 예외인지 명시하면 해당 예외만 처리합니다. 예상하지 못한 다른 오류는 여전히 그대로 드러나기 때문에 **디버깅에 유리**해요.

```python
try:
    num = int(input("숫자를 입력하세요: "))
    result = 100 / num
    print(f"결과: {result}")
except ValueError:
    print("숫자가 아닌 값을 입력했습니다.")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
```

**실행 예시 1 — 문자 입력 시**
```
숫자를 입력하세요: abc
숫자가 아닌 값을 입력했습니다.
```

**실행 예시 2 — 0 입력 시**
```
숫자를 입력하세요: 0
0으로 나눌 수 없습니다.
```

**실행 예시 3 — 정상 입력 시**
```
숫자를 입력하세요: 5
결과: 20.0
```

### 여러 예외를 한 번에 처리하기

처리 방식이 같다면 튜플로 묶어서 한 번에 처리할 수 있습니다.

```python
try:
    data = [1, 2, 3]
    print(data[10])
except (IndexError, KeyError):
    print("잘못된 인덱스 또는 키입니다.")
```

### else 절

`else`는 예외가 **발생하지 않았을 때** 실행됩니다. 정상적으로 처리가 완료된 경우에만 실행할 코드를 분리할 수 있어요.

```python
try:
    num = int(input("숫자를 입력하세요: "))
    result = 100 / num
except ValueError:
    print("숫자가 아닌 값을 입력했습니다.")
except ZeroDivisionError:
    print("0으로 나눌 수 없습니다.")
else:
    print(f"계산 성공! 결과: {result}")   # 예외 없이 정상 실행됐을 때만
```

**실행 예시 — 정상 입력 시**
```
숫자를 입력하세요: 4
계산 성공! 결과: 25.0
```

### finally 절

`finally`는 예외 발생 여부와 **관계없이 항상 실행**됩니다. 파일이나 네트워크 연결처럼 반드시 정리해야 할 작업에 사용해요.

```python
try:
    num = int(input("숫자를 입력하세요: "))
    result = 100 / num
except (ValueError, ZeroDivisionError) as e:
    print(f"오류 발생: {e}")
else:
    print(f"결과: {result}")
finally:
    print("--- 계산 종료 ---")   # 항상 실행
```

**실행 예시 1 — 정상 입력**
```
숫자를 입력하세요: 5
결과: 20.0
--- 계산 종료 ---
```

**실행 예시 2 — 오류 발생**
```
숫자를 입력하세요: 0
오류 발생: division by zero
--- 계산 종료 ---
```

### try ~ except 구조 전체 요약

```
try:
    실행할 코드 (예외 발생 가능)
except 예외종류1:
    예외종류1 발생 시 처리
except 예외종류2:
    예외종류2 발생 시 처리
else:
    예외가 없을 때 실행
finally:
    항상 실행 (예외 여부 무관)
```

> **📌 권장 사항:** `except:` 처럼 예외 종류를 지정하지 않으면 모든 예외를 잡아버려 어떤 문제가 생겼는지 파악하기 어려워집니다. 가능하면 처리할 예외 종류를 명시하는 습관을 들이세요.

## 9.3 예외 메시지 활용

### as로 예외 정보 받기

`except 예외종류 as 변수` 형태로 예외 객체를 받아 오류 메시지를 출력하거나 활용할 수 있습니다.

```python
try:
    numbers = [1, 2, 3]
    print(numbers[10])
except IndexError as e:
    print(f"예외 발생: {e}")
    print(f"예외 종류: {type(e).__name__}")
```

**실행 결과**
```
예외 발생: list index out of range
예외 종류: IndexError
```

### 예외 메시지를 로그로 기록하기

실제 프로그램에서는 오류 메시지를 화면에 출력하는 것에서 나아가 파일에 기록해 두는 경우가 많아요.

```python
import datetime

def safe_divide(a, b):
    try:
        return a / b
    except ZeroDivisionError as e:
        timestamp = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
        log_msg = f"[{timestamp}] ZeroDivisionError: {e} (a={a}, b={b})"
        print(f"오류 기록: {log_msg}")
        return None

result = safe_divide(10, 2)
print(f"10 / 2 = {result}")    # 5.0

result = safe_divide(10, 0)
print(f"결과: {result}")        # None
```

**실행 결과**
```
10 / 2 = 5.0
오류 기록: [2024-05-01 14:30:25] ZeroDivisionError: division by zero (a=10, b=0)
결과: None
```

### 모든 예외 정보 출력하기: traceback

`traceback` 모듈을 사용하면 오류가 발생한 전체 경로(어떤 함수에서 어떤 순서로 호출됐는지)를 출력할 수 있습니다. 디버깅할 때 유용해요.

```python
import traceback

def level3():
    return 1 / 0

def level2():
    return level3()

def level1():
    return level2()

try:
    level1()
except ZeroDivisionError:
    traceback.print_exc()   # 전체 호출 경로 출력
```

**실행 결과**
```
Traceback (most recent call last):
  File "main.py", line 13, in <module>
    level1()
  File "main.py", line 10, in level1
    return level2()
  File "main.py", line 7, in level2
    return level3()
  File "main.py", line 4, in level3
    return 1 / 0
ZeroDivisionError: division by zero
```

## 9.4 직접 예외 발생시키기: raise

### raise란?

`raise`를 사용하면 의도적으로 예외를 발생시킬 수 있어요. 함수에 잘못된 값이 들어왔을 때 명확한 오류 메시지를 전달하거나, 특정 조건을 강제할 때 유용합니다.

```python
def set_age(age):
    if age < 0:
        raise ValueError(f"나이는 0 이상이어야 합니다. (입력값: {age})")
    if age > 150:
        raise ValueError(f"유효하지 않은 나이입니다. (입력값: {age})")
    print(f"나이가 {age}세로 설정되었습니다.")

try:
    set_age(25)    # 정상
    set_age(-5)    # ValueError 발생
except ValueError as e:
    print(f"오류: {e}")
```

**실행 결과**
```
나이가 25세로 설정되었습니다.
오류: 나이는 0 이상이어야 합니다. (입력값: -5)
```

### 사용자 정의 예외 클래스

7장에서 배운 클래스 상속으로 나만의 예외 클래스를 만들 수 있어요. 프로그램의 특정 상황을 더 명확하게 표현할 때 유용합니다.

```python
# 사용자 정의 예외 클래스 — Exception을 상속
class ScoreError(Exception):
    def __init__(self, score, message="점수는 0~100 사이여야 합니다."):
        self.score = score
        self.message = message
        super().__init__(self.message)

    def __str__(self):
        return f"{self.message} (입력값: {self.score})"


def set_score(score):
    if not (0 <= score <= 100):
        raise ScoreError(score)
    return score


try:
    print(set_score(85))    # 85
    print(set_score(150))   # ScoreError 발생
except ScoreError as e:
    print(f"점수 오류: {e}")
```

**실행 결과**
```
85
점수 오류: 점수는 0~100 사이여야 합니다. (입력값: 150)
```

### raise 다시 발생시키기

`except` 블록 안에서 `raise`만 단독으로 쓰면 잡은 예외를 그대로 다시 발생시킵니다. 오류를 기록만 하고 상위에서 처리하도록 넘길 때 사용해요.

```python
def process_data(data):
    try:
        result = 100 / data
        return result
    except ZeroDivisionError as e:
        print(f"[로그] process_data에서 오류 발생: {e}")
        raise   # 예외를 다시 발생시켜 호출한 곳에서 처리하게 함

try:
    process_data(0)
except ZeroDivisionError:
    print("최종 오류 처리: 0으로 나눌 수 없습니다.")
```

**실행 결과**
```
[로그] process_data에서 오류 발생: division by zero
최종 오류 처리: 0으로 나눌 수 없습니다.
```

## 9.5 실전 예제

지금까지 배운 예외 처리를 활용해 안전한 성적 입력 프로그램을 만들어 봅시다.

### 예제: 안전한 성적 입력 프로그램

```python
class ScoreError(Exception):
    """점수 유효성 오류"""
    pass


def input_score(name):
    """이름을 받아 유효한 점수를 입력받는 함수"""
    while True:
        try:
            score = int(input(f"  {name}의 점수를 입력하세요 (0~100): "))
            if not (0 <= score <= 100):
                raise ScoreError(f"점수 범위 초과: {score}")
            return score
        except ValueError:
            print("  ❌ 숫자를 입력해 주세요.")
        except ScoreError as e:
            print(f"  ❌ 유효하지 않은 점수입니다. ({e})")


def get_grade(score):
    """점수에 따른 학점 반환"""
    if score >= 90: return "A"
    elif score >= 80: return "B"
    elif score >= 70: return "C"
    elif score >= 60: return "D"
    else: return "F"


def run():
    print("=" * 45)
    print("        안전한 성적 입력 프로그램")
    print("=" * 45)

    names = ["홍길동", "김철수", "이영희"]
    results = []

    for name in names:
        score = input_score(name)
        grade = get_grade(score)
        results.append((name, score, grade))
        print(f"  ✅ {name}: {score}점 ({grade}학점) 입력 완료\n")

    # 결과 출력
    print("=" * 45)
    print(f"  {'이름':<8} {'점수':>5} {'학점':>5}")
    print("-" * 45)
    for name, score, grade in results:
        print(f"  {name:<8} {score:>5} {grade:>5}")

    scores = [s for _, s, _ in results]
    print("-" * 45)
    print(f"  평균: {sum(scores)/len(scores):.1f}점")
    print("=" * 45)


run()
```

**실행 예시**
```
=============================================
        안전한 성적 입력 프로그램
=============================================
  홍길동의 점수를 입력하세요 (0~100): abc
  ❌ 숫자를 입력해 주세요.
  홍길동의 점수를 입력하세요 (0~100): 150
  ❌ 유효하지 않은 점수입니다. (점수 범위 초과: 150)
  홍길동의 점수를 입력하세요 (0~100): 92
  ✅ 홍길동: 92점 (A학점) 입력 완료

  김철수의 점수를 입력하세요 (0~100): 75
  ✅ 김철수: 75점 (C학점) 입력 완료

  이영희의 점수를 입력하세요 (0~100): 88
  ✅ 이영희: 88점 (B학점) 입력 완료

=============================================
  이름       점수    학점
---------------------------------------------
  홍길동       92     A
  김철수       75     C
```

### 코드 설명

- `ScoreError(Exception)` : `Exception`을 상속받아 만든 사용자 정의 예외입니다. 점수 범위 오류를 의미 있게 표현해요.
- `while True` + `return` 패턴 : 유효한 값이 입력될 때까지 계속 반복하고, 정상 입력 시 `return`으로 빠져나옵니다.
- `except ValueError` : `int()` 변환 실패(문자 입력)를 처리합니다.
- `except ScoreError` : 범위를 벗어난 점수를 처리합니다.
- 두 가지 예외를 각각 `except`로 구분해 오류 메시지를 다르게 안내합니다.

> **📌 9장 정리**
> - 예외(Exception)는 문법은 맞지만 실행 중에 발생하는 오류입니다. 주요 예외로 `ValueError`, `TypeError`, `IndexError`, `KeyError`, `ZeroDivisionError` 등이 있습니다.
> - `try ~ except`로 예외를 처리하고, `else`는 예외가 없을 때, `finally`는 항상 실행됩니다.
> - `except 예외종류 as e`로 예외 객체를 받아 오류 메시지를 활용할 수 있습니다.
> - `raise`로 예외를 직접 발생시키고, `Exception`을 상속받아 사용자 정의 예외 클래스를 만들 수 있습니다.
> - 예외 종류를 명시하지 않은 `except:`는 피하고, 처리할 예외를 구체적으로 지정하는 습관을 들이세요.
